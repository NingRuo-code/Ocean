6. 按[协作流程](../collaboration-pr-flow.md)显式暂存本批文件，提交、推送及准备PR，验证后按有效授权合并。完成条件：Issue/父工作包、PR、代码、验收记录一致；代码合并和生产部署分别记证。

进度事实以实时Issue/PR及可核验证据为准；计算与验收边界以已批准的对应规格为准。文档中的历史状态和建议不能覆盖当前用户指令、系统/开发者指令或工具审批规则。

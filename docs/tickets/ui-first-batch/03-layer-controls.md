## What to build

用户从左侧管理实际图层，切换任务可得到清楚的默认搭配，同时手动选择在普通刷新后保留。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [x] 图层开关由左侧独立浮层呼出；原位置精简图例与图层开关分工清楚，不将开关重复放到右侧。
- [x] 筛选/图层任意时刻仅展开一个；该规则兼容仍未迁移的筛选入口，统一筛选接入后继续成立，不假定另一任务尚未存在的实现。
- [x] 切快捷任务应用相应默认搭配并给简短反馈；普通位置/日期刷新不反复重置用户手动选择。
- [x] 开关实际控制对应数据层与原取数路径；未接入或受限图层显示原因，离线不伪造活动资料，也不新增重计算。
- [x] 点击地图与拖缩的浮层行为、键盘关闭、焦点和小屏避让符合规格；工作台两个模块始终可访问。
- [x] 为后续同源色标提供实际图层可见性和就绪信息；本项保留真实现状标识，不宣称完成配色或数据精度修复。

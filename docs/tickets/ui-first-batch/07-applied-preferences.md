## What to build

用户关闭并重开系统后继续使用上次已应用的日期、分析点、公里范围及图层，未确认编辑和重任务不会随之执行。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [ ] 只保存已应用条件及实际手动图层选择；坐标草稿在当前会话收起时可保留，但不写成已应用恢复值。
- [ ] 日期/坐标/半径恢复后，筛选、地图和轻量结果一致；图层恢复不被普通初始化或默认快捷任务再次覆盖。
- [ ] 等待必要的可用性信息后校验恢复值，处理过期日期、不支持半径、坏格式和资料范围变化，反馈并选合法默认，不伪称恢复成功。
- [ ] 恢复不启动月度/事件/比较、归档准备、在线模型调用或历史任务复算；允许必要的轻量取数。
- [ ] 沿用原有地图视角恢复语义，不能将视图中心误作分析点；存储被禁用/损坏时仍能正常使用和明确降级。
- [ ] 真实浏览器验证应用后重开、未应用后重开、图层手动覆盖、非法/过期值及禁用存储，不引入新的持久化服务。

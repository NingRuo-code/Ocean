## What to build

用户播放逐日地图时，不会无提示地越过整日缺测或未准备资料；暂停后能理解原因并主动继续下一有效日。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [ ] 统一筛选中的播放复用已应用日期和逐日资料状态；按日历处理已知缺日，不把缺失日期从数组中略过后宣称连续播放。
- [ ] 整日缺测或未准备时暂停并显示真实日期和原因；不得沿用上一日观测或填零。
- [ ] 提供用户主动继续下一有效日期/停止的路径；准备入口仅在已有能力且授权时出现，不自动准备归档或重分析。
- [ ] 日内部分缺测说明限制，和整日不可用区分；日期支持不足时说明不能判断连续性，不假定完整日历覆盖。
- [ ] 暂停、手动改日和重复点击播放不会遗留多个计时器；过期取数不恢复已停止播放或跳回旧日。
- [ ] 验证连续就绪、内部缺日、未准备、网络失败、区间边界及播放中手动改条件；保持地图可操作，不以速度基准验收代替。

## What to build

用户在原地图中用 thermal 色带读温度，必要时主动增强局部，并从常驻图例读懂范围；锋面标签与叠加不会淹没活动关系。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [x] 采用已确认 NCL cmocean_thermal，映射与图例同源，保留来源；固定模式同温同色，不能逐日自动取极值却称固定色标。
- [x] 正式全年域未冻结时，仅对有依据的已知资料范围声明值域及适用版本；无法核实就显示待确认，不把16–33°C样稿域转成全年正式默认。
- [x] 提供手动局部增强与返回固定模式，明确显示当前域；越界和缺测有不同表达，不改变像元查询的真实温度。
- [x] 原位置常驻精简图例显示可见且就绪的温度层、单位与模式，点击可看说明，开关/加载状态同步，不替代左侧图层浮层。
- [x] 审查源分箱、再次分箱、粗细层叠加和透明度造成的色块；保留实际网格、不加平滑插值，也不从分箱源虚构更高精度。
- [x] 默认仅最近/选中锋面保留编号，其他可点选而锋面线保留；叠加活动时海温可淡化并手动恢复，用真实样本检查遮挡与读数一致。

## Implementation status — 2026-10-25

软件实现及本地验收完成，已发布[PR #284](https://github.com/NingRuo-code/Ocean/pull/284)，分支 `codex/ui-scientific-colors`，基线 `8a3def0`。固定温标为62份既有海温导出中实际0.5°C档位的20.5–33°C，限定2024年7—8月及记录的产品版本，非全年域。已通过13项配色浏览器回归、49项完整工具测试、129项地图检查、922项数据检查和四档布局；独立Standards/Spec复核问题均修复。实际SST/锋面使用既有可分发展示样本，活动叠加映射使用明确标注的受控合同；不以它替代#34真实活动域资格。

详见[科学色标实施记录](../../reports/ocean-ui-scientific-colors-implementation-2026-10-25.md)。未同步生产；源0.5°C分档、服务侧再分档和远景LOD的精度改进仍按P0/P1后续任务推进。

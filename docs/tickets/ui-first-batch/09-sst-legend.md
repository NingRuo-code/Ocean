## What to build

用户在原地图中用 thermal 色带读温度，必要时主动增强局部，并从常驻图例读懂范围；锋面标签与叠加不会淹没活动关系。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [ ] 采用已确认 NCL cmocean_thermal，映射与图例同源，保留来源；固定模式同温同色，不能逐日自动取极值却称固定色标。
- [ ] 正式全年域未冻结时，仅对有依据的已知资料范围声明值域及适用版本；无法核实就显示待确认，不把16–33°C样稿域转成全年正式默认。
- [ ] 提供手动局部增强与返回固定模式，明确显示当前域；越界和缺测有不同表达，不改变像元查询的真实温度。
- [ ] 原位置常驻精简图例显示可见且就绪的温度层、单位与模式，点击可看说明，开关/加载状态同步，不替代左侧图层浮层。
- [ ] 审查源分箱、再次分箱、粗细层叠加和透明度造成的色块；保留实际网格、不加平滑插值，也不从分箱源虚构更高精度。
- [ ] 默认仅最近/选中锋面保留编号，其他可点选而锋面线保留；叠加活动时海温可淡化并手动恢复，用真实样本检查遮挡与读数一致。

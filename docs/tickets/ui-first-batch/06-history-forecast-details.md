## What to build

用户从右侧阅读有来源的历史或实验预测，并按需展开详细证据；不把稀疏样例当完整月，也不把规则预测当未来观测。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [x] 历史默认月份入口；有可信汇总才显示月结果，已有稀疏记录保留样例标识，无汇总说明未接入/需准备，不自动启动整月计算。
- [x] 真实支持月/日联动时能从月进入某日并返回原月上下文；尚无数据合同时提供诚实状态，受控完整路径检查不冒充真实月资料验收。
- [x] 历史和预测均优先短分析、关键指标、一张有真实资料支持的主图；无资料不画占位曲线。
- [x] 曲线、逐日表、来源和方法迁入默认收起的底部详情，可打开/收起且地图仍可操作；沿用原有确定性证据，不生成新统计结论。
- [x] 保留的规则预测明确实验/未独立验证、基准日与目标日；只有已有真实观测能进入观测地图，规则推演不能成为未来实况。
- [x] 每份结果携带原日期、地点、半径和可得版本身份；改条件标明待更新，进入页签或展开详情不自动重跑详细计算；历史日期不称今天。

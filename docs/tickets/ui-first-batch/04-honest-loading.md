## What to build

在现有地图中快速切换日期、位置与视野，仍只看到当前身份的资料；能区分缺资料、有效零与网络故障，并进行有限重试。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [ ] 先在现有地图完整流程内收敛必要的请求身份和状态表达；与工作台布局无硬依赖，不为此新增测试专用接口或改研究口径。
- [ ] 切日保留底图、视角、缩放并立即移除旧观测作为当前资料的表达；新日期未就绪时明确加载/缺口，不能旧图配新日期。
- [ ] 日期、位置/半径、视野、服务模式或资料版本变化后，旧响应和旧重试不能覆盖当前适用结果；取消失败也能隔离迟到响应。
- [ ] 区分加载、就绪、有效记录零、无记录/未知覆盖、整日缺测、未准备、权限不足和请求失败；来源不保证完整覆盖时，无记录不变成零，单层失败不抹掉其他就绪层。
- [ ] 临时网络/超时自动重试一次，仍失败可手动重试；确定无资料与权限不足不自动重试；切条件后以当前请求优先。
- [ ] 用真实浏览器配合受控延迟、乱序、错误和空态响应验证合同，保留离线路径与已有服务器协议；不将此项记为性能3/1/2秒或线上权限验收。

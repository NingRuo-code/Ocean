## What to build

从左侧附近锋面入口进入同条件的简明事实结果，左右面板可独立收起，地图始终可探索；同时落实工作台两模块及整体视觉分工。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [ ] 复用已验证的非模态共存切片；记录实际采用提交，不将未合并或未部署的实现记为线上能力。
- [ ] 左侧深色工作台同时保留快捷功能和紧凑 AI；右侧浅色保留当前、历史、预测三入口。AI 证据组织迁到左侧，未接模型明确标识，不产生假答复；其他待接入任务清楚说明状态。
- [ ] 点击附近锋面，右侧当前给一句事实、一个主数值及两至三个辅助指标，距离/方位/水温等仅来自支持资料；移除把握度、推荐评分及大段评分规则，详情也不能恢复其有效结论地位。
- [ ] 左右独立呼出/收起；展开时地图适配剩余桌面空间，真实拖动、滚轮、点选、回中和原平面/球面操作保持可用，焦点与 Escape 不抢地图。
- [ ] 应用已确认左深右浅、冰蓝、细线/切角、Saira 数字及简洁中文。1440/1280和390宽检查可读、可达、无整页横向溢出；小屏两栏默认收起。
- [ ] 内部调整仅收敛本流程需要的入口和共享状态，避免先做整站重构；其他未迁移能力保持可用且不伪装完成。

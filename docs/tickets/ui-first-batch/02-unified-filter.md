## What to build

用户从左侧一次呼出筛选，修改日期、坐标或半径，地图和已有轻量结果使用同一套已应用条件。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [x] 日期、坐标、半径合到独立浮层，原顶部重复筛选移除；浮层不挤占快捷与 AI 正文，不引入第二套条件或全局应用步骤。
- [x] 日期/半径选择沿用即时轻量更新；坐标经原应用或地图设置分析点才生效，未应用编辑不改变当前结果。
- [x] 普通查点、设置分析点、地图视图中心含义分明；坐标输入校验与原地图点选保持一致，半径限已有受支持值。
- [x] 点击地图收起浮层并保留原查点/设置点行为；真实拖动、滚轮和缩放控件不收起；浮层内操作不穿透到地图。
- [x] 会话内关闭再开保留编辑；Escape 关闭当前浮层并按焦点上下文返回入口，地图自身 Escape 仍可用。
- [x] 改条件不启动月度/事件/比较等重任务。数据、地图及已有结果同源，快切的请求竞态由独立加载任务处理。

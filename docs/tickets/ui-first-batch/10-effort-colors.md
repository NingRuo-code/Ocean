## What to build

用户在活动任务中通过跨日统一的浅紫对数标尺阅读地图，并能查询真实小时数、核对当前概况及图例，清楚知道展示的完整性限制。

每项均通过现有浏览器入口验证自己的完整用户流程，按影响运行数据、交互与布局检查；同步更新已被本项改变的旧断言，保留仍适用的地图回归。记录实际结果和代表性截图，不以受控响应证明真实线上覆盖，不提交受限源数据。

## Acceptance criteria

- [ ] 采用已确认 NCL MPL_Purples 反向较亮段；在声明的支持范围内共用跨日期颜色/大小标尺，图面与图例同源，保留来源。
- [ ] 对数只作用于显示，图例明确标识对数与小时单位，读数和范围汇总仍为真实小时数；零值不进入非法对数，不伪装成最小正值。
- [ ] 全年时长域依赖 P0 后续冻结；现阶段只用有依据的限定资料域并明示，不能将0–1000h评审域或逐日自适应当正式跨期标准。
- [ ] 图例随活动可见性及资料状态更新，活动与海温叠加能读清关系，手动图层选择/海温恢复保持有效。
- [ ] 核对同值跨日同映射、大于24小时记录、极值/越界、有效零和未知覆盖。样例或受控响应仅用于合同检查，不充当真实月资料证明。
- [ ] 不以颜色迁移宣称取消旧分位/700点截断或完成远景聚合；当前显示受限则显式提示，完整输入汇总沿用已验收活动概况，后续 U2/P1 全量守恒任务继续保留。

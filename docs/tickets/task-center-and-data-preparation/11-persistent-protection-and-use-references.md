## What to build

本人可保护指定成果，任务运行及共享引用也会自动保护所需产物；保护记录持久，未知引用时保持不删除。

每项沿已确认真实浏览器→实际任务服务/执行进程→持久状态/产物→同身份结果接缝验证自身完整行为，辅助API/数据核对。复用W与P0/P1合同，不另建科学引擎或伪造执行；真实处理、合法已知样例及合成故障分别记证，破坏性故障与清理仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

规格用户故事：35、36、37、39、40、42、43、44、47、49、50。

## Acceptance criteria

- [ ] 在T10产物身份/引用上实现持久保护/使用合同，登记任务运行/待提交占用、有效成果共享依赖及主动保存的案例/报告依赖；不新建完整案例编辑、PDF或分享产品。
- [ ] 任务详情提供本人受控的成果保护标记/状态，后续REPORT可通过同一合同登记引用；主动保存所声明依赖默认受保护，未知依赖不能按普通临时产物处理，不宣称已实现真正REPORT保存交互。
- [ ] 共享产物用稳定身份和权威引用关系判断在用状态，两个任务引用同一产物时取消/释放其中一个不解除另一个保护；必要占用/引用增删在实际任务开始/提交/终结路径保持一致。
- [ ] 保护/引用与未来清理有一致的原子登记/使用锁定合同，清理不能依据陈旧列表跨过新保护；会话或进程重启不丢保护，信息无法核实或引用未知默认不删。
- [ ] 所有保护操作及内部引用读取由服务端核本人/归属，访客不能加减私人保护或获取任务条件；保护状态不自动公开成果、不保留原本无许可访问的数据。
- [ ] 真实浏览器与实际持久服务核对保护后重开、任务执行引用、两个共享引用释放其一、未知/损坏保护信息及越权；用合法聚合样例模拟未来案例/报告依赖并明确标注，实际REPORT集成留后续验收。

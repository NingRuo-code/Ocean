## What to build

本人从工作台呼出可分页筛选的任务历史，查看原条件、状态、尝试和已有结果；关闭详情可继续地图，读取不重跑。

每项沿已确认真实浏览器→实际任务服务/执行进程→持久状态/产物→同身份结果接缝验证自身完整行为，辅助API/数据核对。复用W与P0/P1合同，不另建科学引擎或伪造执行；真实处理、合法已知样例及合成故障分别记证，破坏性故障与清理仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

规格用户故事：1、2、3、4、5、6、8、9、36、44、45、47、50。

## Acceptance criteria

- [ ] 沿#100已交付的授权任务记录、最小列表/刷新查询增量提供类型、状态、时间筛选与分页，沿#95布局呼出紧凑历史/详情；不重建#99受理权限、原工作台或新建第二任务数据库。
- [ ] 保留既有任务/意图/尝试/结果身份，原条件、实际类型、受理/核实时间及失败/中断原因可读；缺历史字段标未知，旧加工日志不得伪造为可恢复或已执行产品任务。
- [ ] 选历史只打开原快照/状态，地图筛选、当前任务和旧结果分别保持原语义，收起/刷新不取消或重提交，不新增占满右侧的常驻任务栏。
- [ ] 列表和详情均服务端按本人及归属校验，访客仍可浏览允许公开的就绪地图/结果，但不能枚举私人任务、猜身份取条件/日志；错误及摘要不输出凭据、私人路径或受限底表。
- [ ] 分页/筛选/轮询有界，断网标状态暂不可核实，登录会话失效停止私有读取，不把浏览器状态当任务终态；已有任务在后台继续依其受理授权执行。
- [ ] 真实浏览器核对筛选、翻页、原条件结果、桌面/小屏、键盘/Esc和地图拖缩共存，辅助API核对越权与受理次数不增加；只读历史里程碑不称恢复或准备功能已完成。

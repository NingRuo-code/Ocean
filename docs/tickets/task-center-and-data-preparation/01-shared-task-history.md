每项沿已确认真实浏览器→实际任务服务/执行进程→持久状态/产物→同身份结果接缝验证自身完整行为，辅助API/数据核对。复用W与P0/P1合同，不另建科学引擎或伪造执行；真实处理、合法已知样例及合成故障分别记证，破坏性故障与清理仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

## 实施顺序

#100 已合入。先复用两个现有本人任务存储并增加只读分页、类型、真实状态和日期筛选。再接工作台紧凑历史详情，实际浏览器核查旧结果、当前任务、地图和认证。

读取阶段沿现有任务身份与原条件。使用已有本机合成规范样例，后续准备任务、自动恢复和正式数据走各自票据。

## 本机验证

- 本人分页在原两个存储上进行。类型、真实终态和 UTC 日期可筛选，每页仅回传摘要。页面身份校验发现分页期间新增或变化的记录时，可重新查找第一页。
- 实际 Edge 和同源服务验证两类记录、翻页、中断筛选、原快照阅读和地图缩放。Esc 回到筛选入口并保留当前任务。窄屏无水平溢出。浏览器断网时历史显示暂不可核实，实际服务拒绝授权后清除私人显示。过程中的历史读取没有新增提交。
- 旧时间字段缺失时显示未知。核验使用本机 P0 合成小样及已登记已知单元，独立归档准备、恢复和正式数据继续由对应票据负责。
- 两轴审阅后补充原结果 ID、时区不明时的显示以及失败筛选时的上一页证据标识。实际浏览器先按日期、类型、状态筛选并打开不同类型的已知结果，再移动和缩放地图。验证键盘焦点及 Esc 保留当前任务。
- 最终后端全量 410 项、相关浏览器 50 项、129 项页面交互、四种屏宽、922 项数据检查通过。两轴复审及实际历史场景均完成验证。

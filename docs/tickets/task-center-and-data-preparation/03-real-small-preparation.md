## What to build

本人明确提交已登记的真实小范围资料，经实际提取或加工、校验及版本登记，在浏览器看到具体就绪范围；准备完成不自动分析。

每项沿已确认真实浏览器→实际任务服务/执行进程→持久状态/产物→同身份结果接缝验证自身完整行为，辅助API/数据核对。复用W与P0/P1合同，不另建科学引擎或伪造执行；真实处理、合法已知样例及合成故障分别记证，破坏性故障与清理仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 选择至少一类真实合法且具备实际连接器/本地处理能力的资料，小至一日一层，沿T02计划及#99同一后台受理/执行/只读合同完成明确点击→实际处理→结果；不做虚拟执行器或只生成命令。
- [ ] 本人明确点击合格准备即受理，不弹重复确认卡；服务端复核权限、范围、源/处理版本和保守小范围预算，意图重复发送返回原任务，访客直接调用不能执行。
- [ ] 复用现有提取/加工脚本及P0校验合同，将实际输入完整性、产品/观测日/区域、粒度/单位/缺测与处理身份核对后登记；存在文件或退出成功不能单独证明可复用或就绪。
- [ ] 至少区分提取/处理中、校验、登记、就绪和失败，产物在暂存中校验后经版本化提交点可见，失败半成品不可读，旧就绪版本/成果保持原身份；必要的最小步骤记录和提交适配包含在本项。
- [ ] 就绪说明给实际层/日期/支持和P0用途状态，单层成功不表示AIS或完整月/事件共同资格；受限资料只在合法范围读取，个人准备任务不因地图公开自动发布。
- [ ] 准备期间地图轻量读取和已就绪图层可用，改筛选/收起面板不修改原请求；完成仅提示就绪，不自动发起A/B/C、预测/AI或扩展准备范围，未实现的操作诚实标能力边界。
- [ ] 真实浏览器与实际服务完成至少一个真实合法资料单元，对照独立可核验输出/清单及许可，核对重复点击、错误输入/处理失败和无隐式分析；研究资格、真实准备与合成边界分别记证。

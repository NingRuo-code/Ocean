## What to build

负责人获得可重新操作的任务历史、真实续跑/中断、真实归档就绪与保护清理证据，知道功能和生产容量分别完成到哪里，后续REPORT/AI可复用合同。

每项沿已确认真实浏览器→实际任务服务/执行进程→持久状态/产物→同身份结果接缝验证自身完整行为，辅助API/数据核对。复用W与P0/P1合同，不另建科学引擎或伪造执行；真实处理、合法已知样例及合成故障分别记证，破坏性故障与清理仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

规格用户故事：1、2、5、6、8、9、11、12、13、14、15、16、17、18、19、22、28、29、30、31、32、33、34、35、36、38、39、40、41、43、44、45、46、47、48、49、50。

## Acceptance criteria

- [ ] 从真实浏览器分别回放既有A受控计算与至少一类实际合法小范围准备，经实际任务服务/进程/持久记录到同身份结果；准备包含实际新增与复用单元，研究真实月/事件资格只引用P0/A/B/C证据，不在此造新实证。
- [ ] 隔离环境真实故障覆盖排队、步骤完成后、处理中、校验/发布前后、完成回写前及取消已记录时，核对安全自动续跑、不安全中断、已完成步骤不重做、旧进程写入被拒和无重复发布；模拟HTTP/状态仅是补充。
- [ ] 在统一任务历史核对原条件/版本、尝试/步骤、等待/恢复原因、旧结果读取和明确重试/取消，筛选变更/刷新/会话失效不隐式重建任务；实际后端本人/访客及撤销授权边界可观察。
- [ ] 回放部分准备、P0用途不足、准备完成不自动分析、轻量证据保留、共享引用/主动保护、清理竞态及清理后复算说明；保护示例和实际REPORT集成、无资料与有效零分别记录，地图框架/交互保持可用。
- [ ] 按实际影响运行既有浏览器交互/布局、后端及数据检查，附真实任务/输入/结果身份、处理版本、故障点、独立期望、观察与未核实项；不只交截图或日志success，未真实自动续跑/准备不能建议完整功能通过。
- [ ] 交接同一受理/任务/步骤/恢复能力、授权、产物/保护引用和就绪/P0状态合同，列清REPORT/案例/分享、AI/Q48/Q51、未来预测批任务及生产备份/部署待实现范围，不扩科学算法或新增模型调用。
- [ ] 功能证据可在受控环境独立交付；T14生产容量/保存数值准入单独跟进，未完成则明确未获生产准入，不把其关闭与否当功能结果。整体规格只有全部实际要求满足才建议完整验收。
- [ ] 同步本批进度与残余限制，不修改或关闭#109/#95/#21/#13及P0/P1父级；本轮实现、真实关口、PR、用户合并和部署各留证，未上线不写已上线。

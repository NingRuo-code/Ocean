## What to build

已有清单或确定性查询能读取审计快照中的条件资格，向调用方返回一致的状态、原因和证据，普通读取无需重扫原档。

每项均复用现有显式审计入口，交付可观察报告或可查询的支持结果，并包含自己的自动验证和可复算小例；不把数据结构、读取、API或测试拆成脱节的横向任务。合成夹具与真实资料分开记证，不提交原始 AIS、受限细网格、凭据或私人路径；未执行的检查不填通过。

## Acceptance criteria

- [ ] 优先扩展已有清单/索引/可用性或确定性查询入口，消费同一个审计产物，不新建测试专用接口、AI工具或第二套统计引擎。
- [ ] 返回原请求/实际使用条件、用途、支持等级、各层及共同支持、可用分子分母、原因、缺失前置、证据与版本；未知值不用0代替。
- [ ] 兼容旧调用方，既有ready/available保留其文件级含义并明确不能当research-ready；单层缺失、空态、权限不足和未核实保持语义一致。
- [ ] 公开摘要只投影许可允许内容，不暴露私人路径、地址、凭据或可逆细网格；新的重量审计不开放为访客读取副作用。
- [ ] 重复读取不触发多年扫描、归档准备、下载或详细分析；无快照/过期或扫描中返回可理解状态，不把旧资格当当前。
- [ ] 通过现有FastAPI客户端检查真实请求→快照消费→响应；与显式审计报告及独立期望相符，不以浏览器样式或模拟成功证明线上权限/覆盖。

## What to build

研究者审计某段日期的锋面/SST，能看到真实时间、单位、网格与有效/缺测情况，区分文件存在、成功解析和有效观测。

每项均复用现有显式审计入口，交付可观察报告或可查询的支持结果，并包含自己的自动验证和可复算小例；不把数据结构、读取、API或测试拆成脱节的横向任务。合成夹具与真实资料分开记证，不提交原始 AIS、受限细网格、凭据或私人路径；未执行的检查不填通过。

## Acceptance criteria

- [ ] 通过同一审计入口输出逐层逐日条目和证据，核对文件名、内容日期及时间坐标；多日/多时次文件按产品日界处理，不直接套用界面时区。
- [ ] 核对实际坐标、步长、格中心/格边、声明与实际范围，区分原资料与0.05°展示导出；未证实字段不从默认bbox或粒度提升为事实。
- [ ] SST单位、转换、缩放/偏移、有效范围、填充值及掩码可追溯；启发式单位判断明确标推断，不能作为正式单位一致性证明。
- [ ] 锋面未检出与层缺测分别表达，未知侧别不强行赋冷/暖；不依赖每日F编号具有跨日身份。
- [ ] 输出可用于后续几何的有效支持及其证据，不将非空bbox等同整域有效；坏文件、重复日期、冲突快照和内容错配有具体原因，不静默择一或重复累加。
- [ ] 用可手工核对样本验证时间错配、跨日、多日文件、单位/填充值和有效掩码；可获得真实来源时补小范围核对，范围明确，不能冒充完整月审计。

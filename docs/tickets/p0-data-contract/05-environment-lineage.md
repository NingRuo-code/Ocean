## What to build

维护者能比较不同环境的资料与展示产物，分清同版本、不同处理、已知冲突或尚未核实，并定位旧结果的真实来源。

每项均复用现有显式审计入口，交付可观察报告或可查询的支持结果，并包含自己的自动验证和可复算小例；不把数据结构、读取、API或测试拆成脱节的横向任务。合成夹具与真实资料分开记证，不提交原始 AIS、受限细网格、凭据或私人路径；未执行的检查不填通过。

## Acceptance criteria

- [x] 比较同一来源登记下本地、离线导出和服务器可取得的快照证据，输出匹配/不同/未知及字段原因，而非以名称、文件数或健康正常判一致。
- [x] 部署提交、数据快照、处理与聚合版本分开；服务器未提供身份时记录未知，不能推断部署提交或用当前代码填补旧结果身份。
- [x] 内容证据、可靠校验及源到产物关系可追踪；大小/修改时间仅作变化线索，不单独证明相同；动态latest保留取得快照和时间。
- [x] 保留源/展示/预计算角色，暴露粒度、日期、单位、汇总和许可来源冲突；不将旧事件表当作任意固定区或后7日资料。
- [x] 不要求先获得全部服务器权限才实现比较；先用独立快照验证逻辑，实际不可访问环境保留未核实和解除条件，不虚构真实一致性。
- [x] 报告脱敏可公开，内部定位不外泄；独立样本验证同内容不同路径、内容不同但相同名称/大小、旧版本及身份缺失。

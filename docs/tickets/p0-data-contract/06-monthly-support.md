## What to build

研究者提交地点、半径、月份和分析用途，得到全日历台账与支持等级，明确A月分析和B前后窗口分别能否开展。

每项均复用现有显式审计入口，交付可观察报告或可查询的支持结果，并包含自己的自动验证和可复算小例；不把数据结构、读取、API或测试拆成脱节的横向任务。合成夹具与真实资料分开记证，不提交原始 AIS、受限细网格、凭据或私人路径；未执行的检查不填通过。

## Acceptance criteria

- [ ] 统一条件合同包含用途、点/区域、几何、日期/月/窗口、必需层、源与处理/方法/参数版本及质量规则；非法条件拒绝，不静默换月、换点或扩大半径。
- [ ] 逐日列齐月日历，汇总各层和共同支持、有效/未知面积、纳入/排除天数及原因；支持/有限支持/暂不支持/未核实与资料状态分开。
- [ ] 活动—锋面用途按必需层求交，SST等条件按实际用途加入；有限支持只能开放其有证据的显示/描述，不能绕过正式研究质量或粒度门槛。
- [ ] 完整月审计与月研究资格分开；覆盖阈值、边界/容差及规则在来源和小例检查后版本化冻结，缺关键证据不得默认清单完整即通过。
- [ ] B固定区前7日、后1–3日与后1–7日分别核对相邻月份和事件日规则；不移动固定区域，不从后3日推后7日，不将A合格等同B合格。
- [ ] 报告同支持小时、日均/面积时间分母可用性、证据引用和缺失前置；以完整/缺日/内部缺口/可选层缺失/窗口不足等可手算夹具验证，实际首选月保持2024-08，未审计不能声称通过。

## What to build

研究者查看活动审计结果时，能分清真实记录零、无记录、未知覆盖和处理缺省，知道展示资料能否支持所需分析粒度。

每项均复用现有显式审计入口，交付可观察报告或可查询的支持结果，并包含自己的自动验证和可复算小例；不把数据结构、读取、API或测试拆成脱节的横向任务。合成夹具与真实资料分开记证，不提交原始 AIS、受限细网格、凭据或私人路径；未执行的检查不填通过。

## Acceptance criteria

- [ ] 通过同一入口核对活动清单与实际日内容，登记真实小时单位、日期、网格语义和来源；清单有日期不等于日文件已解析或区域覆盖已证实。
- [ ] 显式有限非负0保留来源报告零的身份；缺字段、null、NaN、坏文件、无记录不能经默认0成为有效观测，稀疏未出现格只有明确源语义支持时才解释为该指标零。
- [ ] 区分来源支持域、非空记录范围和未知面积，不用零铺满栅格生成覆盖；多船累计超过24小时不自动判错，负值/非有限值按规则排除并计数。
- [ ] 显式核对0.01°研究目标、现有0.1°展示资料和实际取得真源；字段默认粒度或插值不证明精度达标，ADR差异保留为研究阻塞，不能自动改目标。
- [ ] 核对重复格/日/版本、旧取最大或邻格匹配、源到展示汇总和小时守恒；邻格返回标明匹配位置与偏移，不能冒充目标格观测。无真源可比较时标未核实。
- [ ] 小例覆盖正值、零、未知、异常、重复、缺省和大于24小时；用独立汇总参照验证，报告不一致与影响，不要求本项重建全时段加工链。

## What to build

给定分析点、公里范围和用途，研究者得到该区域实际有效/未知支持及同支持的小时分子、有效面积和不可计算原因，能用小例复算。

每项均复用现有显式审计入口，交付可观察报告或可查询的支持结果，并包含自己的自动验证和可复算小例；不把数据结构、读取、API或测试拆成脱节的横向任务。合成夹具与真实资料分开记证，不提交原始 AIS、受限细网格、凭据或私人路径；未执行的检查不填通过。

## Acceptance criteria

- [ ] 消费已核实的各层支持与值状态，明确区分分析公里圆、地图bbox和锋线缓冲；部分覆盖说明原请求与实际支持，不能悄悄更换中心或把bbox当圆。
- [ ] 地理距离/面积、坐标系、边界包含和数值容差有版本及独立参照；不同纬度网格面积分别计算，陆地、无效及未知支持不计作完整有效海域分母。
- [ ] 格心归属与交叠分摊根据源语义和边界小例比较后冻结；使用分摊时说明格内均匀假设，不伪称知道格内船舶位置。
- [ ] 同一天按该用途必需层共同支持汇总小时与面积；可选SST只在用途需要时加入，不因潜在图层未接入统一阻塞，也不能漏掉必需层。
- [ ] 锋面缓冲重叠去重、嵌套半径不相加，未知侧别保留；总小时、日均和面积时间密度合同分别表达，分母0/未知不输出假零，零基线不输出无穷大或隐式伪计数。
- [ ] 审计小例覆盖海岸、跨覆盖边界、不同纬度、边界格、重叠缓冲和零分母；仅验证合同与数值，不产生正式A/B/C结论，不批准新半径支持。

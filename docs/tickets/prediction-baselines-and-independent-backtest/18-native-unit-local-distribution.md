## What to build

使用者按已登记原生空间单元查看局部预测样例和圆域聚合，系统不会把一个区域常数涂满网格冒充分布。

每项沿真实浏览器显式操作→实际服务/同一受控计算→同身份预测或可读证据验收自己的完整窄切片，自带独立小例/边界检查，辅助API核数值、权限和调用次数，不为测试新建业务入口。开发限合法已知探索资料，最终目标经完整冻结和权限放行后才揭示；软件、真实资料/基线、候选选择、独立实证分开，不提交受限源档/细表、凭据或私人路径。

## Acceptance criteria

- [ ] 在P03/P04标签/特征与P09/P10同一模型实验管线登记原生空间单元配置和服务圆域映射，复用P16阅读/地图，不重建预测或绘图引擎。
- [ ] 原生单元、掩码/边界、单位/时间支持和可服务半径依P0核实，实际输出每个已支持单元的逐提前量结果；区域模型未验证新单元时拒绝，不复制标量或用显示插值造分布。
- [ ] 采用合法已知/探索小范围生成预测分布及正确聚合，密度不直接相加、重叠不双计，概览/明细与单位守恒；缺格/未支持显式空洞，分辨率不超过原生标签精度。
- [ ] 空间配置有独立实验/模型/版本，变更样本或支持须经P05再冻，开发仅探索库，不提前读P19保留目标；本项只验分布软件，不能继承区域模型的独立分数作为空间证明。
- [ ] 实际浏览器与服务用独立小网格H/E、边界圆/缺格和已知预测核图、聚合与图例身份，地图基本交互可用；不等待P17真实标量回放或整东海资料。

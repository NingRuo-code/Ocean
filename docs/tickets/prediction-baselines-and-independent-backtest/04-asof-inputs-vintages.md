## Acceptance criteria

- [ ] 通过实际特征请求→同源样本/特征身份→可读时效清单，记录观测区间、版本/修订、可用证据、获取/加工和签发时刻，标签、事后质量与输入隔离。
- [ ] 只用签发时已可得的相应版本；观测早但修订/发布晚必须拒绝该输入或按冻结归档条件标注，不能把最终重处理档案伪装当时版本。
- [ ] 活动lag和滑窗按日历/可用性定义，保留最大时距、缺日及最近可用时间；不得用最近若干条记录冒充固定日窗、从未来回填或引用B未来响应。
- [ ] 环境/锋面特征限真实已有SST、距离、可判侧别与可知出现/接近历史，未知不是无锋面；不依赖未来几何、事后确认事件锚日、深入生命周期或未取得的预报/强度。
- [ ] 输入质量只来自当时已知信息，目标日覆盖、最终有效样本、匹配成功及误差不得作特征；训练标签在拟合/选择时还须已经可得，不能只核观测日期。
- [ ] 可核历史当时输入与明确假设归档模式同请求显式区分，保存延迟/修订敏感性及未知限制；两模型组时效模式一致，不将归档模型和真实可知基线混比。
- [ ] 独立小例核晚发布/修订、跨日/缺口、目标质量泄漏和未来值，实际服务与浏览器核特征/拒绝状态；记录地点编码可能记忆位置，原生单位/支持与来源版本可追。

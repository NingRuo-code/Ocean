## Acceptance criteria

- [ ] 复用同一基线/特征通路，从训练历史拟合区域季节常态B2，登记季节/年份/窗口、权重/支持和不足策略，仅在真实支持足够时启用，不用最终测试目标建立常态。
- [ ] 主输出保持活动强度，辅助变化相对训练/可知常态定义，单位和分母明确；常态有效正值才算相对变化，零/缺测返回绝对强度与不可定义原因，不造无限增长。
- [ ] 季节/跨年/闰日及可用日期规则在训练/验证选择后冻结，所有提前量/模型共用支持语义；不把锋面出现常态改名活动常态，不以季节增强预设锋面价值。
- [ ] B2不合格或辅助变化不可定义可完成正确禁用行为并说明，但不能计B2真实实验通过；可继续B0/B1及其他核心任务，不让不适用的季节基线成为伪造资料的理由。
- [ ] 浏览器/实际服务以独立小例核训练常态、时效、零分母、少历史和单位，真实季节实验随P08/后续合格资料记证，热点阈值或概率不在本项偷加。

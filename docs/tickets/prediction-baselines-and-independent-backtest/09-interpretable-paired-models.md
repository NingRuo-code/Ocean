## Acceptance criteria

- [ ] 在P05允许的训练/时间验证及P04可知特征上实际拟合简单回归非锋面/加锋面配对，端到端产出预测、诊断及可读验证证据，不只写模型类/论文名称。
- [ ] 分布/有效零、连续非负响应、单位/暴露量与组诊断决定家族/损失；必要时只加一个有依据的加性/含零连续适配候选，不同时承诺Tweedie/两部分/GAM全套，不机械按小时非负选整数计数。
- [ ] 先切分，每折只在训练拟合插补、标准化、编码、特征选择及常态，验证仅应用；非锋面组保留相同活动/时间/SST，不夹带锋面距离/侧别代理泄漏。
- [ ] 配对保持标签/目标ID、其他输入、源/时效、支持、分区和同等验证预算，双方分别合理调参并记录全部尝试/失败，不只优化锋面组或选择性删难样本。
- [ ] 负值/逆变换/裁剪等处理在选择期登记，保存原输出和异常影响，不按测试结果改后处理；首次最终评估用冻结拟合模型，lag更新不等同滚动重训。
- [ ] 复用成熟组件并记录来源、版本、环境、预算及采用/放弃，独立小例核拟合/变换隔离及公平样本，真实模型选择在P14，资料不足不强行建模/输出因果或创新声明。

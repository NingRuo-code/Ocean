## What to build

研究者对固定区域或已登记原生单元生成未来1/2/3日活动标签，能追到真实小时与有效面积，改变未来锋面不会改变目标。

每项沿真实浏览器显式操作→实际服务/同一受控计算→同身份预测或可读证据验收自己的完整窄切片，自带独立小例/边界检查，辅助API核数值、权限和调用次数，不为测试新建业务入口。开发限合法已知探索资料，最终目标经完整冻结和权限放行后才揭示；软件、真实资料/基线、候选选择、独立实证分开，不提交受限源档/细表、凭据或私人路径。

规格用户故事：2、3、5、7、8、15、33、45、48。规格验收追溯：I02.2、I03.1、I03.2、I03.3、I03.4、I03.5、I03.6。

## Acceptance criteria

- [ ] 消费#71合法逐日基础、P0几何/支持及P02用途判定，沿同一受控加工请求输出标签与可读核对表；复用源适配和H/E，不复制A距离引擎。
- [ ] 冻结签发基准/时区日界，逐个映射t+1/t+2/t+3，明确原生单元/固定公里圆和海陆/服务掩码，累计窗另有定义才可作衍生，不混成逐日标签。
- [ ] 标签按活动自身实际有效支持计算H/E，保留H、E、缺失面积/覆盖和单位；零有效、目标缺测/未知及E为零分别表达，不填零或外推全圆域。
- [ ] 检查A交接是否依未来front/SST共同掩码或距离分带裁切；不足时取许可允许的活动用途基础或明确缺前置，不能从已裁切汇总反推原源或直接沿用条件化标签。
- [ ] 目标几何/服务单元与准入规则在揭示前确定，对所有模型相同；禁止依测试值、未来锋面位置/缺测、最终活动峰值选格或改圆域，用未来共同掩码美化历史支持。
- [ ] 登记原生单元到点位/半径的边界和聚合，密度不直接求和、重复半径不相加、显示LOD不作真源；固定区标量不宣称已形成局部分布。
- [ ] 独立小日历/解析几何核日期、H/E、零/缺测/边界及聚合，反事实只改未来锋面位置/缺测时标签与基础目标队列应不变；浏览器真实显示加工/拒绝结果，未有源时不伪造标签。

## Acceptance criteria

- [ ] 消费#139及传递的#120/#122权威引用/实际清理，在新类型真实报告保存/生成中登记完整合法依赖与活动占用，正式可见前提交保护，不重建清理器或只验通用标记。
- [ ] 隔离合法存储中实际执行保存/导出与清理候选的竞争，最终执行重新核权威引用；清理已完成则拒绝缺产物保存或只按合法固定内容重建，保护先成则不能被盲删。
- [ ] 两个案例/不同类型/报告共享依赖时，失败、取消/重试、暂存释放和进程中断不能解除其他有效引用，未知引用/保护失效/空间不足停止危险删除并保留旧成果。
- [ ] 分别描述原源、训练/特征快照/模型、轻量证据、绘图依据与最终文件保留；无需为读文件永久保留全部模型/源，不可得时可读、再生成、运行/复算分开，不自动补源训练。
- [ ] 实际报告版本可查看安全依赖角色、文件/引用状态与恢复缺口，向既有OPS交接声明范围和恢复读取校验；实际备份/空白恢复/生产扩展依OPS后续安排，不添加反向阻塞或声称已做灾备。
- [ ] 浏览器与真实保护/清理进程核各新类型的文件/引用/墓碑/字节、共享/失败/满盘及旧版本读取，真实研究文件、合法已知样例与合成故障分账，不动生产或真实私人源。

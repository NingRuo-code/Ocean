## Acceptance criteria

- [ ] 在RX10冻结遍历、RX21组合与#132长表基础上，从报告实际生成请求到权威任务/限额执行/文件或可读拒绝闭环，复用#133及TASK，不新建队列或全面压测平台。
- [ ] 以受控合法材料实测新增候选/页数、CSV行/字节、图表、内存/暂存/时长及并发对轻读影响，冻结实际生效限额/停止条件，沿既有资源合同登记估计与未知，不套旧P1秒数或服务器购买结论。
- [ ] 超限明确拒绝或由本人选择标明子集，不自动裁成完整报告；活动暂存/保护引用占用计入预算，不能以满盘为由取消保护、删源或自动扩容。
- [ ] 长表重复表头、复杂分层/逐提前量图、负号/区间/图注/来源与页码实际可读，超布局/缺字体/图像/空间失败明确不发布，清单范围与真实成功文件一致。
- [ ] 实际任务可查、刷新、取消/明确重试；取消竞争、响应丢失、旧任务迟到、渲染中断与政策变化不重复发布/覆盖新版本，不能安全恢复就准确中断，原合法文件保留。
- [ ] 真实浏览器配实际生成进程核限额等待/拒绝/释放、地图轻读和独立文件/视觉期望，无科研/准备/训练/模型副作用；仅测新增变化，性能/功能/生产容量分别记证。

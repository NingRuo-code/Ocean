## What to build

使用者选择已支持的环境特征，看到原值、差异和缺项构成的可解释检索顺序，后续响应好坏不会改变结果选择。

每项沿真实浏览器操作→实际服务/同一受控计算→候选、原证据或短窗图示验证自己的完整行为，自带独立已知小例和边界核查；辅助API核数值、身份与权限，不为测试新建业务入口。前期仅开放明确合法探索允许库，真实目录/响应/匹配与合成故障分开记证，不提交受限源档、细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 沿S03实际候选筛选/详情接入真实有据SST、最近锋面关系、可判定侧别等配置，记录定义/单位/支持及采用和未采用特征，不新建统计或形态引擎。
- [ ] 先用固定、可解释的差异顺序和稳定候选身份处理并列；必要综合距离的尺度/权重/缺项规则在探索小例选定并版本化，不直接要求向量库、学习排序或新算法。
- [ ] 必需特征缺失不进入该配置，可选缺项单列信息不足候选，未知不是0或最相似，不能把不同维数的距离分数直接混排；特征不可比说明具体原因。
- [ ] 形态/长度/像元数、方向和强度只在实际字段及尺度可比时启用，温差/梯度称代理，不将现有长度估计当精确形态；未实现特征诚实禁用。
- [ ] 选择/排序只读取环境和已登记事前条件，不使用后窗响应、增强标志、最终效应或显著性；保留选中清单及依据，检索近邻不自动成为B对照或独立样本。
- [ ] 浏览器主展示短理由和关键差别，详细配置按需展开，不呈现身份概率、作业分数/渔场榜单；反向、无明显变化和无响应资料可正常出现。
- [ ] 独立已知特征差异核排序/并列/缺项，再保持特征不变只翻转后续响应验证候选及顺序不变；普通精确筛选作为参照，未有性能瓶颈不增加加速组件。

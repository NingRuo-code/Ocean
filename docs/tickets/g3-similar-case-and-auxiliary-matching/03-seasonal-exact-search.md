## What to build

使用者得到同海域、相近季节的完整有界候选集合，跨年闰日和分页有明确规则，无结果只表示当前库中未找到。

每项沿真实浏览器操作→实际服务/同一受控计算→候选、原证据或短窗图示验证自己的完整行为，自带独立已知小例和边界核查；辅助API核数值、身份与权限，不为测试新建业务入口。前期仅开放明确合法探索允许库，真实目录/响应/匹配与合成故障分开记证，不提交受限源档、细网格、凭据或私人路径。

规格用户故事：2、3、4、5、6、7、8、14、16、17、19、25、45。规格验收追溯：I02.2、I02.3、I02.4、I02.5、I05.1、I05.4。

## Acceptance criteria

- [ ] 浏览器提交版本明确的海域/范围及前后15天季节基线，经实际服务精确筛选；冻结参考日/锚日、跨年环绕、闰日、端点及实际候选日期规则，15天不宣称生态最优。
- [ ] 同海域依可审计范围定义，无法确定明确不支持；公里圆、视野bbox与海域不可混用，不从名称猜测或在空结果时自动跨海域、换半径/扩大年份。
- [ ] 默认候选锚日早于参考日期，识别查询自身事件/结果及重复版本；逐项保留纳入/排除依据与候选类型，结果条数不等于独立事件数。
- [ ] 返回量、扫描与缓存有界，稳定身份处理并列，游标绑定请求和库版本，版本改变要求新查询；不会跨版本漏项/重复或把截断页数当全库总数。
- [ ] 说明实际已索引/允许库的日期海域范围与未知/未准备部分，无候选不写全部历史无相似事件；分页/展开不启动目录加工、A/B或取源。
- [ ] 独立手工日历和候选全集核同海域、窗口两端、跨年/闰日、未来锚日、自身和重复、分页并列及更新失效，真实浏览器核同服务结果与部分/空态。

## What to build

负责人对真实可访问的短窗观测逐日核对候选、分段和歧义，知道哪些关系有依据、哪些不能确定身份。

每项沿真实浏览器操作→实际服务/同一受控计算→候选、原证据或短窗图示验证自己的完整行为，自带独立已知小例和边界核查；辅助API核数值、身份与权限，不为测试新建业务入口。前期仅开放明确合法探索允许库，真实目录/响应/匹配与合成故障分开记证，不提交受限源档、细网格、凭据或私人路径。

规格用户故事：13、27、33、34、35、36、37、38、39、46、47、50。规格验收追溯：I12.3、I12.4。

## Acceptance criteria

- [ ] 选可访问合法且允许揭示的真实连续观测小窗，沿实际本人受控执行→服务结果→浏览器图示/逐日候选完成一次回放，源和提取/算法版本及实际支持可追。
- [ ] 独立核查每天原观测/几何及候选依据，记录可能关联、其他解释、提取边界、分辨率代理和无法判身份，不以匹配分数自己验证自己或强行制造物理身份真值。
- [ ] 核初始锚定、段内候选、歧义、缺观测/无对象与重置状态，地图无误导连线/累计迁移，B原事件/锚日不变；真实未出现的故障仅用明确合成反例补软件边界。
- [ ] 记录真实样例核对范围及未验证类型、阈值依据、观察与不确定，若据核查改方法保留新版本和影响；不宣称全海域身份准确率、校准概率或生命周期成果。
- [ ] 受保护源日/结果不旁路访问，实际接触沿S08登记，资料不足时真实核查关口保持未完成；不自动全档准备/下载、扩大短窗或请求外部模型。
- [ ] 短窗真实证据与S14历史响应检索分别记证，可独立交付，不等待其真实B资料齐备；浏览器截图/原几何依据、服务引用和合法聚合成果足以复查，生产部署另验。

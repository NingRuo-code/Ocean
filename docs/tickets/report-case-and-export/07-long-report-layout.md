每项沿已确认真实浏览器→实际案例/报告服务→冻结内容/保护产物→预览或实际文件接缝验证自己的完整行为，辅助API及独立数值/视觉核对。复用已有结果/任务/许可合同，不另建科学引擎或以文件存在冒充成功；真实A/B/C成果、合法已知样例和合成排版/故障分开，清理/故障仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 沿R06实际PDF/预览链支持长标题/区域名、多页聚合表、跨页重复表头、图号/表号及页码，图注和来源保持关联，不另建通用出版模板平台。
- [ ] 图、表、单位/负号/区间和必要来源/限制在屏幕及纸面均可读，宽表合理分栏/续表而不缩成无法阅读的图片；相同指标标尺/色义保留，PNG单图长标签沿同一图式。
- [ ] 空态、无事件、缺区间/后7不足、C候选/缺项等长说明不得因分页被隐藏或画假数值；合法部分报告与完整报告状态有区别，不把复杂样例声称真实研究。
- [ ] 模板/布局版本更新生成新产物身份，原冻结科学内容与旧PDF不变；字体/图片读取失败、超出已支持布局/渲染预算明确失败/限定输出，不给看似成功的破损文件。
- [ ] 复用实际预览与文件接口，从浏览器对已知长内容生成PDF和PNG并实际渲染检查关键页，核对中文、换页、表头、图注/来源、缺项和页码，附代表性视觉证据。
- [ ] 长文/多区域及故障可用标注合成样例补边界，真实A/B/C文件在各分支另验；不以模板快照或文件存在替代文本/视觉核对，不在本项重做科学计算。

## What to build

实际普通产物清理与保存/导出同时发生时，案例、最终报告和共享依赖保持可读；失败或资料不足有准确状态，不出现缺文件的保存成功。

每项沿已确认真实浏览器→实际案例/报告服务→冻结内容/保护产物→预览或实际文件接缝验证自己的完整行为，辅助API及独立数值/视觉核对。复用已有结果/任务/许可合同，不另建科学引擎或以文件存在冒充成功；真实A/B/C成果、合法已知样例和合成排版/故障分开，清理/故障仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 把R02已具备的保存/保护一致性和R08实际导出接入#122真实清理合同，不重建TASK清理器；验证正式REPORT案例/文件引用，不以TASK保护标记样例代替本项业务集成。
- [ ] 正式案例/报告可见前保护其声明依赖，活动导出占用与清理使用同一权威锁定/引用规则；候选预览后新保护不能被盲删，清理先完成则保存需明确缺产物/按合法冻结内容重建，不能报假成功。
- [ ] 两个案例/任务共享产物，保存失败、取消导出或释放暂存不能解除其他有效保护；进程中断/响应丢失后按同意图对账，旧成功版本/文件保留，失败未提交记录不可下载。
- [ ] 普通大中间物清理后，轻量证据/案例版本/结果身份及受保护最终文件仍合法可读，物理缺失、新鲜度、许可与原样复算分别说明；读旧结果/重排版不自动取源或重分析。
- [ ] 空间/保护服务不足时拒绝新保存/生成并保留旧成果，不自动取消保护、扩盘或删源；仅本人受控操作和逐源许可有效，不保证全部源永久存在或可撤回已外发文件。
- [ ] 在隔离合法测试存储用实际服务/清理进程，从浏览器核保存/导出与清理竞争、共享引用、重启、保护失败、满盘和普通产物释放；核真实文件/引用/墓碑与原条件，不碰真实私有源或生产资料。

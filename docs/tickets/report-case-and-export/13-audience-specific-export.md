## What to build

本人明确选择内部受控或允许对外分享用途时，得到对应合法内容的导出；许可不支持就拒绝或说明合法部分，私人案例不会自动公开。

每项沿已确认真实浏览器→实际案例/报告服务→冻结内容/保护产物→预览或实际文件接缝验证自己的完整行为，辅助API及独立数值/视觉核对。复用已有结果/任务/许可合同，不另建科学引擎或以文件存在冒充成功；真实A/B/C成果、合法已知样例和合成排版/故障分开，清理/故障仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 在各项已具备的权限/字段边界上增量提供明确导出用途投影和可读差异，内部保存/读取、允许本地导出、对外分享及公开展示分别核验；不是等本项才补最基本服务端授权。
- [ ] 服务端逐源及各字段核实际许可/归属，C含私人来源时不能用一项公开授权投影整份；许可未知/撤销拒绝相应输出或只产生明确合法部分，不凭研究用途自动扩大权利。
- [ ] 用途投影纳入内容/产物身份和复用条件，不能把旧内部PDF/缓存当外部分享文件；生成时与下载时核当前权限，物理保留或保护标记不等于有权公开。
- [ ] 用途改变不得手改科学值或隐去被选结论必要的来源/限制，合法删减注明实际范围/未提供内容；人工笔记按所选版本/用途明确包含与否，未选笔记不能经附件/元信息混出。
- [ ] 实际检查PDF正文/图片/表/书签/链接/可控元信息、PNG、CSV和清单不含受限细表、源路径/凭据或工作目录；文件命名安全可辨版本，不能从任意用户路径读取附件。
- [ ] 通过真实服务/浏览器对已存合法A/C报告验证本人/访客、混合私人来源、用途变化、旧文件复用、授权撤销与直接文件地址，打开实际文件逐项核投影；下载不发布网站、创建分享链接或向外发送。

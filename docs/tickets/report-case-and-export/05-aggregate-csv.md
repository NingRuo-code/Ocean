## What to build

本人下载与报告同源的聚合汇总CSV，能在表格工具中核对单位、数值和缺失状态，并定位原结果版本。

每项沿已确认真实浏览器→实际案例/报告服务→冻结内容/保护产物→预览或实际文件接缝验证自己的完整行为，辅助API及独立数值/视觉核对。复用已有结果/任务/许可合同，不另建科学引擎或以文件存在冒充成功；真实A/B/C成果、合法已知样例和合成排版/故障分开，清理/故障仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 沿R02冻结内容实际生成、校验、保护和下载UTF-8聚合CSV，复用A已有合法聚合表，不读原档新计算或把受限逐日细网格/底表伪装为汇总附件。
- [ ] 表保留稳定区域/分组/窗口ID、指标/单位、空间/时间支持、结果/版本引用、来源及缺失状态；真实零、未知/缺测、无区间和不适用分别表达，不统一填0或空值丢语义。
- [ ] 预览舍入与允许聚合原精度分开记录，单位转换可核对，不按显示小数制造更高精度；原值与图表/摘要在既有容差内同源，不把不同范围总小时当可比密度。
- [ ] 实际下载按本人归属及逐源允许字段检查，内部读取成功不自动批准对外用途；导出只含选定合法内容，不含私人笔记、源路径、凭据、临时目录或可逆源数据。
- [ ] 产物绑定精确内容与表格/格式版本，完成校验后可取且按主动保存成果保护；重复读取不重新生成研究，失败不覆盖旧CSV，编码/转义保证文本、中文及字段边界可正确读取。
- [ ] 真实浏览器下载实际CSV并重新解析，用独立已知聚合值核列、单位、精度、零/缺测、长文本/中文及身份，核对与页面一致且无隐藏重算；真实A文件消费在R09另记。

## What to build

本人按标题、标签、类型和时间查找案例，修改笔记或关联新结果时生成明确新版本，旧版本仍可读取且并发修改不会静默覆盖。

每项沿已确认真实浏览器→实际案例/报告服务→冻结内容/保护产物→预览或实际文件接缝验证自己的完整行为，辅助API及独立数值/视觉核对。复用已有结果/任务/许可合同，不另建科学引擎或以文件存在冒充成功；真实A/B/C成果、合法已知样例和合成排版/故障分开，清理/故障仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

规格用户故事：2、4、5、6、7、8、9、22、25、26、36、38、39、42、46、49。

## Acceptance criteria

- [ ] 在R02实际案例服务/界面上增量提供有界检索/分页、版本列表与版本选择，不复制TASK任务历史数据库；结果/案例/版本身份分别表达，同名案例不串用。
- [ ] 标题、标签、笔记、所选章节或关联结果变化形成明确新版本，旧科学内容/证据不可变；新结果沿同一合法保存/保护合同登记，不因改名、换模板或生成时间冒充重新分析。
- [ ] 版本更新按原版本校验并发冲突，重复保存意图仍幂等；冲突清楚提示保留的旧/新版本，不静默覆盖或手工修改科学数值，失败不丢已有保护。
- [ ] 人工笔记标明角色及保存时间，按文本安全排版，不执行HTML/脚本或指挥渲染器取任意资源；筛选变化不改笔记所属结果，未选笔记不混入其他版本。
- [ ] 查看旧版本和按原聚合内容预览不自动复算；原源不可得/新鲜度未知分别标示，重新研究是独立本人显式请求，不能原样时说明而非换源覆盖。
- [ ] 真实浏览器核检索/分页、重名/长标题、版本重开、并发修改、响应丢失、源变化与权限；独立核对原条件/内容未变及无研究/归档/AI调用，个人内容不因版本列表公开。

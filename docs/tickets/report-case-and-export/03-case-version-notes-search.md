每项沿已确认真实浏览器→实际案例/报告服务→冻结内容/保护产物→预览或实际文件接缝验证自己的完整行为，辅助API及独立数值/视觉核对。复用已有结果/任务/许可合同，不另建科学引擎或以文件存在冒充成功；真实A/B/C成果、合法已知样例和合成排版/故障分开，清理/故障仅在隔离受控材料验证，不提交受限源档、细网格、凭据或私人路径。

## Acceptance criteria

- [x] 在R02实际案例服务/界面上增量提供有界检索/分页、版本列表与版本选择，不复制TASK任务历史数据库；结果/案例/版本身份分别表达，同名案例不串用。
- [x] 标题、标签、笔记、所选章节或关联结果变化形成明确新版本，旧科学内容/证据不可变；新结果沿同一合法保存/保护合同登记，不因改名、换模板或生成时间冒充重新分析。
- [x] 版本更新按原版本校验并发冲突，重复保存意图仍幂等；冲突清楚提示保留的旧/新版本，不静默覆盖或手工修改科学数值，失败不丢已有保护。
- [x] 人工笔记标明角色及保存时间，按文本安全排版，不执行HTML/脚本或指挥渲染器取任意资源；筛选变化不改笔记所属结果，未选笔记不混入其他版本。
- [x] 查看旧版本和按原聚合内容预览不自动复算；原源不可得/新鲜度未知分别标示，重新研究是独立本人显式请求，不能原样时说明而非换源覆盖。
- [x] 真实浏览器核检索/分页、重名/长标题、版本重开、并发修改、响应丢失、源变化与权限；独立核对原条件/内容未变及无研究/归档/AI调用，个人内容不因版本列表公开。

## 本机实现与验收

- 本人目录沿既有案例库，在标题、标签、类型和 UTC 保存日期下每页八项。同名记录按案例身份打开，翻页固定本次目录身份。目录和筛选变化清除上一页，再从第一页重查。
- 新版本可修改笔记、章节或明确关联另一份已核实的 CC0 预览。服务端校验原版本和新报告原身份，将新版本及其引用一起持久化。旧版本的原结果、内容、笔记和保护仍可读。
- 浏览器验证同名长标题及 64 个案例分八页、类型和日期筛选、新报告绑定、自选章节、旧版本、并发编辑及回执丢失。隔离环境从仍存在的公开目录中移除原快照，或移除隔离目录后，旧版本继续展示冻结内容。页面区分原快照不可取得和底层来源新鲜度未知。
- 此项仍使用合成结果。所选章节用于案例预览，章节组合导出沿 R12 独立验收。

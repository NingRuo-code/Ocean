## Acceptance criteria

- [ ] 扩展R06实际导出任务，复用#101/#102及已传递的W受理/持久状态合同，注册导出类型的有界执行与操作能力，不另建任务中心、资格或队列平台。
- [ ] 幂等意图绑定案例/结果版本、章节/用途、模板/渲染配置，重复点击/响应丢失先核原任务；已存在合法同身份完成文件可复用，模板/内容变化建立新产物不覆盖旧版。
- [ ] 取消必须服务端在实际安全阶段生效，区分请求中、已取消、完成来不及取消；明确重试保留原记录及新尝试，源资料不足不得由导出自动重算/准备。
- [ ] 渲染中断按真实阶段能力登记，不能安全继续就中断后明确重试，不假称任意PDF可断点续跑；半成品/失败文件不可下载，已完整校验发布的旧成果仍受保护。
- [ ] 晚到响应/重试依据任务和内容/产物身份隔离，切换案例版本后不把旧PDF放到新版本下载按钮下；活动导出/暂存占用和最终文件保护沿TASK合同，地图轻读不被长生成阻塞。
- [ ] 服务端核本人、任务归属及当前文件/用途权限，访客不能新建/取消/重试私人导出；真实浏览器配实际渲染进程验证延迟、失败、断网刷新、重复提交、取消竞争和明确重试，独立核实际次数和文件身份。

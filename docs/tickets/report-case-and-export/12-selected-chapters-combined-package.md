## Acceptance criteria

- [ ] 扩展已有各单类包/统一内容实现多结果明确选章、顺序与详细程度，案例新版本记录每项精确结果/条件、选项和人工笔记；A/B/C既有单类导出保持独立，不为组合重建计算或格式引擎。
- [ ] 不同条件/用途分别成章并标原时间/区域/单位，相关支持衍生用原身份，REPORT不得新增跨区差值、平均区间或综合分数，不能因选章筛掉反向结果或缺失候选。
- [ ] 被选结论的来源、支持、区间/缺失原因及研究边界强制随章保留；精简只减细节，不能关闭全部局限后仍保留同一结论，某章节缺能力/产物须明确拒绝或标部分包。
- [ ] PDF/PNG/CSV及包清单均绑定同一所选内容/案例版本和允许用途，清单列成功文件、未提供项/原因、模板/渲染身份、校验与安全复算/引用，不夹带工作目录或临时文件。
- [ ] 成果包实际装配/下载和必要耗时任务沿R08，完成文件均校验/保护后原子发布；单一格式失败不伪报整包完整，旧有效包与案例不被新失败覆盖。
- [ ] 真实浏览器以已有真实A/B/C成果选择/换序/精简章节生成包，逐文件解包核身份/数值/限制和图表清晰度；长文/部分失败补合成，普通读取/组合仅排版不启动分析或模型。

## Acceptance criteria

- [ ] 消费R04冻结地图/图表及R02同一报告内容，复用现有可用HTML/报告排版基础，实际渲染、校验、保护并提供PDF下载；不能只提示系统打印、把HTML改后缀或用旧报告重新计算源数据。
- [ ] 文档包含目的/事实摘要、原年月/区域/公里范围、H/E与单位、主图/聚合表、方法/对照/来源/版本/局限，中文字体和基本页码/图表编号正确，零/缺测/无明显关系状态如实呈现。
- [ ] 报告内容身份与PDF产物身份分开，产物记录模板/渲染器、字体/区域设置和生成时间及校验值；重新排版不伪造新分析结果，不要求不同渲染环境文件逐字节相同。
- [ ] 本人权限和逐源允许内容在生成/取文件时核验，图片/链接只用已批准冻结资源，不访问任意外部资源；正文、书签/附件和可控元信息不暴露私人路径/凭据/受限表。
- [ ] 小型生成有界执行，耗时部分沿既有实际任务受理/状态路径而非阻塞地图；完成渲染/完整性/身份校验并保护后才原子提供下载，渲染失败、字体缺失或空间不足不报成功，不覆盖旧文件。
- [ ] 真实浏览器生成和下载后实际打开PDF、提取文本/表并渲染代表页，核对中文、单位/负号、图例/来源及数值与原内容一致；基础合法小例先验，长表能力在R07、真实A整链在R09。

现有本人合成月任务在选项、提交预检及事务中重新核源时，要求登记的许可标识精确为 `CC0-1.0`，可保留分号后的说明。拼写含同一前缀但未登记的许可不得接受。已用实际服务和临时任务库复现：`CC0-1.0-unverified` 曾返回成功，修正后拒绝，且未创建任务库。原已登记合成样例、同意图重放和历史读取规则不变。此验证不接入正式 A，不替代真实 P0 证据、用途许可或生产权限。

## 冻结 P0 与本人持久受理的本机接口

现有本人任务 POST 支持显式的 `monthly_distance_reference`，同时要求输入 SHA-256、固定条件和 P0 快照；沿用现有月资格及距离计算引擎。受理前、事务执行前及发布前重核资格、输入和执行环境；校验失败不保存该意图的结果。合成距离记录保留资格绑定和原引擎结果身份，当前源或快照撤下仍可读、可重放原意图；新意图必须重新通过资格。

距离任务必须显式配置独立的 `OCEAN_QUALIFIED_DISTANCE_RUN_STORE_PATH`，默认关闭，不可指向旧合成任务库。距离库身份与旧库不同，保留旧版本读取原库的路径。距离计算有 25 秒子进程预算，数据库写锁最多等待 32 秒；同目的的重复意图等到原记录提交后可原样重放，超过等待预算仍可显式重试。不伪造排队或受理状态。新记录写入前使用回读的同一验证规则。

距离任务使用独立并发额度，每个服务进程同时最多两个执行或等待同意图重放的请求。与普通读取共用的线程继续处理轻量查询。限制普通读取只剩一个可用线程时，实测距离子进程仍在运行期间，普通只读选项请求可完成；修复前同一测试超时。

原合成任务目录和导出保持原合同；用 `?purpose=monthly_distance_reference` 明确读取距离目录、记录或提交意图。同一意图的幂等范围是所选用途。正式 A 提交和生产接入仍待完成。此步不改变只读演示、研究批准或暂缓项。

定向回归验证了原引擎结果 ID、月汇总及逐日值一致、同意图重放、源撤回后拒绝新意图并保留历史、旧库并行写入，以及损坏输出回滚。真实浏览器以实际本机服务回归了既有合成任务提交和回读。

## 本机浏览器的 P0 合成距离参照

通过既有「本人合成小例任务」选中「P0 合成距离参照」。同源服务上的本人令牌用于只读核对草稿。只读预检检查登记几何、P0 快照、合成输入指纹和环境，给出候选条件，不启动计算或建立任务库。明确提交后才运行原距离引擎，服务重新核对受理条件。界面展示原任务、快照、共同支持月汇总、距离分带和逐日证据。合成距离参照与已知单元分别保留各自的历史和本地任务引用。

真实浏览器与本机 API 联合校验一击提交、双击不新增、已知 0 值、切换任务类型清除旧展示、登记几何 ID 变化及输入撤下时拦截新任务、含海温历史和实际计算失败回读。距离预检与提交共用每个服务进程的两个名额。满额时新提交立即返回 503 和重试提示。已有终态的同意图可直接重放，历史、意图查询和普通轻量读取仍可用。请求直接取消时，计算仍持有名额至实际返回。正式 A 所需的源和研究资格仍按原有流程核验。

## 资格变化与中止记录

#99 的同一个任务入口核对两个时点。计算开始前条件失效时拒绝新意图。计算开始后资格或执行输入无法再核实时，中止原尝试，只保存原意图、原资格和中止原因。失败记录既可通过意图查询，也可按原任务回读，复读不再计算。完整和半成品都不得发布。

计算超过 25 秒子进程预算时保存单独的超时原因，资格变化或不可核验时优先保存中止原因；同一意图重复提交只读取已存终态。真实浏览器与实际服务用 P0 合成小样验证关闭面板、撤回资格、再次认证及查回同一尝试，只有一次提交。

原因使用兼容的 failure_reason 字段，原失败状态和错误码继续符合上一版读取合同。服务进程中断和恢复沿 #100 验证。

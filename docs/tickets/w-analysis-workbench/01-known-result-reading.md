## Acceptance criteria

- [ ] 沿用#30已交付的历史/底部阅读和#25传递包含的非模态双侧框架，增量接入最小A结果读取适配及明确来源的合法已知样例；不复制UI布局、另建测试专用业务服务或先做整站重构。
- [ ] 入口以“月度空间关系”等简短中文说明用途，B/C分别显示待接入原因；保留左侧快捷和紧凑AI两个模块、独立筛选/图层浮层、右侧当前/历史/预测，不新增宽大常驻统计栏或AI右标签。
- [ ] 从实际只读服务或既有合法离线结果读取明确结果身份，显示原年月、固定点/公里范围、样例/真实身份与来源；本项已知样例不声称真实A交接或整月研究通过。
- [ ] 右侧默认少量关键数字和短分析，底部默认收起；图、表、摘要和允许聚合下载来自同一快照，零值、未知、缺测及无区间分别表达，不给评分、排名、渔获或因果保证。
- [ ] 普通读取、打开详情或切页签不触发A/B/C、归档准备、下载源档或模型调用；缺结果/能力/服务时给真实说明，不画占位曲线、模拟排队或借旧历史频次假称A。
- [ ] 只消费逐项允许公开的聚合样例或现有授权成果；权限未知不公开，私有结果服务端拒绝，样例不含受限细网格、私人路径或可重建底表。
- [ ] 通过真实浏览器打开/收起、键盘/Esc和桌面/小屏操作核对摘要→底部证据与真实请求，证明地图拖缩/选点可用；用独立已知值检查显示和只读无重任务副作用。

## Acceptance criteria

- [ ] 在W05实际任务路径中接入真实服务端取消，排队任务可撤回，运行任务在可验证安全阶段协作停止；必要最小计算阶段/取消适配随本项完成，不能只停止浏览器等待或做测试专用执行器。
- [ ] 任务状态区分取消请求中、已取消、完成、失败/中断与当前阶段不支持取消；只有服务端确认停止才显示已取消，没有取消能力明确欠缺，不报假成功或勾完整W完成。
- [ ] 取消与完成竞争遵循权威终态和发布顺序：已完整发布的有效结果保留且说明来不及取消，已取消不发布后续半成品，重复取消不反复修改已终结任务。
- [ ] 服务端验证本人和任务归属，访客/失效授权不可取消，不能借猜测任务身份得到私人条件；取消不删除此前有效成果或切换当前地图/结果。
- [ ] 旧任务迟到状态/结果依据任务和结果身份隔离，切换新条件、新任务或旧详情后不会串入；收起工作台、关闭详情及取消只读请求均不自动取消分析。
- [ ] 通过实际服务运行可控规模A计算，在受理、执行安全点及完成竞争阶段从真实浏览器发出取消；核对工作确实停止/拒绝、原记录与产物、重复取消和越权行为，合成延迟仅辅助竞态验证。

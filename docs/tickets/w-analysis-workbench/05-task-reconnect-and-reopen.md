## What to build

本人关闭面板、刷新或断网后能重新找到已受理任务及原条件，恢复原任务查询而不重跑；状态无法核实时明确提示，不长期假装正在执行。

每项沿已确认真实浏览器→受控服务→任务/结果→同源证据接缝验证自己的可观察行为，并辅助API核对。复用#24及A/B/C确定性合同，不另建科学引擎或伪造执行状态；真实资料、合法已知样例和合成故障分别记证，不提交受限源档、细网格、凭据或私人路径。

规格用户故事：19、20、21、22、23、24、29、30、31、43、44、45、48。

## Acceptance criteria

- [ ] 扩展W04实际任务查询与最小任务列表/引用，刷新、关闭页面再打开或切换视图后从授权持久记录找到原任务，不把浏览器本地引用当权威状态，不引入完整任务历史产品。
- [ ] 复用#31已应用筛选/图层恢复，当前地图条件和历史任务原条件分别呈现；恢复偏好或任务引用只做轻量查询，不能自动重建分析意图，存储禁用/损坏仍可通过授权服务找回任务。
- [ ] 提交响应丢失时保留意图身份并向服务核实；只有明确拒绝/未受理证据才允许按清楚状态操作，不盲目新建任务。恢复网络后查同一任务，不因超时转失败或自动重试重计算。
- [ ] 断网/服务不可达显示状态暂不可核实并保留最后核实状态和原条件，真实失败/中断另列；关闭工作台不取消任务，迟到消息不切换当前选中结果。
- [ ] 轮询采用有界频率与退避，面板隐藏/授权失效时停止不必要订阅，重新打开再查权威状态；不重复注册轮询或由长任务堵塞地图读取，不把轮询开始当计算运行。
- [ ] 服务进程退出后无法确认继续执行的持久记录要通过实际存活/中断判定变为中断或暂不可核实，不永远停在运行；真实中断不能发布部分结果。自动安全续跑、跨重启恢复步骤仍留公共TASK专项，未实现不宣称Q49通过。
- [ ] 真实浏览器配实际服务验证提交超时、面板关闭、刷新、断网重连、存储损坏、授权过期和受控服务中断，核对原任务ID、受理数、地图可操作及无自动重分析；模拟故障与实际服务观察分开记录。

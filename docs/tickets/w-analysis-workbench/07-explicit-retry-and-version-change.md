## Acceptance criteria

- [ ] 沿W05实际失败/中断记录提供本人显式重试，保留原请求、原因、已知版本和旧成果；新尝试有独立任务/意图身份并可追溯父尝试，状态读取、网络自动重连或恢复偏好不得重启计算。
- [ ] 重试前复用已有A/P0资格与版本核对，冻结输入仍合法可得才称原条件重试；当前源替换、身份未知、权限失效或资料清理时明确原因和所需前置，不拿新源伪装原结果。
- [ ] 本人主动选择按当前源或新条件提交时，以明确新请求记录条件/版本变化及与旧任务关系，不悄悄更换月份、范围、主方案或调用归档准备；无需重跑时可先查看已有合法成果。
- [ ] 同一重试意图双击/发送超时仍幂等，同一旧任务允许多个明确尝试但不能由自动重试无限扩增；已运行任务状态不明先核实，不能直接并行复制昂贵任务。
- [ ] 新失败/中断不覆盖旧成功快照，部分写入不可发布；仅当前明确选中且适用身份匹配的结果可刷新摘要，失败任务和新结果各有原条件。
- [ ] 服务端复核本人及任务归属，访客不能重试或通过读取触发；用真实浏览器与受控服务错误、原输入重试、同路径换源、资格过期及响应丢失核对实际次数和关联身份，独立检查结果与无隐藏任务。

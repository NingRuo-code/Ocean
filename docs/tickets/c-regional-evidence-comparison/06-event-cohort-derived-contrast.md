## What to build

研究者在已有B合同支持下明确限定事件队列或窗口政策，得到可追溯的衍生事件摘要与描述差值；没有事件对应、细量或合格对照时只保留受限并列及所需B前置。

每项贯通显式确定性/受控请求、既有快照消费或同合同组合到可读结果/证据，并在本项核对独立小例与边界。复用A/B/P0基础，不新建测试专用业务接口或第二科学计算引擎；真实资格、真实比较与合成验证分开记证，不提交原始AIS、受限细网格、凭据或私人路径。

规格用户故事：15、16、20、21、22、23、24、25、27、28、29、30。

## Acceptance criteria

- [ ] 按显式登记的搜索期/窗口/队列与既有B合同操作已就绪合法基础量，保留原/新事件成员、绝对日期、相关组、支持与排除；原结果不被重标为新队列。
- [ ] 不同区域相对日一致不构成配对，只有已有合同给出配对目标/日期/支持时才使用；不能为C新识别事件、选低活动对照、按活动效果配对或隐式调用B重任务。
- [ ] 沿B既有目标量/权重和H/E合同形成限定摘要，不混事件等权均差与合并密度；后1–3和后1–7分别保留资格、真实支持及共同/不同队列，不补后7。
- [ ] 仅兼容的同指标、同单位和同窗口给明确方向的描述差值，相对值只对正有效基线；对照域/匹配、未匹配、共享日/区域/对照和独立组限制随结果保留。
- [ ] 改变队列、支持或权重后不沿用旧区间/p值，不靠两区原区间推导新检验；需要新匹配/联合推断或源读取时给B任务前置，不扩展正式跨区域检验引擎。
- [ ] 政策及衍生身份在真实计算前冻结，不按增强/显著筛选事件；资料不足只描述或拒绝该项差值，不删候选、不填无响应、不引入综合排名。
- [ ] 通过显式入口以不同锚日、缺对应/细量、不同队列、失配对照、零基线与共享组小例，独立核对新成员/H/E/描述值/区间失效及B前置；分支不阻塞C05月度增强。

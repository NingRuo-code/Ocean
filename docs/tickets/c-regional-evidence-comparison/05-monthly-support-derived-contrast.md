## What to build

研究者明确选择共同日期/分组政策后，复用A已有可加基础量取得带新身份的限定支持结果，计算口径一致的区域甲减乙；不具备合法基础量时返回重算前置。

每项贯通显式确定性/受控请求、既有快照消费或同合同组合到可读结果/证据，并在本项核对独立小例与边界。复用A/B/P0基础，不新建测试专用业务接口或第二科学计算引擎；真实资格、真实比较与合成验证分开记证，不提交原始AIS、受限细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 默认原月结果不裁切；只有本次显式请求已登记共同日期/分组/标准化政策才产生衍生结果，保留源结果和原/新年月日支持、各区H/E、排除与目标量，不重新标注原完整月快照。
- [ ] 调用A既有可加汇总合同在各自固定区域上重聚合，不做跨异地空间交集，不新增原档读取或地理引擎；只有许可允许且已就绪的底量能用，缺细支持返回对应A任务前置。
- [ ] 按冻结分子分母求新密度/描述值，支持差异不可判断或过少则受限；分组仅在已有细量足以精确组合时对齐，不按粗组比例猜分布、不细分伪造精度。
- [ ] 仅兼容且单位/估计量一致时给显式选定方向的甲减乙，保留双方值/单位/H/E及比较依据；比值/相对差仅正有效基线，零/未知不加伪计数或填无穷。
- [ ] 变化后的支持/权重/目标量不得沿用原区间或p值，标明区间尚未针对新目标计算与A前置；不取现有区间端点差、是否重叠或p值大小宣称新区域显著差。
- [ ] 政策、单位转换、差值方向及容差在真实比较前冻结，改动产生新身份，不按区域胜出挑日期；无差异、反向或受限均保留，不生成评分/推荐。
- [ ] 以不等日期、不等面积、可精确组合/不可细分组、零基线、未知和原区间失效小例，从显式请求到衍生表/差值独立核对H/E、身份及缺前置，不重复A科学引擎。

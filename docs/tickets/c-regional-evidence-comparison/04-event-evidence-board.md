## What to build

研究者在同一搜索期和事件/窗口定义下并列各区域B响应、对照质量、实际事件样本与区间，清楚知道哪些后7或对照证据缺失，不把相对日一致当同日成对事件。

每项贯通显式确定性/受控请求、既有快照消费或同合同组合到可读结果/证据，并在本项核对独立小例与边界。复用A/B/P0基础，不新建测试专用业务接口或第二科学计算引擎；真实资格、真实比较与合成验证分开记证，不提交原始AIS、受限细网格、凭据或私人路径。

## Acceptance criteria

- [ ] 直接消费B/#84固定区事件和结果合同，读取精确身份、资格、实际搜索/读取期、几何和规则，不重识别锋面事件、不新建匹配或推断引擎。
- [ ] 核对进入/锚日/合并/缺口、前7/0/后1–3/真实后1–7、固定半径和队列政策；移动缓冲旧表与固定区不混用，短窗可用不冒充后7齐全。
- [ ] 保留各区实际事件日期、成员、持续/再进入、候选/入选/排除；相对日相同不是绝对同日、同一物理锋面或自然成对样本，缺既有对应依据就不强配。
- [ ] 事件等权、合并H/E、个案与总体估计分别命名，同期窗口/支持、同日对照候选域、权重/匹配率、未匹配和未控制因素随比较列明，不按字段同名硬减。
- [ ] 事件数、展开行数、有效日期和独立组分开，重叠区域/窗口、共享日或对照保留关联；不相加当独立样本，不用已有区间重叠与否生成新显著结论。
- [ ] 无事件、观测不足、无合格对照、后7缺失、少组/退化区间和有效零分别呈现，缺一项不否定其他可比指标或生成0响应。
- [ ] 从实际比较入口用同搜索期异锚日、不同窗口/权重/对照质量、共享对照、部分缺后7和无事件夹具核对字段、可比理由及证据来源，真实跨区案例在C09记证。

研究者读取不同区域已就绪的A月度结果，在同一年月/公里范围及兼容规则下并列活动、距离带/侧别、支持及已有区间，并能展开每项来源和限制；无需等待B事件比较。

## Acceptance criteria

- [ ] 直接适配A/#71已验证结果/可加基础量与资格合同，按精确源身份消费各候选，不重算源档、重建A空间统计或把旧单点锋面频次改名为月度活动比较。

- [ ] 月度分布/锋面频次仅作有正确观测分母的背景，活动关系引用A同日配对；同月参照的候选域、匹配/权重和限制清楚，不将不同对照含义强称同一效应。
- [ ] 已有区间按原估计对象、置信水平/方法及失效状态并列，缺区间不造值；每个指标可追到A源结果、逐日支撑和P0资格，合法公开聚合与内部细表分离。
- [ ] 通过C实际入口验证A适配、距离/侧别差异、可选层缺失和受限结果，以独立已知快照及已验收源消费核对值/支持；本板可单独验收，真实两区案例在C09最终记证。

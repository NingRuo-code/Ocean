## What to build

使用者在每个区域/指标及区域对看到可比较、受限并列、不可比或未就绪的原因；第三个区域缺资料时，另外两个合格区域仍能比较，缺口不被删除或填成零。

每项贯通显式确定性/受控请求、既有快照消费或同合同组合到可读结果/证据，并在本项核对独立小例与边界。复用A/B/P0基础，不新建测试专用业务接口或第二科学计算引擎；真实资格、真实比较与合成验证分开记证，不提交原始AIS、受限细网格、凭据或私人路径。

规格用户故事：7、8、9、10、11、12、13、14、17、18、24、26、27、28、30、38。

## Acceptance criteria

- [ ] 按区域×指标及必要区域对×指标建立兼容判定，返回稳定状态、机器可读原因、实际条件差异和缺失前置，不用单个全局ready标记放行/否定全部结果。
- [ ] 核对用途、年月/搜索期/日界、半径/几何/粒度、源/处理/质量、指标单位/估计量、分组/权重、有效支持与真实/合成身份；同名字段不能跨用途直接相减。
- [ ] 来源身份引用每区真实内容，兼容性看产品语义及冻结合同/参数和必要等价证据，不要求不同海域内容哈希相同，也不能只因版本名一样就放行或只因版本名不同就拒绝。
- [ ] 只有已登记、语义确定且可逆的单位转换可使用并保留原值/单位/规则；不以简单角度换算冒充公里圆、插值冒充精度或按组序号硬拼不同距离带/侧别。
- [ ] 同名义半径仍显示各区实际海陆/有效面积、有效日期、H/E与排除；未知支持、缺测、未准备和有效零区分，受限并列不计算无意义差值或生成差异显著标签。
- [ ] 源结果未完成、失败、许可或新鲜度不明按实际状态保留该列，其余合格区域对可用；无任何合格对时说明限制，不隐藏候选、挪用异区快照或补数。
- [ ] 完全重复候选拒绝，部分重叠/共享日或对照提示相关性，不相加小时/事件数当总样本；跨不同海域的共同支持指可比时间与支持政策，不错误地求不相交海域的地理交集。
- [ ] 用独立三域矩阵、同名异义、单位/权重冲突、版本语义、哈希不同、重叠、有效零/未知及一项失败夹具贯通入口和可读理由，验证局部资格和无伪显著/伪排名。

## 交付与验收

- 预览中明确点击，取得可实际下载的 Markdown 报告及逐日聚合 CSV；均从相同冻结报告形成，包含报告/成果/投影身份、条件、单位、版本、许可及样例/未通过研究资格声明。
- 0 与未知分开，CSV 不包含源格网/船舶/私人定位，公式起始文本安全转义；Markdown 来源文本不会注入链接或 HTML。
- 在线请求再次核验公开权限及 projection_id，拒绝/损坏/版本改变不返回文件；文件名绑定成果及报告身份。切换选择、来源变化、失败后旧下载入口失效。
- 真实浏览器到实际服务的文件内容与预览逐字段核对，验证合法样例、零/未知、拒绝、重复点击及错误；下载不执行分析或改变源文件。
- 离线仅使用已随应用公开的同源合成内容；PDF、私人/真实成果导出及生产保持原关口。

## What to build

研究者在同一固定区域结果中读取前期、短期和后7日的总小时、有效面积时间、密度及前后差，能够判断变化是否受到不同天数和覆盖位置的影响。

每项交付显式受控请求或同一计算适配到可读结果/证据的完整行为，并在本项核对独立小例与边界。复用现有实验、确定性服务及A/P0合同，不新建测试专用业务接口。合成测试、真实资格与实证分开记证；不提交原始AIS、受限细网格、凭据或私人路径。

规格用户故事：17、18、19、20、21、29、33。

## Acceptance criteria

- [ ] 复用A/P0逐日可加小时H和面积时间E，分别汇总各窗后求h/(km²·d)；总量、日均及密度分开命名，保留真实有效日数，不直接比较7天与3天总量或平均均值冒充整体密度。
- [ ] 前后几何固定，覆盖位置/面积变化时采用事先明确的共同空间支持或有依据的标准化/配对方案；仅除面积不称已消除覆盖构成差异，交集不足或不可判断则降低比较范围。
- [ ] 窗口双方小时与分母在同一选定支持，逐日/窗口与排除贡献可追溯；陆地、未知和无效区不进入有效分母，重复源、重叠对象和多半径不得重复计时。
- [ ] 分别给短期/后7相对前期的密度绝对差；正且有效前期才给比值/相对变化，0/未知不加伪计数或填无穷，分母0不输出假零。
- [ ] 事件等权效应与按面积时间合并的整体效应分别登记目标和权重，不混称同一指标；本项提供可复算基础，正式主估计量在B08冻结。
- [ ] 合法多船大值保留，逐日/各窗支持和暴露状态随结果呈现；不引入旧20%增强规则或捕捞收益、因果和预测价值结论。
- [ ] 用不等窗长、不等有效面积/位置、缺日、全零/零前期、重叠来源等手算小例贯通入口与可读效应，核对共同支持、分子分母守恒及正确降级。

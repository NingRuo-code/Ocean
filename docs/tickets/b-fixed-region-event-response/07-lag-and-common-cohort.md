## What to build

研究者能逐日查看−7至+7日的活动/对照变化，比较后1–3日与后1–7日时知道是否使用同一批事件及同类支持，避免把队列变化误读成时滞规律。

每项交付显式受控请求或同一计算适配到可读结果/证据的完整行为，并在本项核对独立小例与边界。复用现有实验、确定性服务及A/P0合同，不新建测试专用业务接口。合成测试、真实资格与实证分开记证；不提交原始AIS、受限细网格、凭据或私人路径。

规格用户故事：13、16、17、22、29、32。

## Acceptance criteria

- [ ] 从相同事件/匹配与逐日H/E直接形成相对日结果，0日单列，逐日列实际值、单位、覆盖、暴露、事件数和相关组身份，不推算缺失相对日或连线补数。
- [ ] 主时滞比较采用预登记的共同队列/支持或有据标准化方案；各日仅按可用案例形成的描述图单列，成员/权重变化可查，不伪称同一稳定样本曲线。
- [ ] 比较短期与后7效应时列两窗各自合格数与共同合格事件子集；包含关系及相同事件/日支持不作独立重复，后7不足只能保留相应短期描述。
- [ ] 持续暴露、前期污染和再次触发按冻结规则随时滞呈现，标题写锚日后而非默认离开后；不通过移动锚日对齐活动峰值。
- [ ] 本项交可读日级/队列表和描述性时滞图，不在无依据时为每个点强给区间；需要正式日级推断时沿B06设计登记主/探索及检验族，不另做逐行检验。
- [ ] 以日级缺口、事件数随相对日变化、不等支持、持续事件和短期/后7不同队列小例，从同入口核对时滞表/图与窗口效应的分子分母，支持不足清楚降级。

## What to build

研究者在正式目标期效果计算前登记主事件、窗口、对照、共同支持和推断规则，再通过同一B流程运行有限变体，得到事件成员、锚日、支持和效应共同变化的比较矩阵。

## Acceptance criteria

- [ ] 结合P0/A真实源精度与合法小例，冻结固定几何、进入/退出/去抖/再触发、缺口、锚日、识别上下文、窗口、共同支持/质量、对照、主估计量/权重、相关组及种子，不在拆票时凭空指定阈值。
- [ ] 目标期正式效果计算前保存主方案和敏感性清单身份；已看过结果如实标探索性，2024-07/08不冒充未见独立验证，改规则保留旧版本、理由与影响。
- [ ] 实际执行有限小例变体，覆盖受支持半径、事件距离/持续/再次触发、断档/边界、共同队列、对照、相关组和合法大值影响；不做所有组合穷举，不自批新研究尺度。
- [ ] 矩阵同时报告事件成员/锚日/合并/排除、覆盖、H/E、效应与区间状态，不能把换队列的差异只说成参数效果；各半径锚日/集合改变时保留对应与不一致。
- [ ] 主结果保留合法大值，不删除不利样本或只留显著；其他处理单列依据和完整结果，嵌套半径不当三次独立重复。
- [ ] 多窗口/半径/事件规则分主与探索，正式多项检验须登记检验族及处理，否则维持探索性区间/限制；解释不输出因果或预测增益。
- [ ] 从冻结配置→B主/变体计算→比较矩阵核验可复算、缺支持和方案变化路径，真实候选完整敏感性在B11执行，小例不解除真实门槛。

## What to build

研究者显式运行一个合法小型固定区域样例，得到单个已知观测事件、前7日/事件日/后1–3日/后1–7日的小时与面积时间以及可读响应摘要；条件、来源身份和样例性质明确。后续任务扩展同一条执行链。

每项交付显式受控请求或同一计算适配到可读结果/证据的完整行为，并在本项核对独立小例与边界。复用现有实验、确定性服务及A/P0合同，不新建测试专用业务接口。合成测试、真实资格与实证分开记证；不提交原始AIS、受限细网格、凭据或私人路径。

规格用户故事：1、2、13、15、18、19、21、34、39、40、42、44。

## Acceptance criteria

- [x] 增量复用#9现有受控实验入口、产物与运行清单模式，贯通明确请求→合法逐日夹具→简单已知事件/窗口→可读结果；只做必要兼容适配，不另建平行实验工程、宽泛重构或测试专用业务接口。
- [x] 明确B固定区域用途及版本，请求包含点、公里半径、锚日搜索期和输入/方法身份；样例几何已知且前后固定，不将旧移动缓冲表改名成B，不依赖固定锚点查表。
- [x] 在已知日历及固定有效支持上，由观测规则确定简单样例锚日，单列0日和各窗真实相对日期；计算可独立手算的小时、面积时间及归一化变化，不直接比较7天与3天原始总量。
- [x] 有效零、无记录未知、缺测和零分母分开，正有效前期才计算相对变化；零基线保留可算绝对差和原因，不补数、不加伪计数或输出无穷增幅。
- [x] 结果绑定提交快照，普通读取和改条件不自动重跑，失败/中断不发布为完成；现有旧响应表查询保持原语义，最小受控执行不称完整任务中心。
- [x] 明确标注合法合成输入及许可范围，不让未核实真实源或公开读取触发重计算，不输出受限细网格或私人路径；生产准入与完整事件识别分别由B02/B03接入。
- [x] 经现有受控入口或同一核心适配检查完整小例及缺日/零基线/失败路径，独立核对端点和数值；不以旧行级检验、增强阈值或样例后7冒充真实研究证据。

## Acceptance criteria

- [ ] 复用A/#66成熟统计适配、重采样/退化输出基础及#9运行清单，针对B重新定义事件依赖和目标量；不能直接搬A的日期分组或旧逐行bootstrap/符号翻转。
- [ ] 至少登记相邻事件、重叠前后窗口、嵌套/重叠区域、同日影响及复用对照的依赖关系和组成员；组后仍说明跨组独立假设，不以事件ID不同当独立。
- [ ] 分别给候选、合格事件、窗口/半径展开行、有效日期与可用组数量；按有依据的事件组/时间块采样，保持组内前后、目标/对照、多窗/半径对应结构。
- [ ] 依已说明的事件等权或合并H/E目标量及权重重算每次效应，记录区间方法/水平、组块规则、次数、种子、容差和失败比例；正式方案在B08冻结，不混平均均值与整体密度。
- [ ] 组数不足、全同值、零分母、退化或假设不满足时给区间不可可靠估计及原因，保留可计算效应和描述；不靠增加次数、无依据最小样本数或临时换方法强给区间。
- [ ] 置换/符号翻转只有组级可交换/对称等假设有依据时补充，保持整个相关组并说明对象；不满足可不做，p值不作为必有字段或因果证据。
- [ ] 通过B入口用独立已知组、窗口重叠、共享对照、多半径及退化/无差异小例验证配对、权重、种子和可读限制，不以显著或旧186行数量为验收。

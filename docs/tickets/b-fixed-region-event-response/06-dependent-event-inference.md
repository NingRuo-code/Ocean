## 实施记录 · 2026-11-19

固定海域实验入口接受 `fixed-event-group-uncertainty/v1` 与 `registered-group-percentile/v1`。输入 `ocean-fixed-region-event-inference-input/v1` 包含研究点和搜索期内各半径的 B05 冻结摘要及清单原文，以及登记 `policy`。请求半径是主要估计半径，其他半径只提供相关性关系。证据包绑定所读结果、参数与输入 SHA-256。

连接相邻锚日、前后窗同日、同日嵌套或重叠半径、复用或同日重叠对照，保留关联原因与组成员。候选事件、主要半径的合格事件、半径展开行、有效日期和可用组分别统计。抽样整组，复用 A 的随机数和百分位处理，按登记的事件等权或合并 H/E 重新算目标量。结果保留登记依据、次数、种子、失败比例及估计范围。

缺少主效应、跨组假设未核、组数不足、日期重复造成 H/E 无法合并或区间退化时，保留可用描述和明确原因。本轮为合成工具核验，真实跨组独立依据与正式推断方案沿 #80、#83 冻结及复核。

## What to build

研究者获得事件区前后变化及同日可比非锋面对照差，能查看候选域、固定对照、前后权重、可比性与失败事件；无法匹配时保留描述结果和原因。

每项交付显式受控请求或同一计算适配到可读结果/证据的完整行为，并在本项核对独立小例与边界。复用现有实验、确定性服务及A/P0合同，不新建测试专用业务接口。合成测试、真实资格与实证分开记证；不提交原始AIS、受限细网格、凭据或私人路径。

规格用户故事：23、24、25、26、28、37。

## Acceptance criteria

- [ ] 复用A/#65可比性、成对支持、权重和失败解释基础，扩展到B真实前后窗口及固定对照；不重新建立第二套匹配引擎，不把A同月远距带结果直接改名成B对照。
- [ ] 候选空间域、几何、P0资格、日期和环境匹配规则预登记；对照不按低活动或有利后窗选择，旧50km排除最多是需核实的条件，不用未知覆盖空海域制造低背景。
- [ ] 前后保持明确固定对照区域/组合与冻结权重；必须变化时说明标准化和目标量，目标区不随对照扩大，双方分子分母与实际共同支持可复算。
- [ ] 核对可用的位置、季节/日、距岸、SST/水深等及未控制因素，保存候选数、匹配差异/率、未匹配事件与原因；缺字段不想象补齐或无依据扩下载范围。
- [ ] 记录对照窗口的锋面资格、后续进入/缺日与复用关系；用事后整个窗口筛选须标回顾性条件比较，不冒充当时可知输入或随机分组。
- [ ] 事件前后差与同日对照差分别输出；若补充变化差，四个组成量同支持并列假设和局限，不直接称因果；无合格背景降级描述，不删除该事件或填零响应。
- [ ] 用手算案例从B入口验证不等面积/日期、固定/变化权重、对照再暴露、零背景、无匹配与正负/无变化，记录复用对照身份供B06相关组处理。

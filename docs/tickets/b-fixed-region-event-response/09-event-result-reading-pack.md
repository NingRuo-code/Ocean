## What to build

使用者先读一张时滞主图、关键前后/对照变化和简短解释，再按需查看事件时间线、窗口支持、相关组和匹配失败；允许导出的聚合图表与结果数字一致。

每项交付显式受控请求或同一计算适配到可读结果/证据的完整行为，并在本项核对独立小例与边界。复用现有实验、确定性服务及A/P0合同，不新建测试专用业务接口。合成测试、真实资格与实证分开记证；不提交原始AIS、受限细网格、凭据或私人路径。

规格用户故事：22、35、36、37、38。

## Acceptance criteria

- [ ] 消费同一B结果身份，提供可独立阅读的主图/摘要与基础聚合成果包，不重算科学数值，不等待完整工作台/AI，也不新建完整PDF、案例库或界面框架。
- [ ] 时滞图明确相对日、指标/单位、队列/支持与可用区间，0日及持续暴露可辨；无支持不连线造趋势，区间不可得有原因，不把描述图包装成正式推断。
- [ ] 附事件清单/时间线、前后与同日对照表、窗口覆盖、候选/排除/未匹配和相关组说明，均追溯同一逐日基础量、实际日期、几何及版本。
- [ ] 无事件、观测不足、无完整后7、无对照、无变化、反向与推断不足分别解释；不复用旧增强规则当B结论，不出现评分、把握度、渔获/收益或成功率。
- [ ] 图、表、摘要和允许的聚合导出同条件同数值，来源/许可/局限可查；未知授权不自动公开，受限细表与私人证据路径不出现在公开产物。
- [ ] 用同一受控结果验证数字、文字、队列变化、样例标识、缺测/退化展示及导出，真实成果消费在B12复核；#21单独验收工作台浏览器联动。

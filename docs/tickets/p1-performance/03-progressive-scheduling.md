## What to build

使用者换日或拖缩时先得到正确概览，再补当前视野明细；新操作不被旧慢请求阻挡，同条件在途请求可复用。

任务类别：近期。每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 消费已验收#28的身份隔离、错误分类和一次重试，复用同一请求状态；不重新实现另一套正确性逻辑。
- [ ] 换日保留底图/视角并隐藏旧观测，同日拖缩可保留合格概览；必要图层、概览精度和明细完成可区分。
- [ ] 实现当前操作优先、同条件在途复用、防抖及有据并发上限；取消不可靠时仍隔离过期结果，不能为省请求永远不补细节。
- [ ] 条件/日期/视野/层/数据版本参与必要身份，过期结果不得覆盖当前；预取和后台读不能抢占当前操作。
- [ ] 用固定操作对照等待、请求数、字节和失败，覆盖快速换日/拖缩、重叠窗口及不支持日期；保留真实地图交互与离线回归。
- [ ] 在同输入/支持参照上证明变化与限制，记录未改善场景；本项不重复做全局缓存、邻日预取或归档准备。

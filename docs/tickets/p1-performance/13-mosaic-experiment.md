## What to build

对活动空间图、日序列和少量证据卡的小原型比较普通查询、协调和预聚合开关，决定Mosaic路线是否有净收益。

任务类别：条件性。本项为条件性实验：先核对进入条件，成立才执行限定小样对照；不成立则交付有据的延后/不采用决定。决策完成不等于候选技术已实现或整项性能工作已完成。\n\n进入条件：真实共享筛选聚合构成瓶颈，普通参照稳定，构建/更新预算可度量。\n\n每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 以普通聚合基线判断进入条件，缺瓶颈或输入语义不稳就延后；不把论文题录、演示或通用缓存当已复现。
- [ ] 限定三类视图和合法查询模板，冻结输入/筛选/分桶；确认真实请求走候选优化路径，不以系统接通当实验完成。
- [ ] 对照普通方法、协调以及预聚合关闭/开启，记录首次、持续交互、构建/重建、数据更新、存储/内存与回退。
- [ ] 总小时、有效分母、圆域/锋线缓冲边界和缺测保持同一合同；复杂空间谓词须精确处理，不假设自动物化替代所有科学计算。
- [ ] 在预定工作量内累计交互节约需覆盖额外构建/重建，正确性及预算先通过；无净收益如实放弃或限定采用。
- [ ] 交付原始来源/实现版本、适配点、操作及结果证据和容量增量；不替换原地图或开放访客任意SQL，不宣称GPU imMens完整复现。

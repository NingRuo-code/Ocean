## What to build

用户连续浏览多日和多视野后浏览器资源仍受控；当前就绪后才空闲预取前后各一日概览，返回已看区域能复用合格数据。

任务类别：近期。每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 对浏览器跨日数值、对象和图像建立全局字节/条目/版本预算及淘汰，不以每日期四片代替总上限；预算依据固定负载测量冻结。
- [ ] 数值与图像身份分开，图像包含色表/标尺/局部增强版本；源/处理变化不误复用，淘汰后能合法重取。
- [ ] 仅当前必要操作完成且预算允许时预取前后各一天已就绪概览；不取明细、不准备归档，换条件或资源不足可停止无用预取。
- [ ] 当前请求优先，有限并发配合既有请求调度；隐藏图层数据是否保留服从预算，不能无限保留跨年数组。
- [ ] 长播放、多窗口和版本切换测缓存增长、命中/淘汰、JS堆及可得进程/图像资源，说明GC及不可得项，不把堆大小当总内存。
- [ ] 保留零/未知/失败、图例和查点行为，验证内存受控与端到端成本；不清理用户保存结果、原档或服务器缓存。

任务类别：近期。每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 消费#38的活动小时、有效零/未知覆盖、实际粒度和守恒合同，不重新读取许可或裁定研究真源精度；未核实来源不可假装完整输入。
- [ ] 先定义日期/视野实际支持再分桶，每桶保留总小时、源格数、范围和下钻身份；近景恢复该支持内全部有效格。
- [ ] 取消默认第60分位过滤和700点硬截断；叠加/隐藏背面、裁切及预取余量区别清楚，不声称屏幕圆点和等于整批响应或分析圆总量。
- [ ] 与同支持完整输入独立求和核对守恒及预定容差；0、未知和失败分开，粗桶标尺度，不伪装源格或以插值提高精度。
- [ ] 颜色/大小遵循已确认固定映射合同，和U2 #34协调但不重复配色票据；未冻结正式域只声明真实受支持范围，查询保留真实小时。
- [ ] 以完整支持B1对照性能、资源与下钻交互，记录同工作量收益；地图聚合不进入正式科学统计，且不依赖整个P0/界面全部关闭。

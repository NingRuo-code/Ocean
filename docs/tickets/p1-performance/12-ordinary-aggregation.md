## What to build

对同一份已验收月度输入，比较直接计算与普通数据库聚合，得到可供论文候选公平对照的数值和成本参照。

任务类别：条件性。本项为条件性实验：先核对进入条件，成立才执行限定小样对照；不成立则交付有据的延后/不采用决定。决策完成不等于候选技术已实现或整项性能工作已完成。\n\n进入条件：A已交付可复算的完整月计算与稳定输入/分母，存在目标联动查询。\n\n每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 消费#18已验收计算、基础表和直接参照，不在本项重复设计A或另算科学结论；A未具备就等待对应前置。
- [ ] 冻结日期/空间筛选、用途、分子分母、资料/方法版本和输出，明确地图/时间序列/证据卡的真实共享过滤。
- [ ] 从同一合法输入贯通直接扫描与普通聚合到相同可读结果，核对总小时、有效面积/天、缺测、边界去重和单位。
- [ ] 统计首次、冷热查询、数据准备、索引/转换与更新资源，不只挑一个缓存命中；不能以平均均值替代可加基础量。
- [ ] 真实联动未形成或普通方法已足够时给出证据，不默认必须引入论文系统；不足时不以合成结果证明真实月覆盖。
- [ ] 交付版本化基线、固定查询/操作、数值容差、环境与原始测量摘要，后续实验复用，不开放任意SQL或受限细网格。

## What to build

比较现有窗口读取与一个COG切片在目标平移/缩放场景的综合成本，给出是否值得采用的明确结论。

任务类别：条件性。本项为条件性实验：先核对进入条件，成立才执行限定小样对照；不成立则交付有据的延后/不采用决定。决策完成不等于候选技术已实现或整项性能工作已完成。\n\n进入条件：窗口IO/传输瓶颈成立，并能验证实际Range及概览/明细服务路径。\n\n每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 依据基线及#37空间/单位/缺测证据判断是否进入；没有窗口IO瓶颈或服务前置不成立就延后，不转换全档。
- [ ] 冻结合法切片、窗口、尺度和查询语义，比较现有数值/PNG路径与候选，验证实际Range和概览读取，不因后缀是COG就假定高效。
- [ ] 贯通同窗口首次/重复、平移重叠/不重叠和多级缩放，计请求数、读字节、服务/传输/解码/绘制成本。
- [ ] 对照数值、缺测、几何及查点；类别锋面结构不被普通均值抹掉，科学图例和源查询仍可用。
- [ ] 包含转换、索引/磁盘、更新及缓存成本，检查新路径收益和退化；用真实环境声明，不把理想局部读当实测。
- [ ] 决定采用/限定采用/延后/放弃并记录容量增量；与PNG实验独立，无需先完成所有其他格式实验。

## What to build

在固定地图操作中保留稳定底图，只更新必要数据/标记，隐藏面板按需计算，展开后读数仍与当前条件一致。

任务类别：近期。每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 先用基线定位实际重复绘制/计算，按成本选择局部更新、路径/投影或指标复用，保持原地图框架；无对应成本则保留简单实现并给证据。
- [ ] 图层和底图按必要条件失效，选中/查点/缩放/定位及球面/平面几何保持；不能为减少节点删必需对象或细节。
- [ ] 隐藏面板不重复执行无需立即读取的复杂计算，重开后准确更新；独立缓存失效不留下旧日期/半径结果。
- [ ] 同场景核对真实读数、几何、图例与缺测状态；保留键盘/小屏及用户已确认的非模态交互，不修改整套面板产品设计。
- [ ] 对照绘制时间、长任务、帧间隔、节点/路径规模和端到端等待；固定真实渲染环境，一次只改变可解释因素。
- [ ] 结论区分实现采用、无收益与延后；本项不直接强制改Canvas/WebGL或完整GPU架构，剩余瓶颈交条件实验。

## What to build

从真实导航、换日和拖缩操作得到可复跑的端到端报告，区分当前行为B0与合法小样的同语义正确参照B1，为后续优化提供统一测量入口。

任务类别：近期。每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 复用现有浏览器交互能力，先贯通导航→当前身份概览可用、日期动作→新概览、拖缩结束→明细可用；底图/加载提示或旧响应不得提前算完成，局部必要整理在本切片完成。
- [ ] 记录实际请求/状态/编码/字节、可得分段时长、渲染与面板成本，区分用户总等待和重叠阶段；计时开销、跨时钟和不可得指标如实说明。
- [ ] 固定提交、数据/方法身份、设备/浏览器/GPU模式、窗口/DPR、网络、缓存层、操作与重复协议；冷热分别报告，禁用GPU功能检查不能代替真实渲染对照。
- [ ] 保留B0旧分位/700点截断等限制；建立合法可复算小样B1，未知真实覆盖不借夹具解除。不同输入/显示支持的结果不直接计算加速倍率。
- [ ] 报告全部尝试、成功/失败/取消/超时及p50/p95适用性；冻结样本、分位、预算与失败口径，失败不记0，少量样本不称稳定尾延迟，3/1/2秒目标不预填达成。
- [ ] 验证已知延迟、旧响应、空白底图与完成事件的识别及测量摘要复算；本地/测试可独立开始，无需等待现服盘点或全部P0。

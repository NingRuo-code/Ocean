## What to build

用一个SST小切片比较现有RLE/SVG与PNG展示的总成本，在保留查点/锋线/图例前提下决定是否限定采用图像层。

任务类别：条件性。本项为条件性实验：先核对进入条件，成立才执行限定小样对照；不成立则交付有据的延后/不采用决定。决策完成不等于候选技术已实现或整项性能工作已完成。\n\n进入条件：真实栅格解析/绘制是重要成本，存在已核实合法的小切片与同色标参照。\n\n每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 先根据基线记录是否满足进入条件，消费#37的单位/掩码/网格证据；没有对应瓶颈或可比输入就有据延后，不为套技术强制改图。
- [ ] 冻结同日、范围、尺度、色表/增强、缺测和查询要求，复用已有PNG能力，不额外重建一套数据意义。
- [ ] 贯通真实服务出图、编码/传输、浏览器解码/绘制及原操作，和同语义RLE/SVG对照；不是只比JSON文件大小。
- [ ] 保留矢量锋线、点查询、选中与常驻图例，颜色和原数值同源；不平滑伪造精度，类别/缺测边界不被均值抹除。
- [ ] 记录首次/重复成本、预处理/缓存和内存/磁盘；正确性先过，再判断收益超出波动且关键场景不退化。
- [ ] 交付采用范围或不采用理由及可回退路径；采用需附容量增量，未运行/未接产品的原型不得称已部署。

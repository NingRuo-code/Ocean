## What to build

维护者得到现有路由、部署身份、资源与数据分层清单，知道哪些是实测、历史线索或未知项，并能为后续缓存和容量设置有据预算。

任务类别：近期。每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 复用只读盘点与既有P0来源信息，核对真实前端→代理→后端路径、来源及版本；历史404和机器注释仅为线索，不凭健康正常断言当前提交一致。
- [ ] 记录可取得的CPU、RAM、磁盘/余量、IO/带宽、进程worker及现有负载；无现服访问证据时交工具、部分清单和缺项，不能把本机配置当现服已核实。
- [ ] 按原档、热输入、派生/索引、缓存、结果、加工暂存和备份分别计实际字节/增长，注明压缩/展开/数组表示；复用P0身份，不重新调查零值/粒度合同。
- [ ] 区分当前演示、东海多年研究和全球冷归档上界，未取得的AIS/SST/年份不以名义完整数据计实测；不扩大下载范围。
- [ ] 给初步工作集、并发和缓存预算的事实/估算/未知分项及复核办法，不预定采购配置，不执行生产压测或生产缓存清空。
- [ ] 盘点摘要脱敏可审查，原始服务器定位和私密信息不外传；测试缺资料/无权限与正常清单，缺项不伪填0。

## 2026-11-19 公开样本离机恢复

在独立于校内共享盘的本机工作区，保存 `0ebc55ba1629ac6b9e8975cfdc0cd89f3337e282` 的 Git 源码压缩包及 15 份已登记公开样本。原档共 249,417,616 字节，样本和源码两包共 95,849,782 字节。清单登记两包 SHA-256、每份样本的相对路径、大小及 SHA-256。以空目录为目标，仅使用这两包和本机既有运行依赖恢复，解包前核对包哈希，解包后重核每份样本。

恢复的 8 份锋面、4 份 GFW 与 SothisAI 留存的校验值一致。3 份海温是本机独立取得的同日文件。编码字节与服务器副本有差异，既有逐日核验记录的时间、经纬度、海温和掩码数组一致。恢复后复跑固定 ZIP 成员检查、来源、逐日和共同支持审计，来源身份与本机冻结记录一致。10、20、30 公里各为 0/31 天可用。回环服务 12 项检查和数据完整性 922 项检查通过。恢复及校验在本机约 3.5 秒，另外计入审计和接口验证。

复演时从本机副本的冻结提交解包源码，再把样本解包到登记的相对路径。运行[八月原档与准入复跑](../../reports/ocean-august-source-readiness-2026-11-06.md#从原档复跑到准入判定)，用恢复目录的原档和独立缓存启动回环服务。核对有资料日、缺资料日、缓存复用和研究拒绝。

离机恢复范围为公开样本与 Git 源码。生产保护成果、权威状态、运行时恢复和正式恢复目标继续沿 #236–#242 验收。账号实际余量及受控入口仍是 #47 和 #228 的前置。

## 分层分配字节

原只读盘点复用同一次目录扫描，在 Linux 报告各层普通文件的已分配字节。原逻辑长度、扫描预算和 #228 使用的盘点字段不变。Linux 对照用例的两个文件名共 6 个逻辑字节、8,192 个分配字节，与 GNU `du` 对照一致；只扫描一个条目时报告 4,096 个已观测字节，总量保留未知。Windows 仍报告逻辑长度，分配字节明确未知。

Python 工具全量回归 158 项通过，最终盘点与发布预检定向 33 项、数据检查 922 项通过。

分配量只描述当前选定层内的文件条目。账号已用、剩余配额、代表性混合负载、正式入口和独立恢复点仍需实测，不能从这些分层数字推导。见[盘点报告口径](../../data/local-runtime-inventory.md#结果与限制)。

## 2026-11-19 校内公开样本顺序读取

在校园登录节点，以单进程按稳定顺序读取 15 份现有公开样本（共 249,417,616 字节），每次以 1 MiB 为块计算 SHA-256。连续三遍耗时分别为 1.822、0.388、0.484 秒。每遍有 12 个摘要值匹配既有锋面与活动清单，15 份文件在三遍之间均一致。剩余 3 份海温仅在本轮重复读取间核对；其来源证据沿用上文的离机恢复。

这些数字适用于校园共享盘上该小样本的读取加哈希计算。文件系统缓存未控制，后来两遍不可当作独立冷测；不据此估算持续带宽、单次读写上限、混合负载或账号剩余配额。过程没有写入原档或清理缓存。

## What to build

维护者得到现有路由、部署身份、资源与数据分层清单，知道哪些是实测、历史线索或未知项，并能为后续缓存和容量设置有据预算。

任务类别：近期。每项均交付一条可运行、可观察的完整用户流程或端到端测量/决策链，并包含自己的正确性参照、实际检查和前后对照。复用已有浏览器/CDP、服务与数据合同，不另建测试专用业务API；无新证据不宣称加速，真实、受控及合成样本分别记证，不提交受限源资料或私人运维信息。

## Acceptance criteria

- [ ] 复用只读盘点与既有P0来源信息，核对真实前端→代理→后端路径、来源及版本；历史404和机器注释仅为线索，不凭健康正常断言当前提交一致。
- [ ] 记录可取得的CPU、RAM、磁盘/余量、IO/带宽、进程worker及现有负载；无现服访问证据时交工具、部分清单和缺项，不能把本机配置当现服已核实。
- [ ] 按原档、热输入、派生/索引、缓存、结果、加工暂存和备份分别计实际字节/增长，注明压缩/展开/数组表示；复用P0身份，不重新调查零值/粒度合同。
- [ ] 区分当前演示、东海多年研究和全球冷归档上界，未取得的AIS/SST/年份不以名义完整数据计实测；不扩大下载范围。
- [ ] 给初步工作集、并发和缓存预算的事实/估算/未知分项及复核办法，不预定采购配置，不执行生产压测或生产缓存清空。
- [ ] 盘点摘要脱敏可审查，原始服务器定位和私密信息不外传；测试缺资料/无权限与正常清单，缺项不伪填0。

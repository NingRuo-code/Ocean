## Acceptance criteria

- [ ] 端到端区分地图已应用条件、AI草稿、待澄清意图、已受理任务及选中结果，绑定会话/消息/父上下文版本；发送后的地图改变或迟到回复不能改写原请求。
- [ ] 明确文字覆盖有依据的继承值，展示实际来源及本轮差异；未应用坐标不当生效值，年月/事件搜索期/签发日不可混同，指代、年份、坐标方向/单位不明时合并询问必要条件。
- [ ] 只改条件不提交，“改后再分析”可按原明确意图执行；解释只读已有证据，缺结果给任务入口。澄清回答绑定原意图，补齐且原意图仍有效时直接提交，不重复确认；取消/改目标或版本冲突则不执行旧意图。
- [ ] 新会话不偷偷继承私人旧对话，清空草稿不取消任务；同一待澄清意图重复回答或并发补充按上下文版本裁决，已经提交的意图不再受理一次。
- [ ] 条件、资格或预算变化时保留拒绝/待处理原因，不换源/换月/缩范围；“准备后分析”不授权准备结束自动重算，分开说明两个动作及后续入口。
- [ ] 以真实浏览器/服务及独立对话期望覆盖只改/改后执行、含糊指代、跨年、未应用坐标、同时消息、重复补齐与旧回复，核实际任务次数；规则能确定才执行，不靠模型猜测兜底。

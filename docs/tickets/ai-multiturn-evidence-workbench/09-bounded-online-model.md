## Acceptance criteria

- [ ] 按当时官方资料登记实际供应方/模型标识及版本、运行位置、认证、结构化能力、上下文、保留/训练条款与费用计量；用固定开发用例与规则/可用本地基线比较，选一个必要在线方案，不无边界遍历模型。
- [ ] 启用前落实允许发送字段、单轮/会话/滚动费用及并发、输入输出/工具次数、超时/重试预算；以实际计价与合法小样实测冻结，缺配置/授权/许可则明确等待，不能声称完整在线交付。
- [ ] 真实浏览器经原AI服务实际调用所选模型，在明确合法探索小例完成单工具理解/原结果解释，并由AI04核证后发布；模型理解不直接生成科学数值，真实响应与替身测试分别留证。
- [ ] 预算在服务端预留并按实际用量/计费证据对账，估算/实际/未知区分；429、超时或响应丢失不盲重发可能已计费请求，未知保守占用待核，幂等与研究任务身份分开核实。
- [ ] 未知工具/无效JSON/截断/核证失败/预算不足准确降级，规则仅在原意图条件可确定时执行，否则澄清或回手动；不得本地失败后擅自切在线、买额度、扩容或重跑成功研究。
- [ ] 开发和首次验收记录实际模型/提示/工具/投影版本、用例/输入类别、原响应、结果引用、延迟及用量/费用限制；独立最终用例封存待AI25，不要求文字逐字相同或科研正向增益。

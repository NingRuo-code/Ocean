## Acceptance criteria

- [ ] 复合读取和显式计算分开，读取已有结果不算新分析；缺源不自动补档或隐式重跑A/B。准备完成后分析即使写在一句话也保留新的分析发起边界。
- [ ] 每步稳定意图/公共任务/结果引用，部分成功可独立阅读，重开/重复/受理未知先对账；取消计划后不发后续步骤，正在运行任务由原真实取消合同处理并保留终态。
- [ ] 对条件/资格/源变化和失败给具体状态，不偷改计划或为解释重算；不同条件结果可并列，不由计划新造差值/联合区间或挑有利结果。
- [ ] 真实浏览器与实际服务核已知双步骤、部分失败、上限/越权、并发消息和取消竞争，独立核每步实际次数/值；在线语言组合适配及冻结用例在AI25另验，不阻塞单工具AI09。

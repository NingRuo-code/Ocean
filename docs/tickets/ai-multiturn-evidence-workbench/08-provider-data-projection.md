## Acceptance criteria

- [ ] 沿既有AI服务/模型适配扩展版本化发送政策，区分读取、保存、导出与发送供应方；逐源逐字段检查许可/所有权、目的及保留/训练条件，公开展示或内部可读不自动获得外发权。
- [ ] 只投影允许且必要的聚合、短条件、知识，用户文本/坐标同样处理；原AIS、细网格/可重建数据、密钥、私人路径、日志或未选笔记不能进入请求，不只靠提示词提醒或字符串脱敏。
- [ ] 发送前显示规则/本地/在线及字段类别，已配置政策内的明确问答不逐轮重复确认；供应方、费用、模型或许可未落实保持禁用，不因Q30允许在线就试调付费请求。
- [ ] 本项用明确不含保留资料的探索允许集完成真实浏览器→服务→投影/阻止/本地回退通路；研究集未有AI07及原工具隔离不得放行，不能先发送后补保护。
- [ ] 用受控供应方替身捕获实际请求验证允许字段、混合权限、撤销、注入及旧缓存的投影身份，替身只验证传输边界，不新建业务服务或宣称真实在线模型接通。
- [ ] 模型地址/凭据由服务端受控配置，不接受用户或模型任意指定网址/路径；健康/能力不发送生成式探测，状态不暴露内部端点，转供应方/在线回退必须重新满足政策。

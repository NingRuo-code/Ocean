## Acceptance criteria

- [ ] 实际持久会话保存最小条件/差异、澄清/执行意图、轮次父版本、公共任务/结果/证据引用、回答与模型/提示/工具版本、状态/时间，不只依赖浏览器存储，不保存隐含推理或不必要原始提示。
- [ ] 重开/断网恢复只读原版本和原任务，受理未知先对账；显式重新生成形成独立解释版本而不改科学结果，源变化、权限失效与状态未知不自动重发。
- [ ] 旧会话摘要/截断不能成为条件或授权真源，必要条件、冲突、缺口和引用沿结构化记录；新会话、选旧轮次和并发编辑有清楚可观察结果。
- [ ] 访问先核所有权及当前逐源权限，私人摘要/缓存不旁路撤销；证据可读、产物清理、源可用和可复算分开显示，日志只记必要脱敏状态。
- [ ] 基础轮次/字节/上下文上限先有保守配置，超限给手动/新会话入口，不无限积累；与正式清理/保护的增量在AI24完成，不因此让初版任意保留敏感内容。
- [ ] 真实浏览器/服务核关闭刷新、断网、相同消息重复、并发旧版本、重新生成及撤权，独立核会话/任务/模型调用次数与原引用；模型尚未接入时如实标规则模式。

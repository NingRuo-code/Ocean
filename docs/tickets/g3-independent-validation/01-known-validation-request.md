研究者提交一个小型复核请求，得到按年份和季节分层、可手算核对的A聚合结果与证据；先贯通受控入口和阅读输出。

每项沿显式G3请求→现有API或受控计算→实际冻结/资格/原A/B执行或兼容复用→可读结果/证据验收完整行为，包含自己的独立小例及边界检查；不为测试新增业务入口，不拆成孤立层。真实资料资格、软件/合成验证、真实独立复核分别记证。重计算受控授权，不提交原始AIS、受限细网格、凭据或私人路径。

## Acceptance criteria

- [x] 从显式受控请求到合法已知A结果读取、候选格和可阅读输出形成完整最小路径；所需最小适配随本项做，不单开孤立schema或广泛重构，不调用旧逐行实验冒充新推断。
- [x] 请求与结果保留A/B类型、固定区域/公里范围、年月/季节、源/方法与协议/分区引用、H/E及单位；样例可用明确标注的合成已知答案，不宣称真实或独立研究通过。
- [x] 分层示例覆盖两个年份和季节标签、有效零/缺测与不合格项，候选不静默删除，支持不一致不补零或混算；A/B类型不能混池。
- [x] 至少显示可读候选表、同源聚合证据及身份，读者能从数值定位输入依据；完整科学冻结/资格在后续切片启用，未具备不得标确认性。
- [x] 沿现有API或受控实验入口验收，以独立手工H/E核对请求→实际读取→输出及错误条件；不新建测试专用业务接口，不触发归档、AI或隐式批量研究。
- [x] 本项可立即开始，只交付小例的软件通路；后续真实P0/A/B合同按接缝接入，PR、合并、部署及真实研究分账。

## Acceptance criteria

- [ ] 条件性分支消费V15完整冻结模型与独立分区，经V03/V04检查真实接触及相关性后受控评价；不等待V09结果再挑模型，不默认其资料仍是未见。
- [ ] 评价只使用已冻结变换/模型和目标量，验证期不得再拟合选择预处理或调候选；已揭示后改方案保留版本并改探索标记，新确认性评价另需未接触资料。
- [ ] 结果保留目标单位、实际协变量、支持/样本组、假设/诊断、条件效应与合法不确定性，复用V07成熟相关推断/多重边界，不把残差逐行当独立或比较区间端点。
- [ ] 协变量缺失、超支持外推、分布/诊断不合格或独立组不足时明确拒绝/降级；不能因模型拟合成功就声称消除全部混杂、因果、预测泛化或锋面预测增益。
- [ ] 真实合法未用于选择资料上的实际模型评价、原冻结版本复算及同源图表/聚合证据分别留档；缺资料仅完成软件检查和缺口报告，真实模型验证不得填通过。
- [ ] 独立小例检查接触后重命名、预处理泄漏、已看G3资料误入、单位/支持和拒绝行为，交接真实资料用途给后续预测；不自动调用在线模型、工作台或系统报告。

## Acceptance criteria

- [ ] 在冻结登记/执行入口检查实际分区关系，输出冲突成员、依据及通过/需调整/探索状态；不是仅生成一份离线规则文档。
- [ ] 对A日/时间块与空间支持、B相关事件/完整窗口/共享对照保留跨月跨区域关系身份；同一组换月编号或嵌套半径不能伪装新增独立样本。
- [ ] 基于实际支持确定整组划分及必要时间/空间隔离，记录依据和残余相关性；不承诺一个任意统一天数能消除依赖，不仅按年份或行政海域名称判断。
- [ ] 分区目标记录重合、事件窗口越界、共享对照或几何重叠必须被检测；只能在有依据的调整/重新冻结后确认，或保留探索标记，不因结果有利豁免。
- [ ] 以独立可手工列举的关联图核对整组归属和冲突，反例覆盖同组多标签、跨月、邻区和预处理使用复核资料；不依赖尚未交付的完整B引擎进行软件小例验证。
- [ ] 真实A/B执行接入时仍核真实组/日期/支持，不把小例通过当现实独立性证明；预测另设标签可知时间和隔离，本轮不交付预测切分。

## Acceptance criteria

- [ ] 显式G3请求消费V05实际A逐日基础和组，输出逐层目标量、H/E、有效日/独立组、对照、区间和不足；核心可只做分层重复，不强制任何总效应。
- [ ] 区分总小时、sum(H)/sum(E)描述密度、预定层效应均值和联合对比；可加支持须无重复，层级/权重/重叠去重和不合格层处理在目标揭示前冻结，嵌套半径不能当独立重复相加。
- [ ] 联合推断只用合法共同基础量、组/联合重复估计并保留日期、空间与共享对照依赖；复用成熟方法及A相关组结构，不平均/相减区间端点或用区间不重叠当正式检验。
- [ ] 推断记录目标、假设、有效组、区间含义、种子及迭代；组数或基础不足、零分母/零基线、退化区间正确降级，不以逐行网格制造精度，不任意套元分析。
- [ ] 登记主/次/探索检验族和无法计算成员；仅在原检验有效时按冻结适用方法作多重处理，保留原始/调整后证据及全集，不能只校正显著子集或事后调权。
- [ ] 稳定解释展示量级、区间与支持，无有依据的容许范围及程序不声称等效；差异不显著/多数方向一致不证明稳定，不输出把握度/评分、渔获或因果结论。
- [ ] 用独立手算权重/差值、可列举相关组及锁定成熟方法参照核对实际请求输出，覆盖共享记录、少组、无效原检验和缺少联合基础；方法在探索/小例选定后由V03冻结，再用于真实V09。

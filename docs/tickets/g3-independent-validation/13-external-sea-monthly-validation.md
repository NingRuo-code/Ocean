## Acceptance criteria

- [ ] 条件性分支：先沿V02核一个真正不同海域的实际联合覆盖、授权、研究粒度和支持，预定候选及接触历史，不能以东海子区域或C已有样例直接声称外海域独立。
- [ ] 沿V03/V04冻结和检查外海域分区，继承可比原A/G3方法，不根据目标效应重选海域或规则；源语义不同须分开/拒绝并说明，内容文件不同本身不构成冲突。
- [ ] 实际执行原A、G3分层/敏感性及同源阅读，保留东海与外海域的单位、几何、覆盖、权重、H/E和不确定性；不新增排名/因果或未经预定的联合推断。
- [ ] 至少一片真实外海域的合格未用于选择资料完成实际复算/复用核对才能声明该范围通过，方向相反同样是合法结论；仅合成、待下载或已看资料不能替代。
- [ ] 无合法独立资料时记录未启用/阻塞条件，真实外海域验证保持未完成，不自动购买、全档准备或修改ADR；不反向阻塞东海A交付。
- [ ] 核对具体图表/证据及首次揭示记录，明确跨海域与跨年份/季节各自证据范围，A外海域不自动证明B、模型或预测泛化。

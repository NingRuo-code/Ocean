## What to build

研究者提交实际月条件时，月分析读取同用途的P0快照，在执行前给出是否支持、能做哪些描述及缺少哪些前置；被拒绝的条件不启动重计算。合法小例仍可单独运行。

每项沿用已确认的显式确定性分析验收入口，交付可运行/可读取的完整行为或成果链，并附独立期望与边界检查。合法夹具明确标注；真实资格、真实计算和合成验证分别记证。遵守P0及ADR粒度/许可合同，不提交原始AIS、受限细网格、凭据或私人路径；无证据不写完成。

规格用户故事：1、2、3、4、5、9、10、36、39。

## Acceptance criteria

- [ ] 直接消费#41的全日历、用途、必需层、共同支持、质量/几何规则和版本；沿用同一资格来源，不重复P0审计或要求#42查询API先完成才读取合法快照。
- [ ] 明确核对实际点、公里半径、月份及主分析/子分析用途，支持范围不是预置档位或名义海域覆盖；拒绝条件不换月换点扩圆，已变更或无法核实的身份不得沿用旧准入。
- [ ] 区分支持/有限支持/未核实与未准备/缺测/无资料/权限/失败，并返回具体证据及缺失前置；有限描述与正式研究准入有明确边界，不默认全日历有文件即合格。
- [ ] 活动—锋面主分析按实际必需层交集判定；侧别/环境子分析按自己的额外支持，ADR的0.01°目标和实际粒度分开，未批准替代不能静默通过。
- [ ] 仅显式受控提交在准入通过后读取/计算；只读资格及结果不隐式扫描归档、准备数据或触发整月任务，访客消费边界沿用授权合同。
- [ ] 从月分析入口对完整、缺日、可选层缺失、边界、版本失配和权限等P0兼容快照验证放行/拒绝与原因；合成支持样例和真实资格分别记证，真实候选月关口由#44/A08承接。

## What to build

研究者在真实候选月正式分析前登记主方案和有限变体，通过同一分析流程得到半径、边界、距离带、覆盖门槛及大值影响的比较矩阵；每一项都有支持状态和参数身份。

每项沿用已确认的显式确定性分析验收入口，交付可运行/可读取的完整行为或成果链，并附独立期望与边界检查。合法夹具明确标注；真实资格、真实计算和合成验证分别记证。遵守P0及ADR粒度/许可合同，不提交原始AIS、受限细网格、凭据或私人路径；无证据不写完成。

规格用户故事：28、29、30。

## Acceptance criteria

- [ ] 消费P0的真实粒度、几何、质量和资格合同，结合源精度及合法探索小例冻结主效应、距离带/端点、对照、支持门槛、异常规则、相关组方案与种子；理由可追溯，不凭空填阈值。
- [ ] 主方案与敏感性清单在正式目标月效果计算前记录版本；探索数据和最终复核身份分开，已经看过目标月效果时如实标探索性，不宣称该月为独立验证。
- [ ] 实际执行同一入口的受控变体比较，至少覆盖P0支持的多个半径、几何边界归属、距离带、覆盖门槛和合法大值影响；不支持的变体列明原因，不自批新尺度。
- [ ] 主结果保留全部合法小时，大于24小时的多船累计不当作错误；任何其他处理有依据、单独版本和结果，不删除不利样本或仅保留显著方案。
- [ ] 比较矩阵报告每项实际支持/排除、分子分母、效应与区间状态；资料支持变化不能只画成效果变化，同支持与不同支持差别明确披露。
- [ ] 多个半径/侧别/距离带标明主与探索；正式多项检验须登记检验族和处理，否则维持探索性解释。变更方案保留旧身份、理由与影响。
- [ ] 用合法小例从冻结记录→主/变体执行→同源比较矩阵验证可复算及缺支持路径；真实月完整敏感性随A08执行，不用本项样例通过代替真实关口。

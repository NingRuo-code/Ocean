## What to build

研究者在同一受控月分析入口取得逐日匹配的距离带活动小时、有效面积时间与月度密度，并能查看每一天的贡献和未知部分。结果使用完整分析输入和P0几何合同，可作为后续对照和优化的直接参照。

每项沿用已确认的显式确定性分析验收入口，交付可运行/可读取的完整行为或成果链，并附独立期望与边界检查。合法夹具明确标注；真实资格、真实计算和合成验证分别记证。遵守P0及ADR粒度/许可合同，不提交原始AIS、受限细网格、凭据或私人路径；无证据不写完成。

规格用户故事：6、8、9、11、12、13、15、16、17、18、24。

## Acceptance criteria

- [ ] 消费#39核实的公里圆、空间归属、地理距离/面积、共同支持、单位与容差规则；保留真实源粒度和边界假设，不重写P0审计、私自批准粒度替代或将展示限点作为分析输入。
- [ ] 逐日从对应源和版本读取活动与已检出锋线，计算分析单元到同日最近锋线的距离，形成可追溯基础量；不以对象中心、像素距离、固定事件表或月度叠图替代。
- [ ] 按最大距离带、源精度和误差取得必要的圆外搜索支持，验证圆外近锋线；检出为空、缺测和支持不足分开，有限搜索只给可证明的下界/分组，不自动填无限远或伪远距组。
- [ ] 距离带互斥，端点与最外带规则版本化，多锋面/重叠缓冲去重，未知组单列；分组可加小时与面积时间守恒，未知和排除贡献可查。
- [ ] 日级到月级按同支持的分子与分母加总再求密度；不同有效日、面积或嵌套半径不得随意平均/相加，合法多船大于24小时不自动删除。
- [ ] 返回逐日及月度距离表、支持和版本，直接参照不依赖屏幕筛选或缓存；结果可阅读和复算，正式完整月资格仍由A04/A08核验。
- [ ] 以解析/独立几何小例验证距离端点、圆外锋线、海岸/跨边界、不同纬度、重叠、同日错配及零/未知分母；贯通真实入口和月汇总，不用被测聚合生成预期。

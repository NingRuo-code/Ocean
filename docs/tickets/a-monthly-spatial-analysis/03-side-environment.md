## What to build

研究者从同一月结果读取冷侧、暖侧和未知侧的活动及支持差异；SST或梯度具备实际支持时再查看对应子分析，缺少可选资料时仍能读取主距离分析。

每项沿用已确认的显式确定性分析验收入口，交付可运行/可读取的完整行为或成果链，并附独立期望与边界检查。合法夹具明确标注；真实资格、真实计算和合成验证分别记证。遵守P0及ADR粒度/许可合同，不提交原始AIS、受限细网格、凭据或私人路径；无证据不写完成。

规格用户故事：14、21、22、23。

## Acceptance criteria

- [ ] 沿用P0实际产品及空间归属合同，为同日分析单元确定可判定侧别；多锋面冲突、线附近不确定和缺资料保留未知，不猜测或强分冷热。
- [ ] 侧别分组的活动分子、面积时间分母和有效日期使用同一子集，报告已知/未知贡献及与主分析的样本变化，不以全体小时除已知侧面积。
- [ ] SST与可用环境量标来源、单位、匹配方式/偏移、有效支持和局限；可选资料缺少只影响需要它的子分析，不改变不依赖它的主分析资格。
- [ ] 如计算温差/梯度，登记方法、空间尺度、缺测和代理单位；它不是未接入的真实锋面强度，不凭缺字段补数或新增未经确认资料范围。
- [ ] 逐日与月度侧别/环境结果随同一身份可读，未知组/分母0显示原因；结果保持活动关系的条件性表达，不引入评分、渔获量或成功率。
- [ ] 用小例从提交到结果验证明确冷热、歧义、可选SST缺测及子集变化，复核小时/面积守恒和主分析不被可选条件无故阻塞。

## What to build

使用者读取某个已有月结果时，先看到关键指标、一张距离关系主图和简短解释，再按需查看月度分布、侧别、同月对照与逐日证据；允许导出的聚合表和图片与显示数字一致。

每项沿用已确认的显式确定性分析验收入口，交付可运行/可读取的完整行为或成果链，并附独立期望与边界检查。合法夹具明确标注；真实资格、真实计算和合成验证分别记证。遵守P0及ADR粒度/许可合同，不提交原始AIS、受限细网格、凭据或私人路径；无证据不写完成。

规格用户故事：16、17、24、31、32、35、37。

## Acceptance criteria

- [ ] 直接消费同一确定性结果身份，生成可独立打开的最小结果阅读产物和基础聚合图表包，不重算科学值；不等待完整工作台/AI，也不建立新的界面框架或完整PDF产品。
- [ ] 距离主图有明确距离带、指标/单位、有效支持及合格区间；无支持不连线穿缺测，未知/下界/无区间各自说明，不制造平滑趋势或假曲线。
- [ ] 提供月度活动分布、侧别及同月比较、逐日支撑等可读附图/表，显示原条件、实际日期/面积、纳入/排除和版本；锋面频次仅作背景，不用叠图替代同日证据。
- [ ] 默认短解释与主图聚焦可观察关系，正向、反向、无明显差异、无对照和资料不足均可正常呈现；不加入评分、把握度、捕捞成功率、因果或收益承诺。
- [ ] 图、表、摘要、聚合导出和运行清单同源，单位和数值可互核；许可未知则限制相应导出/公开，不输出细网格、可逆源资料或私人证据路径。
- [ ] 使用同一受控结果验证数值、条件、样例标识、缺测/退化图和文字，核对图表与API/证据包一致；真实结果消费及复算由A11验收，#21负责后续浏览器工作台联动。

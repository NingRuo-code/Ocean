## What to build

研究者读取近锋面与同月同日可比背景的密度差，能同时检查双方小时、面积时间、匹配日期和可比性；缺少合格参照时保留描述关系并解释原因。

每项沿用已确认的显式确定性分析验收入口，交付可运行/可读取的完整行为或成果链，并附独立期望与边界检查。合法夹具明确标注；真实资格、真实计算和合成验证分别记证。遵守P0及ADR粒度/许可合同，不提交原始AIS、受限细网格、凭据或私人路径；无证据不写完成。

规格用户故事：19、20、21、25、37。

## Acceptance criteria

- [ ] 优先以同分析圆内明确的远距带构造距离参照，记录候选、纳入、排除、同日交集和权重；对照不以低活动或最终有利差异选择。
- [ ] 额外非锋面区域只有在预先登记候选空间域、P0支持和匹配方案后才使用，不暗扩用户圆、不硬套旧50km、不用未知覆盖或空海域制造低背景。
- [ ] 在兼容日期/有效支持上重新计算目标与参照双方小时、面积时间、密度及绝对差；正且有效基线才给比值/相对差，0和未知不加伪计数或填无穷值。
- [ ] 核对实际可用的位置、距岸、SST等可测条件和支持差异，登记未控制因素、匹配质量及失败；缺水深/渔具不想象补齐或无依据扩数据范围。
- [ ] 可读比较结果追溯逐日分子分母与方法；无可比日/面积/合格背景返回描述降级和限制，不输出因果、捕捞收益或预测增益。
- [ ] 用手算小例贯通入口、成对支持、效应与失败解释，覆盖面积不等、缺一方日期、零背景、无匹配及正/负/无差异，保留全部约定结果。

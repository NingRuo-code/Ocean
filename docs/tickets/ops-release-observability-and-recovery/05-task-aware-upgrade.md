## What to build

维护者切换服务时可限制新重任务并处理在途工作；本人看到原任务安全继续或准确中断，旧执行者不能改写结果。

每项沿实际发布/备份/恢复操作→原服务与真实浏览器/API→同身份任务/结果/文件验证自身完整行为，辅助独立小例、内容/权限核对及受控故障，不为测试新建业务系统。真实成果/模型、已知样例、合成故障、隔离环境与生产分别记证；生产操作须后续已有审核和单独安排，本轮拆票不授权部署、采购、清理或模型费用。凭据、真实主机地址/个人路径、受限源档/细AIS及原始敏感日志不进入公开产物。

## Acceptance criteria

- [ ] 消费#115产物/状态对账和旧执行者写入隔离、#117取消跨重启，在原公共执行器上补发布维护点及进程/合同版本约束，不另造任务或恢复系统。
- [ ] 限制新重任务受理后核正在执行/发布步骤，等待已登记安全点或准确中断，不按固定短超时强杀后声称可续；已允许轻量阅读继续，维护范围与原因清楚。
- [ ] 切换代际对任务状态和实际文件提交都生效，旧进程恢复通信不得越权覆盖，发布与完成回写竞争保留已校验成果；已取消任务不复活，不重做已完成步骤。
- [ ] 新进程仅按兼容原输入/格式/执行授权接续，未知或不支持类型不自动执行；发布响应丢失按持久阶段对账，不重复创建用户意图、下载或模型调用。
- [ ] 在隔离环境对真实A受控任务或合法准备步骤于运行/安全点/产物提交及取消临界实际切换/终止，独立核任务/步骤/结果身份和发布次数，模拟UI乱序仅补前端分支。
- [ ] 浏览器能重开原状态和成果，故障/未知不伪进度；记录实际进程版本、故障点与残余类型，既有TASK证据复用，仅补跨发布风险，生产切换仍另行安排。

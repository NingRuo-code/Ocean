## Acceptance criteria

- [ ] 消费O05及#116不安全恢复/明确重试合同，登记已知可用目标和前后端/配置/持久格式/资料兼容矩阵，实际完成隔离发布失败→回退→浏览器原成果核对，不只写命令。
- [ ] 代码回退、配置回退、数据版本选择与持久备份恢复分开，不能用切代码或旧数据库覆盖新状态假装恢复；本项只允许已核兼容状态回退，灾难恢复沿O12/O16后续合同。
- [ ] 有格式变化才定义实际迁移与可逆/前向修复策略，不能为无变化发布强制新框架；不可逆/未知格式拒绝旧版写入并保留原状态、暂停受影响动作，不删除新结果换取成功。
- [ ] 原任务的完成/取消/中断、保护引用和新旧结果身份保持，回退不触发重算/外部发送或恢复旧许可；对不再兼容的任务说明原因供本人选择，不偷偷换源。
- [ ] 真实隔离故障覆盖激活前后、版本/格式不兼容和失败残留，独立核内容/任务/文件及原授权；仅浏览器可打开或health正常不能证明状态正确。
- [ ] 更新可重复回退/停止操作及范围，源不可复算、文件可读和格式兼容分开记证；未验证迁移类型保持未支持，不在生产做破坏演练。

## What to build

维护者从可核对的固定版本发布包，在独立环境启动原前端和API，用浏览器读取合法已知地图/查询并核实际运行身份。

每项沿实际发布/备份/恢复操作→原服务与真实浏览器/API→同身份任务/结果/文件验证自身完整行为，辅助独立小例、内容/权限核对及受控故障，不为测试新建业务系统。真实成果/模型、已知样例、合成故障、隔离环境与生产分别记证；生产操作须后续已有审核和单独安排，本轮拆票不授权部署、采购、清理或模型费用。凭据、真实主机地址/个人路径、受限源档/细AIS及原始敏感日志不进入公开产物。

## Acceptance criteria

- [ ] 复用现有部署/服务脚本及已存在的确定性查询，完成审核提交/内容身份→允许内容打包→独立代码/运行环境安装→原地图和API已知小例的完整通路；不另建科学引擎、容器平台或测试专用业务服务。
- [ ] 发布包采用明确允许清单、完整性及运行时/依赖解析记录，不整包工作目录后只排除少数目录；受限原档、私人资料、凭据、临时产物和未审核改动不混入，上传包无Git目录仍可核实际身份。
- [ ] 首版仅回环/受控隔离入口及合法公开已知只读样例，外部发送、采集、模型与未受保护写接口默认禁用；代码/静态资产/环境和全部可写目录不与生产共享，输入固定且可证明只读，否则使用隔离副本。
- [ ] 实际浏览器能操作原地图并读取同身份查询/来源/单位/覆盖，健康只证明对应存活；环境未含新业务状态时准确显示未接入，不将静态截图、文件存在或日志字符串当成功。
- [ ] 独立已知小例核发布包/运行版本、数值/零缺测、资产/接口和离线兜底；模拟错误包/缺依赖/越界目标/危险内容仅在隔离环境，拒绝错误版本且不改现有环境。
- [ ] 交付可重复的小范围操作和适用边界，旧#10/#11/#12材料只作复用来源，不复制旧同步任务或要求它们全部关闭才验证新增隔离发布；无生产操作、付费调用或最低服务器配置宣称。

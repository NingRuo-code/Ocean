- [ ] 预检读取规范化候选身份、必需/可选能力、允许来源和非敏感配置，错环境/不兼容状态/缺授权/余量不足可复查拒绝，不自动装包、改权限、更新资料、开端口或购买资源。
- [ ] 对代码、环境、源/缓存/成果/暂存/备份分层记录实际空间/开销与未知，基础限额先可生效；完整混合负载和生产参数在O22，不能以预检静态估算代替实测。

- [ ] 在实际隔离目标用合法小例验证准入、错版本/目录、空间不足/未知、配置改变及预检后失效再次拒绝；只读操作无写入/研究/模型副作用，未来生产激活仍需单独安排。

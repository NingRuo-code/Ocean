- [ ] 消费#158实际东海A/B复核和#175检索/辅助匹配合同，增量登记服务/请求/结果/索引与分区接触引用及备份适配；不重复科研引擎、台账或强制深入追踪。
- [ ] 实际候选浏览器核已登记协议/用途、真实分层A/B证据、候选库/响应和短窗核查，保留跨期/海域适用范围、区间不足/反向、代理相似与断档，匹配分数不成身份概率。
- [ ] 从实际合法备份在隔离环境重开上述原结果/候选/图表及必要冻结引用，验证权限/版本/索引及已知接触，缺台账/当前政策不明默认受限；完整备份后变更对账沿O15。
- [ ] 普通检索、展开和定位不自动研究/取源，正式执行仅完整冻结及准入通过；恢复/清理/更新不让已见目标变未见，不能借不同ID/半径/缓存绕过保护。
- [ ] 复用原真实样例与独立已知反例核数值/方向/兼容、缺日/重新锚定、未知角色/权限及无隐式执行，恢复测试不新消耗科学保留资料，科研结果与OPS功能分账。
- [ ] 仅纳入已真实交接的声明范围，外海域/条件模型或新增类型完整报告没有证据则保留未验；本分支不等待PRED、AI或整个生产交付，适配不能凭脚本链接假称在线可执行。

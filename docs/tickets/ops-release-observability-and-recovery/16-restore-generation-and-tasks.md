## Acceptance criteria

- [ ] 将O06兼容回退和O12完整状态恢复接到同一TASK租约/检查点/提交合同，登记可区别恢复代际和对账状态，不重新实现已由#114–#117承担的执行器。
- [ ] 恢复旧数据库/文件不能使旧执行者重新取得写入资格，状态与实际产物两处拒绝失权写入；不能仅重置一个旧序号或只保护状态表而放开文件替换。
- [ ] 核恢复点后已提交/完成/取消与可取得的权威依据，已校验完成步骤不重做、取消不复活，未知副作用中断；安全原输入/检查点/执行授权均满足才续原任务，其余供本人明确选择。
- [ ] 实际隔离进程在恢复前后、提交与回写之间、取消持久后重启，保留失权旧进程模拟迟到通信，独立核步骤/文件/结果/发布次数和原条件；只改HTTP状态不证明此项。
- [ ] 浏览器重开原记录显示恢复时间/原因、准确终态与已有成果，断网/登录过期不自动新建/取消；恢复策略不自动取源、研究或付费模型，源改版不静默替换。
- [ ] 记录适用发布/格式/业务类型及未支持恢复阶段，真实恢复证据与TASK已有进程重启证据分别引用，原成果/保护不丢；生产故障和实际切换另行安排。

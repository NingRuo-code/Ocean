## What to build

维护者实际从备份恢复固定发布与基础状态，浏览器能重开原任务、证据和文件；恢复环境默认不自动执行或对外发送。

每项沿实际发布/备份/恢复操作→原服务与真实浏览器/API→同身份任务/结果/文件验证自身完整行为，辅助独立小例、内容/权限核对及受控故障，不为测试新建业务系统。真实成果/模型、已知样例、合成故障、隔离环境与生产分别记证；生产操作须后续已有审核和单独安排，本轮拆票不授权部署、采购、清理或模型费用。凭据、真实主机地址/个人路径、受限源档/细AIS及原始敏感日志不进入公开产物。

## Acceptance criteria

- [ ] 用O11真实备份在空白独立存储/代码/环境恢复声明范围，先核清单/链/校验、必要配置/测试凭据取回和格式兼容，不借原在线目录或只解压文件声称恢复。
- [ ] 恢复默认禁止采集、外发模型、自动任务执行和公开写入；旧恢复点的取消/完成/权限/接触/费用可能不新，无法核实的范围一律未知/禁用，不因高级正向适配尚未完成就默认允许。
- [ ] 通过原实际服务/浏览器重开任务、结果及合法保护文件，核原条件/版本/数值/状态/权限与物理内容；本项先用明确已知探索样例，不冒称真实研究或全业务类型。
- [ ] 缺密钥/依赖、损坏、旧格式与部分恢复显示准确原因，不假成功；记录恢复点、实际开始/完成、数据损失窗口和实测资源，目标值未冻结不能称生产恢复达标。
- [ ] 隔离环境不共享生产可写源/状态/执行代际，真实文件/记录核对配故障反例；只读恢复不重算、准备或新建用户意图，无法复算与旧文件可读分开。
- [ ] 基础恢复可先交付，不等待全部科研、AI或生产；完整撤权/接触/费用对账和恢复后的执行者衔接分别在O15/O16，未知范围持续停用，独立主机副本在O13实际取回验证。

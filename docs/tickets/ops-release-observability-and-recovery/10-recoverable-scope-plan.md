每项沿实际发布/备份/恢复操作→原服务与真实浏览器/API→同身份任务/结果/文件验证自身完整行为，辅助独立小例、内容/权限核对及受控故障，不为测试新建业务系统。真实成果/模型、已知样例、合成故障、隔离环境与生产分别记证；生产操作须后续已有审核和单独安排，本轮拆票不授权部署、采购、清理或模型费用。凭据、真实主机地址/个人路径、受限源档/细AIS及原始敏感日志不进入公开产物。

## Acceptance criteria

- [ ] 消费#120及其#119真实轻量记录/保护引用，从已登记业务范围→实际存储/依赖枚举→可读恢复计划，首版覆盖原任务/结果及合法保护样例，不假定某数据库含全部状态或另建产物目录平台。
- [ ] 代码/环境、权威元数据/条件、受保护聚合文件、可再生产物、缓存与源资料分开标备份/重建/不保留；每项源/用途/大小/身份、缺依赖与原样复算限制可核，未知不能当完整。
- [ ] 未接入REPORT/AI/科研台账的类型明确未保护，后续O13/O15/O17等注册真实适配；初版只备当前声明合法范围，不因此声称全系统恢复或封存资料可重置。
- [ ] 计划读取不复制、不清理、不准备源或重算；受限原档与细AIS不因备份自动获复制许可，凭据/密钥只存受控取回引用，公开记录不含秘密/地址/个人路径。
- [ ] 给持续生产备份所需频率/保留、允许损失、恢复时长、存储位置/容量与访问的实际配置检查；未落实输出明确欠项，小范围受控试验可测量，不能以默认值宣称生产达标。
- [ ] 真实服务/受控运维入口及原浏览器任务核计划/引用/权限，独立已知共享依赖与缺文件例验证范围/计量/拒绝；不只统计目录文件数，保护不等于许可或永久可复算。

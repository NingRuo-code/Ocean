# 已知月成果报告的软件交付

日期：2026-10-28。用户在本次接续中授权规划当前可完整执行的票并连续实施。本补充范围从已完成 A01/W01 的公开合成月结果出发，按下列两项交付；原 REPORT 规格、真实成果票及其依赖保持有效。

## 问题与范围

现有月阅读器能查看公开合成成果及逐日证据，但没有统一的报告预览与同源报告文件。用已许可公开的 CC0 合成成果，可完整验证报告的选择、身份、内容、缺测表达和下载；这不需要暂缺的原始资料或新服务器。

本批只支持现有 `ocean-published-month/v1` 投影中经服务端核验、明确允许公开的 CC0 合成结果。继续通过现有月成果目录和明确选择的 result_id 读取，不增加分析执行、持久任务、模型调用或数据准备。真实成果、私人结果、B/C 报告、PDF、案例版本管理及生产部署各保留原验收。

## 顺序与完成条件

1. **软件票 S01：已有月结果报告预览。** 在现有公开月结果的只读服务路径增加报告表示，沿现有底部证据面板从“报告预览”按钮读取。报告包含原年月/点/公里圆、H/E/日均/密度及单位、有效与日历日、逐日图表、方法/版本、来源/许可、未估计区间、局限。已知零与未知明确区分；没有距离/冷暖侧结论和统计区间时如实说明，不将小时汇总包装成关系结论。身份绑定精确 projection_id、report_version 和内容；筛选草稿及地图操作不改报告条件。服务错误、拒绝、过期投影及晚响应均不得发布错误报告。在线失败不静默回退离线样例；离线只对已经随应用公开的同一投影生成同一报告。
2. **软件票 S02：同源 Markdown 与 CSV 下载。** 预览中明确点击下载，得到完整 Markdown 报告与逐日聚合 CSV。每种文件保留报告/成果/投影身份、条件、单位、方法/源版本、样例/研究资格/许可与缺测说明；CSV 仅含日级聚合，不含格网、船舶或私人定位。内容来自预览使用的冻结报告，下载期间选择或来源变化使旧下载入口失效。文件名含成果与报告身份，合法公开结果才可下载；CSV 转义公式起始文本，Markdown 按纯文本转义来源字符串。拒绝和不可验证状态没有可用下载。

两票各自包含浏览器→实际 FastAPI 服务→既有冻结公开成果→报告/文件的端到端流程，辅以原 FastAPI 客户端独立数值参照。S02 直接依赖 S01，按序完成，不按 schema/API/测试横向拆票。沿原 #126/#42 已规定的浏览器和只读查询边界采用 TDD；独立期望取已知 40 h、7 km²·d、2/29 日及有效零/未知小例。

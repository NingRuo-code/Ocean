## Problem Statement

完整研究版需要让使用者把可信研究结果保存、重开并导出成可阅读、可核查的成果。既有REPORT规格已覆盖A月度关系、B固定区域事件和C区域比较，但G3跨期/跨区独立复核、相似历史情形/短窗辅助匹配、PRED活动预测回测都把系统内完整报告留给后续适配。仅能在页面看新结果，或者把旧A/B/C模板改标题，无法完成这些类型的成果交付。

不同研究类型有关键差异。复核报告必须保留协议、接触/分区、全部候选、实际支持及未完成维度；相似案例报告必须说明检索全集、选取理由和非独立样本，不能把相似顺序当作业排名；预测报告必须区分历史签发与目标日、输入可知条件、逐提前量公平对照及真实验证范围。文件生成成功不会增加科学证据强度，保存也不能把已经接触的资料重新标成未见。

目前主目录旧报告入口会组合旧式角度窗口、历史、对象和追踪计算，现有脚本主要导出HTML、Markdown及摘要；这些是可复用基础，不能证明已具有本规格要求的新研究类型案例、同源PDF/PNG/CSV、保护保存及权限闭环。已发布任务也只是合同，不能据此推断功能已经实现。

## Solution

在原工作台和结果详情中，为上述新研究类型增量接入已有REPORT案例、版本、内容投影、文件生成和TASK保护合同。本人明确选择已有结果，查看将保存的真实范围，保存案例后可按原版本重开、预览，并实际下载PDF、PNG、CSV与成果清单。地图和原界面分工保留，长证据按需展开。

报告只读取原结果及其合法聚合证据；科学量、区间、检索顺序和预测评价沿原引擎，不在报告中重新计算研究。A类G3复核可以先接，B复核、相似响应、短窗核对、预测局部和有真实支持的空间扩展分别推进。资料不足、无关系、反向、模型无增益、探索性及部分可用都保留准确状态；未完成的研究关口不会因漂亮报告被勾选。

主验收链路为真实浏览器选择新类型结果→明确保存→重开版本→预览→实际服务生成及下载文件。辅助检查核数值/身份、许可和接触记录、隔离保护清理及实际PDF页面。复用既有案例/任务/权限/渲染服务，不建立第二套报告或科研平台；生产部署和相对今天的滚动预测另行安排。

## User Stories

1. 作为研究者，我希望从已有G3复核结果打开报告，以便带走同一份跨期证据。
2. 作为研究者，我希望G3的A复核先形成成果，以便不等待B或外海域全部完成。
3. 作为研究者，我希望B复核单独保留事件窗口和相关组，以便正确理解响应。
4. 作为读者，我希望分清跨年、季节和海域分别验证到哪里，以便不扩大结论。
5. 作为读者，我希望看到全部候选及排除理由，以便知道报告是否只挑了有利结果。
6. 作为读者，我希望知道实际协议和分区版本，以便核对研究问题及独立性。
7. 作为研究者，我希望保留接触用途与冻结时序，以便区分探索和最终复核。
8. 作为读者，我希望有效支持、小时和面积时间一起出现，以便理解效应的分母。
9. 作为读者，我希望区分原始记录、事件与独立相关组数，以便不被样本量误导。
10. 作为读者，我希望看到原分层效应、权重及区间限制，以便避免误读汇总。
11. 作为读者，我希望敏感性和反向结果仍在报告中，以便理解不稳定情形。
12. 作为研究者，我希望有条件模型时引用原诊断和边界，以便不把解释关系当预测或因果。
13. 作为研究者，我希望没有条件模型时仍可导出核心复核，以便不被可选分支阻塞。
14. 作为使用者，我希望保存一次相似检索的真实上下文，以便之后重现当时看了什么。
15. 作为读者，我希望知道海域、季节窗和候选库版本，以便理解案例的来源范围。
16. 作为使用者，我希望选中的案例和当时顺序固定，以便候选库更新不改旧报告。
17. 作为读者，我希望分页报告说明实际包含多少候选，以便不把一页当完整全集。
18. 作为读者，我希望相似原因和差异可追溯，以便不把相似度当作业成功率。
19. 作为读者，我希望环境案例与有B响应案例分开，以便不误以为每个案例都有活动证据。
20. 作为读者，我希望A背景和B事件分板呈现，以便不混淆单位或观察对象。
21. 作为研究者，我希望重复事件、不同半径及相关案例保持关系，以便避免伪独立。
22. 作为使用者，我希望短窗核对可保存逐日图示，以便说明可能关联的依据。
23. 作为读者，我希望缺日、歧义和重新锚定清晰显示，以便不看到虚假的连续轨迹。
24. 作为读者，我希望辅助匹配不改写B事件定义，以便原分析保持可复核。
25. 作为研究者，我希望预测回测报告保留实验与模型身份，以便评价对应真实版本。
26. 作为读者，我希望历史签发日、目标日和提前量一起显示，以便不把回测当今天的预报。
27. 作为读者，我希望区分归档条件与当时可知输入回测，以便了解时效假设。
28. 作为研究者，我希望逐1/2/3日报告评价和覆盖，以便不只展示最好的提前量。
29. 作为读者，我希望基线、候选和有无锋面对照同条件呈现，以便判断增量价值。
30. 作为读者，我希望失败预测、缺目标和排除也有记录，以便不把删掉难样本当提升。
31. 作为读者，我希望误差单位与差值方向明确，以便不会把负号解释反。
32. 作为读者，我希望模型卡和选择记录随成果保留，以便理解采用、放弃及未验证范围。
33. 作为研究者，我希望无稳定增益也能形成完整成果，以便如实交付研究结论。
34. 作为使用者，我希望局部标量与真实空间分布分别标识，以便地图不制造精度。
35. 作为读者，我希望跨期、空间留出和东海推广分别记证，以便不从局部外推整域。
36. 作为使用者，我希望保存前看到具体结果和范围，以便不误存尚未应用的筛选。
37. 作为使用者，我希望重开旧案例保持原条件，以便新源、新模型或模板不改变历史成果。
38. 作为使用者，我希望标题、笔记和选章产生明确版本，以便科学数值不被手改覆盖。
39. 作为使用者，我希望多类型组合保留各自身份，以便不混成一个总分或总效应。
40. 作为读者，我希望精简报告仍带必要来源、分母和局限，以便简洁不损害解释。
41. 作为使用者，我希望下载真实可打开的中文PDF，以便用于阅读和汇报。
42. 作为使用者，我希望PNG保留完整图例和上下文，以便独立使用图片时仍能读懂。
43. 作为研究者，我希望CSV保留允许的聚合精度、单位与缺失状态，以便后续核查。
44. 作为使用者，我希望成果包说明成功文件和缺口，以便知道是否完整。
45. 作为使用者，我希望长表和复杂图可读，以便不依赖应用页面才能理解文件。
46. 作为使用者，我希望生成时仍能操作地图，以便不被长任务阻断。
47. 作为使用者，我希望取消、失败和重试有真实状态，以便半成品不被当作成功。
48. 作为使用者，我希望重复保存和迟到响应不串版本，以便下载始终对应选定成果。
49. 作为研究者，我希望保存和预览不触发重算或训练，以便不会改变实验和消耗预算。
50. 作为研究者，我希望封存目标在预览和导出时同样受控，以便不经文件旁路泄漏。
51. 作为研究者，我希望报告阅读与导出的接触按原政策记录，以便不重置未见状态。
52. 作为本人，我希望文件与私人案例按当前授权检查，以便旧链接和缓存不能绕过撤权。
53. 作为使用者，我希望内部阅读和允许分享用途分别投影，以便不误带受限内容。
54. 作为使用者，我希望主动保存的新类型成果受保护，以便普通清理不会破坏案例。
55. 作为使用者，我希望源缺失时区分可读、可再生成和可复算，以便知道还缺什么。
56. 作为使用者，我希望沿已有规则选择AI注释，以便说明不混入确定性科学正文。
57. 作为维护者，我希望按实际类型和体量限制导出，以便一份大报告不挤垮轻读。
58. 作为维护者，我希望新类型声明依赖能交给既有备份恢复，以便不遗漏模型或接触引用。
59. 作为负责人，我希望真实成果、合成排版和故障测试分开记证，以便准确跟进完成度。
60. 作为负责人，我希望各类型独立交付和关联旧任务，以便避免重复建设或循环等待。

## Implementation Decisions

### I01 范围与既有模块复用

- [ ] 归属L2的REPORT扩展，关联#13/#21，承接#125/#140，消费G3 #141/#159、PRED #176已发布结果与证据；不修改或关闭既有父级/任务，不扩大它们的完成定义。
- [ ] 增量注册复核、相似检索/短窗核对、预测回测的结果类型、章节和允许用途。共用#127/#128案例版本、#129–#133格式/生成任务及#138/#139用途/保护合同，不复制账户、案例库、队列、清理器或科学引擎。
- [ ] 每类建立可独立操作的选择→保存→重开→预览→文件通路。已有合法已知样例先验证软件；真实研究消费另设直接关口，不把全部G3、预测、AI或OPS收官任务统一设为起步前置。
- [ ] 旧报告只能复用安全格式化/排版经验，不得以旧角度窗口、历史锋面频次或连续追踪摘要冒充新研究结果。未接入类型明确未支持，不以改标题或占位图交付。

### I02 精确引用、内容身份与版本

- [ ] 输入为本人选定的已发布结果或允许的部分完成结果，绑定类型、请求/任务、数据/方法、协议/分区及子结果身份。保存不从当前视窗、筛选草稿或“最新同日结果”补引用。
- [ ] 新类型接入原案例/报告内容与产物身份，包含所选章节/候选、用途投影、解释规则及原证据版本；渲染模板/字体/图式形成产物版本，不把重排版当新研究。
- [ ] 案例正文及科学依据不可静默修改；标题、笔记、所选引用或章节改变产生可追溯版本，保留原作者角色。新源、新模型、新库或新协议不覆盖旧内容。
- [ ] 预览及文件完整性状态区分完成、部分、缺证据、未支持和失败。失败/中断任务可记录原因，不能保存为已完成实证；允许部分成果须保留未完成候选/维度，不能仅删掉缺项后宣称完整。

### I03 G3复核候选、支持与独立性

- [ ] 复核报告读取原协议、候选全集/纳入排除、年份×季节×海域层、A/B子结果及版本，区分候选数、有效日期、事件及相关组，不根据当前图表筛选重新定义研究全集。
- [ ] 保留执行时冻结/分区、原接触用途与独立性判定、方法改变及降级说明。跨年、跨季节和跨海域分别记真实支持；同年多月不替代跨年，探索性不能改标签变确认性。
- [ ] A保留全月实际日历/有效支持、距离带/侧别、H/E及同月对照；B保留固定几何、原事件锚日/组、前7/当日/后1–3及真实后1–7和原对照，不能外推缺窗。
- [ ] 图表/CSV使用原合法聚合证据，展示覆盖、未知侧别、有效零/缺测与排除原因；不凭文件存在或报告渲染通过新增研究资格，不用展示粒度反推分析真源。

### I04 G3效应、汇总与条件模型

- [ ] 逐层效应、单位、合法区间/不可估原因、原始与调整后检验证据及主次问题沿原结果；反向、近零、宽区间、失败候选和敏感性均可查，不只导出显著部分。
- [ ] 跨层汇总只消费原冻结目标量、权重及合法联合证据。不得在导出时平均效应/区间端点、重算p值或混池A/B/不同半径；原无联合推断时只保留描述和限制。
- [ ] 方向相近、未显著、等效和稳定分别沿原判定，不将排版汇总升级成因果或普遍稳定；H/E、组数和支持变化与图注同时保留，舍入不改变原判断。
- [ ] 条件模型只在原分支真实输出时附模型/目标单位、协变量、假设/诊断、独立性及适用边界，不重拟合/调参；未启用、缺资料或不适用明确说明，不阻塞核心复核报告。

### I05 相似检索快照与选择范围

- [ ] 保存原参考日/固定公里域、海域/季节规则、年份范围、候选库/索引/特征/检索版本、分区访问政策与查询身份；记录当时完整检索规模及实际包含/选中候选，不将REPORT个人案例等同于历史环境事件。
- [ ] 报告可含明确选定候选或有界完整允许集，保留稳定候选身份/当时顺序及未包含原因。单页、前若干条或手动选择都标明子集；不能靠重新搜索“当前第一页”生成旧报告。
- [ ] 需要遍历多页时沿同一冻结库和游标合同，在原授权与资源预算内显式生成；游标/原快照不可用就拒绝完整性声明或导出已明确的合法子集，不偷偷切新库补齐。
- [ ] 相似/差异按原特征逐项解释，保留缺特征、并列、重复事件/半径/版本与相关组关系；候选条数不当独立样本，相似度不当概率，不重新按后续响应选优或计算成功率/作业榜单。

### I06 原响应与短窗辅助核对

- [ ] 环境案例、A背景和B响应保留类型；展开的原A/B证据精确引用，B保留原窗口、H/E、对照、效应/区间及缺口。只有环境依据不得在摘要/图注中写已有活动响应。
- [ ] 案例并列只消费已有兼容与差值依据，无合法差值就只并列及解释不可比；不在报告中新做检验、平均相关案例或把相似检索当独立验证。
- [ ] 短窗图示引用原日期、对象提取/裁切、锚点、算法版本、各项度量、备选和段身份。缺日、失败、歧义、无对象与重新锚定准确分段，不跨缺口连线或累计为同一锋面迁移。
- [ ] 匹配分值/初始化值不画成身份概率；局部F编号不当跨日永久身份，人工核对单独标角色与依据。辅助匹配不得改变B固定区域事件或制造生命周期结论，旧图层若不具备段依据则不生成误导图。

### I07 预测实验、日期与输入可知性

- [ ] 读取原实验/协议/分区、特征训练快照、模型/参数/后处理、预测签发及评价身份；历史签发日、目标日、t+1/t+2/t+3、空间支持与单位在页面和独立图表可辨。
- [ ] 归档条件回测、可核当时输入回测和规则参考分别标识，记录训练截止、输入发布/可用时刻及时距、不确定的时效假设；不能把最新活动观测日加提前量冒充相对今天未来预报。
- [ ] 保留标签H/E/支持定义、零/缺测、分区/相关组/接触与最终目标首次揭示依据、冻结/选择角色。报告只引用原合格结果，不以显示观测目标为由重新选择样本或未来锋面掩码。
- [ ] 预测与目标观测分图层/图例和日期，实况只在明确回测对照中显示。未评价、缺输入、缺目标或未支持提前量如实说明，不由报告补值、训模型或生成原来没有的预测。

### I08 预测评价、公平对照与范围

- [ ] 逐提前量列基线/候选及有无锋面对照，消费原相同目标队列、非锋面特征/预算和失败处理依据；保留所有已登记方法与采用/放弃，不只展示获胜模型或最优提前量。

## Testing Decisions

主验收接缝已获用户确认：真实浏览器选定已有新类型成果，经同一REPORT服务保存案例、重开固定版本、预览，再由实际任务/渲染链生成并下载PDF、PNG、CSV和成果包。辅助API、独立已知聚合例、文件审阅和隔离清理只核该业务链路；不为测试引入另一套报告入口，不要求重新运行全部研究。

1. **端到端阅读与身份。** 从具体G3/检索/短窗/PRED结果进入，验证实际所选引用、内容/产物/用途、保存后刷新重开和文件身份一致；改筛选、切案例、源/库/模型更新与迟到响应不改旧报告，地图仍可操作。复用既有W/REPORT浏览器交互及布局检查，按影响核小屏和键盘。
2. **独立已知答案。** 用独立手列的分层效应/H/E/权重与候选、含缺日/歧义/重置的短窗，以及逐提前量配对误差小表核页面、PDF、PNG与CSV。包含零/缺测、少组/无区间、A/B不可混池、部分候选、配对失败和差值方向；预期不能由被测导出器生成，不重复科研引擎的检验。
3. **真实PDF和独立文件。** 实际打开文件并渲染代表性PDF页面，检查中文、页码、负号/单位、长标题、跨页表、复杂效应/预测图、图注/色标/缺口。PNG和CSV可独立解释，清单校验及范围匹配；未知字体/图片读取失败必须有真实失败或明确限定输出，不把HTML改后缀交付。
4. **保留集、接触和权限。** 用实际服务验证封存目标经摘要/缩略图/分页/直接ID/旧文件等旁路仍不可读，放行与原接触记录一致；撤权/用途变化、重复意图和不同模型/分区下不重置未见。检查导出字段、附件及元信息，真实研究文件与明确合成的泄漏反例分开留证。
5. **无隐式科研与版本可靠性。** 记录实际调用次数，证明保存/预览/重排版、取消/重试不计算复核、重新搜索/构建索引、提取短窗、训练/评分、准备或调用模型。重复点击、响应丢失、断网刷新、取消竞争和半成品不得造成重复发布或串版本；复算仅经既有独立显式研究任务。
6. **新增依赖的真实保护清理。** 在隔离合法存储接#120/#122/#139验证各新类型保存、活动导出、共享证据和清理竞争，实际核文件/引用/墓碑；满盘、引用未知、保护失败保持旧成果、不报假成功。原源/模型已清理时可读/再生成/复算限制准确，不操作生产或私有真实源。
7. **真实成果分批消费。** G3真实A与B复核、真实历史案例/B响应、真实短窗逐日核对、局部真实预测t+1/2/3及公平锋面对照分别回放保存和格式交付；原支持不足就保持该关口未完成。条件模型、外海域、空间/跨期和东海扩展只对真实已有成果验相应声明，不能用合成样例补足；无正向关系或无增益允许正常通过。
8. **容量、可选注释与交接。** 按实际新类型规模核限额/拒绝/可取消和轻读影响；有AI适配时用已有冻结注释核选择、来源、用途及保护，不发起模型调用。向OPS交接依赖与恢复读取要求，但实际灾备/生产另验；记录实际检查、未执行项和残余范围，不以文档发布或旧测试总数宣布功能完成。

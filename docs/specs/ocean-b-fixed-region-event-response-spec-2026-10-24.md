# Ocean B 固定海域事件与前后活动响应实施规格

整理日期：2026-10-24。关联既有 B #19、实验基础 #9、执行总纲 #13 与统计协议 STAT-04/05，承接 A #60/#61–#71 和 P0 #35。状态：已发布 [规格 #72](https://github.com/NingRuo-code/Ocean/issues/72)，标签 `ready-for-agent`；验证边界已获用户确认。发布标题：`[Spec] B 固定海域事件响应：真实前后窗口、可比对照与相关事件推断`。

实施任务已按用户确认发布为#73–#84：[任务与阻塞关系](../tickets/b-fixed-region-event-response/README.md)。本行仅为本地导航，远端规格正文保持不变。

## Problem Statement

使用者不仅希望知道活动与锋面的位置关系，还希望了解：锋面接近某片固定海域后，该海域的活动相对前期怎样变化，后1–3天和后1–7天是否不同，这种变化是否也发生在同日其他可比海域，以及资料是否足以支持这种解释。

现有响应表及查询能展示预先汇总的活动字段，已有实验会输出区间和检验，但不能据此认定已从逐日资料识别了真实固定海域事件。每日局部锋面编号、每日一条记录、多半径展开行和旧186行表都不等于独立事件。旧转换直接比较前7日与后1–3日总小时，旧实验按行抽样，均需要针对不同窗口长度、面积支持及相关性改造。

B需要一个可复算的固定区域事件分析闭环：从锋面观测独立形成候选事件，再核实真实前后窗口、共同支持和可比对照，输出观察到的活动变化及不确定性。正向、反向、无稳定变化、没有事件、无可比对照和资料不足均应诚实呈现，不预设锋面带来鱼量或收益提升。

## Solution

提供显式的确定性事件响应入口：使用分析点、公里半径形成整个分析期间固定的研究区域，指定事件锚日搜索期及资料/方法版本。读取P0的事件用途支持和A交付的逐日基础量，按冻结规则从同日锋面与区域的空间关系识别事件，保留全部候选、合并、锚日、纳入/排除及相关组。

对每个合格事件分别核实前7日、事件日、后1–3日和后1–7日真实支持，以明确的有效面积时间与可比支持计算前后差、同日非锋面对照差，必要时补充有假设说明的变化差。按相关事件组/时间块估计合格的不确定性，样本不足就保留描述结果与原因。

结果提供事件清单、逐日时滞图、前后/对照表、有效样本与敏感性、版本和复算证据。默认只展示一张主图、关键变化与简短解释；工作台、AI和报告后续消费同一快照，不另算数字。

## Implementation Decisions

### 1. 归属、复用与几何口径

- 本规格细化[B #19](https://github.com/NingRuo-code/Ocean/issues/19)及STAT-04/05，归属[执行总纲 #13](https://github.com/NingRuo-code/Ocean/issues/13)，复用[实验 #9](https://github.com/NingRuo-code/Ocean/issues/9)的适用执行、产物和复现基础，不另建平行事件实验工程。已回读相关正文及评论，当前均开放且暂无评论；本轮尚未实施或运行B。
- 按已确认研究顺序A→B→C推进。真实B消费[A规格 #60](https://github.com/NingRuo-code/Ocean/issues/60)的已验收逐日输入、几何、分母与结果合同，重点承接[#68](https://github.com/NingRuo-code/Ocean/issues/68)/[#71](https://github.com/NingRuo-code/Ocean/issues/71)的真实参照和交接。小例可先设计，不以A Issue关闭替代实际合同与证据验收。
- 固定研究区采用已支持的分析点与公里圆，在一个事件的前后窗口中不移动、不随每日锋面形状改变。公里圆、地图视野、锋线搜索支持及锋面缓冲分别命名；不通过拖动地图改变已提交研究区。
- ADR-0001仍保留表观捕捞小时、0.01°分析目标、前期与同日对照等原则；其中既有“锋面缓冲”与本轮已确认的“固定区域”是不同几何估计对象。实现需记录该几何扩展的ADR澄清并保留旧口径，不把本规格视为已修改ADR，也不将移动缓冲结果改名或混入固定区结果。源粒度替代仍走既有ADR评审。
- 已有质心/形状/包围盒短窗口匹配可作观测核对，不能当跨日物理锋面真值；B只研究锋面与固定区的事件关系，不要求深入生命周期、分裂合并或移动预测。
- 旧转换中的前7日/后1–3日原始总小时、增强阈值与零基线处理保留旧身份，不能搬成新B主要估计量。现有视野响应查询仍只代表旧产物，不静默变更语义；新增正式用途/版本并保持兼容。

### 2. 请求、支持与实际依赖

- 请求包含固定区域/点与公里半径、事件锚日搜索起止、用途、所需窗口、P0支持快照及源/处理/几何/质量/事件/对照/推断/参数版本。首选2024-08为锚日搜索期，不是只读取该月内日期。
- 读取P0 [#39](https://github.com/NingRuo-code/Ocean/issues/39)的几何/分母与[#41](https://github.com/NingRuo-code/Ocean/issues/41)的事件窗口资格，参考[#44](https://github.com/NingRuo-code/Ocean/issues/44)真实审计及缺口；A的完整月资格不等于B前后窗口资格。
- 请求必需层按事件判定及目标活动用途确定，SST/侧别或其他环境匹配只在实际用途需要时加入；可选资料不足不无谓阻塞不使用它的描述输出。许可、真实粒度、共同支持及对照区域资格逐项核实。
- 窗口支持按每个候选锚日和实际区域核对，返回支持/有限支持/未核实、未准备/无资料/缺测/权限/读取失败等稳定状态。部分描述不得冒充完整B研究准入；未满足不补零、换日期、扩圆或降低质量门槛。
- C/#20、W/#21及完整任务中心、AI、性能论文实验均为后续消费或公共增强，不反向阻塞B核心计算。P0定义资料资格，A提供基础量，B只扩展事件/窗口/对照与推断；后续拆票明确实际交接，不用父级全部关闭作统一门槛。

### 3. 从锋面观测形成可审计事件

- 对固定区逐日计算冻结的锋线—区域空间关系，可使用相交/接近及明确距离依据；说明是到圆边界还是分析点、源格语义、搜索支持和容差，不能混用或以屏幕像素判定。
- 事件判定只依赖锋面观测、预先登记的环境/质量规则及时间连续性，不使用活动峰值、响应方向或显著性筛选锚日。候选列表在响应计算前冻结并保留身份。
- 先建立每日已观测进入/接近、未满足、未知状态，再按冻结规则形成连续段。登记候选起止、首次满足日期、锚日、持续长度、合并、退出与再次触发条件；具体距离阈值、持续日数、间隔和滞回/去抖规则据源精度与小例确定，不凭空指定数值。
- 默认锚日采用规则确定的首次合格进入/接近日，事件日为相对日0；仅有日观测时称观测锚日，不声称已知真实小时级进入或先后因果。其他锚定方式只能作为预登记的独立方法/敏感性，不按活动结果移动日期。
- 缺日不等于离开，未知不能直接接成无锋面或确认新进入；缺口内连续性不明时保留不确定/分段关联，并依冻结规则限制事件资格。多日无观测后首见只算首次观测，不能自动当新事件。
- 搜索期只决定允许的锚日，额外读取足以确认进入、退出/再次触发与窗口的前后上下文。首日已处于锋面条件、末日尚未退出或上下文不足分别标左/右截断，未确认起点不伪造锚日。报告实际额外读取范围；不能仅靠前后7日就默认已证明连续性。
- 多锋面同时出现以固定区的暴露事件为主，保存当日对象关联与歧义；每日F编号仅作当日标识，编号更换不拆出新事件。同一日同一区域的小时不因多个对象重复累计。
- 所有候选、合并前片段、排除和原因均可查，包括无事件与无法判定。无事件只有在判定所需观测足够时成立，缺测不能得出“没有锋面事件”。

### 4. 真实窗口、复现与暴露状态

| 窗口 | 相对观测锚日 | 含义 |
| --- | --- | --- |
| 前期 | −7至−1日 | 前期活动参照，记录是否已有锋面或其他事件影响 |
| 事件日 | 0日 | 单列观测和活动，不混入主前后比较 |
| 短期 | +1至+3日 | 锚日后短期活动，不等于锋面离开后的活动 |
| 延长窗口 | +1至+7日 | 独立计算的真实后7日支持，包含短期窗口但不是新独立重复 |
| 日级时滞 | −7至+7日 | 各相对日真实值、覆盖、暴露与样本，仅作清楚标注的日级证据 |

- 时区/日界、来源时间对齐与窗口端点按P0版本规则记录；不把卫星日产品或行为估计说成精确时刻。事件搜索期、识别上下文与响应窗口读取范围分开。
- 从真实逐日资料重新求各窗口，月初读取前一月、月末读取后一月；真实源未取得时返回具体日期/层缺口。后1–3日不能推算后1–7日，旧表含有某字段也不能替代逐日支持核验。
- 前期和后期逐日标记是否满足事件条件、其他进入/再次触发及窗口污染。持续事件的后窗可能仍有锋面，不称“离开后”；再进入/重叠影响按预登记规则排除、分层或保留为相关案例，不临时挑结果。
- 前7、后1–3和后1–7各有资格、小时、面积时间、有效日期和排除。后7不足可保留合格短期描述，但完整后7能力不得记通过；比较两种后窗效果时给出共同合格事件子集及变化，不能把样本变化当时滞差。
- 日级时滞图标明各相对日的事件数、独立组和分母。若可用事件随时滞变化，主比较采用冻结的共同队列/支持或标准化方案；其他可用案例图单列，不连成同一稳定样本趋势。

### 5. 同支持指标与前后效应

- 复用A/P0可加基础量：同日固定区域上的真实表观捕捞小时H与有效面积时间E；不同窗口分别汇总H与E，再求h/(km²·d)密度。总小时和明确有效日数的日均另列，不直接比较7天与3天原始总量。
- 固定区域不等于有效支持固定。前后覆盖位置/面积改变时，主分析用事先明确的共同空间支持或有依据的标准化/配对方法，使两侧可比；仅除面积不能自动消除观测位置变化。交集过小或无从判断时限制比较并解释。
- 缺测、覆盖未知、无记录与有效零按P0合同分开；陆地、未知和无效区域不进有效分母。分母0/未知不给密度；合法多船累计大于24小时不自动当异常。
- 每个事件分别输出前期、短期、延长窗口与同支持差值，保留双方原始分子分母、日期及实际单位。相对变化仅在有效正基线时计算；零或未知不加伪计数、不输出无穷增强，仍可给可计算的绝对差。
- 默认关注归一化前后差与同日对照差，效应和不确定性优先于显著标签。多个事件的汇总目标与权重在正式计算前冻结：事件等权均差与按面积时间合并的差是不同估计对象，分别命名、不可互换或平均均值后冒充整体密度。
- 所有汇总可回到事件与日级H/E。重复源、重叠锋面、嵌套半径和同日对象去重；多半径是敏感性，不相加也不作为额外独立样本。

### 6. 同日对照、可比性与解释边界

- 从预登记且P0支持的候选区域中构造同日非锋面对照，明确空间域、固定几何、排除锋面条件、日期、覆盖和可测环境匹配规则。旧至少50km只能是需核实的一项候选排除条件，不自动代表可比。
- 控制区域及权重的选择不得依据最终活动低值、后窗增强或有利效果。前后变化比较尽量保持同一固定对照区域/组合及冻结权重；若必须变化，说明标准化和目标量，不悄悄将不同海域拼成一个前后对照。
- 核对实际支持的位置、季节/日期、距岸、SST/水深等因素，报告已控制与缺少因素、匹配差异、候选数、匹配率及失败原因。水深/渔具等没有就如实记录，不想象补齐，不为B默认扩大付费/下载范围。
- 非锋面资格按所需对照时段检查，保存对照后续进入锋面或缺日等情况。若描述分析使用整个窗口的事后观测筛选，明确它是回顾性条件比较，不说成当时已知的预报或随机对照；候选只看前期资料的规则也须记录，不能混用。
- 事件区前后差、事件区与同日对照差分别表达。若补充“事件区变化−对照变化”，对四个组成量保持同支持并说明混杂/趋势等假设；它不自动成为因果效应，也不能以没有前期差异证明全部假设成立。
- 没有合格对照时返回描述降级与未匹配列表，不补空海域，不把无法比较写成没有响应。对照复用、共享日支持与权重进入后续相关分组。
- B只能报告观测到的活动变化/响应及限定条件；AIS接收、算法、船型、天气、管理等局限随证据说明。不能推出锋面导致作业、鱼更多、渔获/收益提升、成功概率或预测增益。

### 7. 相关事件、区间与检验

- 先输出候选、合格事件、窗口记录、多半径展开行、有效日期及依设计可用的独立组数量，不能把旧186行或新表行数当样本量。一个持续事件不是每日多个独立事件。
- 相关关系至少检查相邻事件、重叠前后窗口、嵌套范围/海域重叠、同日影响与复用对照；保留组成员和理由。规则分组后仍要说明跨组独立性假设，不声称按事件ID分组就解决全部时空相关。
- 按有依据的事件组/时间块重采样，保持组内事件、前后、目标/对照和多窗口/半径的对应结构。聚合权重与目标估计量共同冻结；每次按选定估计量重算可加基础量和效应，不使用旧逐行独立重采样。
- 记录组/块方案与长度、次数、种子、区间水平/方法、容差、失败比例和退化处理。小样本、只有少数可用组、全同值/零分母或假设不成立时不给貌似精确区间，返回可推断范围及原因；增加重采样次数不能补充真实独立信息。
- 成熟实现可参考[SciPy bootstrap官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)和[时间序列bootstrap官方说明](https://arch.readthedocs.io/en/latest/bootstrap/timeseries-bootstraps.html)。前者配对选项与后者块抽样是可复用组件，不能替代Ocean对事件依赖、估计量与边界的设计；具体方法/依赖按实际数据验证冻结，不要求全部采用。
- 置换/符号翻转仅在组级可交换/对称等假设有依据时补充，保留整个相关组并说明检验对象；无法论证时不执行或仅保留明确探索用途。p值不是必有字段，也不证明因果。
- 多窗口/半径/事件定义区分主与探索，正式多项检验先登记检验族及处理，否则报告探索性区间和限制；不从大量结果挑一个显著值作主结论。

### 8. 冻结、敏感性与负结果

- 正式目标期效果计算前冻结：真实来源/粒度、固定几何、进入/退出/再次触发与缺口规则、锚日、边界上下文、前后窗、共同支持/门槛、对照、主要效应/权重、分组推断和敏感性清单。探索样例可检验精度/误触发，不按最终活动显著性选规则。
- 至少检查P0支持的多个半径、事件距离/持续/再次触发规则、跨日缺口、边界支持、窗口共同队列、对照匹配、相关分组及合法大值影响；执行有界且有依据的变体，不承诺所有组合穷举。
- 主方案保留全部合法值，其他异常处理有依据、独立身份及完整结果；每个变体同时报告事件成员/锚日/支持变化与效应，不把换了事件样本的差异仅解释成模型参数效果。
- 多半径会改变事件集合或锚日时，登记跨方案对应关系、共同案例和不一致项，不能当三个独立重复。旧结果、改动理由、数据与参数版本保留，不静默覆盖。
- 已探索的2024-07/08不冒充跨期未见验证；B是当前范围的回顾性分析，独立跨年/季节/海区复核归G3。无稳定变化、反向和对照无法匹配均保留，验收不要求显著或增强。

### 9. 结果合同、图表与执行

- 优先扩展A交接的确定性请求/结果与已有API测试模式，明确B用途/版本和只读结果；受控批处理与服务使用同一核心合同，不再造平行统计引擎或测试专用业务API。
- 返回任务/结果身份、提交条件、实际读取期、资格与缺口、候选/入选事件及相关组、固定几何和日级支持、各窗H/E/效应、匹配/未匹配、区间/检验状态、敏感性、图表数据、证据和局限。未知、无事件、无效分母、无对照和无明显变化分别表达。
- 结果至少含事件时间线/清单、相对日时滞主图、前后及同日对照表、窗口覆盖和相关组说明。主界面只消费简短解释和一张主图，其他证据按需展开；图上标单位、样本变化及区间可用性，不连过缺测造趋势。
- 图、表、摘要及许可允许的基础聚合导出由同一不可变快照派生，旧响应标签/增强规则不重新包装为新研究结论。基本阅读产物可独立验收，完整PDF/案例库由后续成果模块承担。
- 显式提交才执行，改条件不自动重分析；只读和访客不能触发归档准备/重计算。沿用A受控执行与最小任务记录，成功校验后才发布，失败/中断不把半成品当完成；不在B重复完整队列、恢复或身份平台。
- 请求、资料、区域/事件、质量、窗口、对照和推断版本共同决定复用身份，不能仅按日期/F编号缓存。更换来源或规则有新结果，源身份未知不冒充当前资格；直接计算与复用在冻结容差内一致。
- 内部细资料与公开聚合分离，许可和署名按P0核实的实际来源执行；未知授权不自动公开。C/#20消费兼容的区域/事件证据，W/#21后续接按钮及浏览器联动，AI只解释已计算值；不将这些集成视为B已实现。

## Testing Decisions

### 1. 已确认的主要验证入口

以“显式提交固定区域事件响应请求→实际识别/窗口/对照/汇总链→读取同身份结果与证据”为主要端到端入口，优先沿用现有FastAPI测试客户端、确定性响应检查及A的受控执行/结果合同。内部批处理走同一计算合同；已有旧产物查询的回归保留其旧用途。

独立可手算空间/日历夹具验证事件识别、锚日、前后分子分母、对照和相关组；真实合格事件及真实前7/后1–3/后1–7窗口另行复算记证。图表、摘要和基础导出作为同结果的消费核验；工作台浏览器联动在#21后续验收，不等待全部工作台或AI完成才验证B数值。

用户已于2026-10-24确认上述边界：显式事件请求贯通实际识别、窗口、对照、汇总与同身份结果/证据；独立手算小例核对锚日、缺日/再进入、跨月窗口、小时/面积时间与相关事件组；真实前7/后1–3/后1–7窗口与合成测试分开记证；复用现有API/受控入口，工作台浏览器联动在#21后续验收。此前UI、P0、P1和A验收各自继续有效，不能直接当作B已通过。

### 2. 好的测试和既有基础

- 检查请求/实际条件、事件成员及理由、独立支持、窗口端点、分子分母、匹配与效应、结果身份和可读产物，不绑定内部函数拆分、目录或图表DOM结构。
- 复用现有查询缺测不报零、覆盖/许可、来源身份及结果读取测试，借鉴旧实验运行清单、后7缺口与复现检查；旧行级区间和不同天数总量比较不能成为新B预期答案。
- 用解析几何与很短已知日历构造进入、持续、退出、再进入、缺日、前后差及对照；预期由独立手算/参照实现得出，不能用被测事件/聚合路径生成自己的答案。
- 统计检查验证组内结构、配对、权重、种子、退化状态和真实目标量，不要求小例显著。真实运行与合成边界分开，未跑/无访问明确记录，文档检查不等于研究通过。

### 3. 必须覆盖的外部行为

| 场景 | 验收证据 |
| --- | --- |
| 固定区与视野变化 | 前后几何身份一致，拖图/换屏幕不改变已提交区域 |
| 编号重排/多锋面/连续日 | 不凭每日F编号分裂事件，不重复小时，候选与归属可查 |
| 缺日与再次触发 | 缺测不等于退出，去抖/合并/再进入按冻结规则及理由复现 |
| 搜索期边界与额外上下文 | 左右截断不伪造进入，实际读取范围和锚日资格明确 |
| 无事件与观测不足 | 充分观测的无事件与无法判定分开，不补零响应 |
| 月初/月末与后7缺口 | 跨月逐日核对，短期可用不冒充真实后7，事件日0单列 |
| 持续暴露/前期或后期污染 | 仍有锋面或再进入有标记，不误称离开后或独立重复 |
| 3/7日比较与面积变化 | H/E可手算，前后共同支持有据，不比较原始不同天数总量 |
| 有效零/未知/零基线 | 无伪零密度、无穷增幅或伪计数，绝对差与原因保留 |
| 对照不平衡/变更/无法匹配 | 候选域、同日/前后支持、权重与失败可查，不造低背景 |
| 重叠事件/嵌套半径/复用对照 | 相关组与窗口共同结构保留，行数不等于独立样本 |
| 退化与敏感性 | 不强给区间，主/探索与成员变化清楚，不挑显著或删合法大值 |
| 同源输出/版本/执行失败 | 图表/摘要/导出一致，旧结果不串用，读取无重任务副作用 |
| 真实实例与无明显增强 | 实际完整窗口及对照可复算，不以正相关或显著为通过条件 |

### 4. 实施时的证据要求

- 保存实际输入和方法身份、固定几何、全候选与排除、前后逐日支持、匹配、组结构、效应/区间状态、种子、环境、运行范围和残余问题；真实受限细资料留在受控存储，公开记录不泄露私人路径。
- 从直接参照到结果消费核对数值容差，缓存/复用与同输入重算一致。若身份/支持无法核实，标旧结果和不能复算原因，不将其作为新资格。
- 实施时按影响运行后端、数据和必要结果消费回归；工作台集成再测浏览器。性能、容量、完整任务恢复和生产权限平台分别由对应工作包验收，不以B测试替代。

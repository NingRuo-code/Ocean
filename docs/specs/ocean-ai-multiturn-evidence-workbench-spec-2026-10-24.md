## Problem Statement

使用者希望围绕渔业活动研究连续提问：某片海域附近有哪些锋面、锋面与表观捕捞活动有什么关系、换月份或范围后怎样、不同区域是否可比、历史案例或预测误差说明了什么。系统已有功能较多，使用者不应先理解全部专业参数和页面结构才能获得可靠结果。

现有前端AI主要按本地快照组织规则文字；后端已有单次自然语言解析、可选本地模型、知识和工具证据结构，但未形成完整的多轮条件继承、本人受控任务执行、持久对话与证据阅读。旧“月度活动”仍可能是锋面频次而非A月度联合分析，角度裁剪与公里圆域也不能直接等同；模型接通、工具名称出现或结论带引用编号，均不足以证明任务正确且证据支持结论。

需要在已有确定性工具可靠后分批加入AI，降低操作门槛，避免猜测缺失条件、误用旧结果、重复付费或计算、泄漏私人/保留资料，以及把关系、规则参考或历史回测说成渔获保证或当前预报。

## Solution

在左侧可收起、非模态工作台的紧凑AI模块提供自然语言输入、少量任务建议和可展开的多轮记录。本人明确要求分析且条件、资格和预算具备时，直接通过同一W/TASK服务提交；仅改条件、阅读或解释不会启动重计算。缺条件则一次询问必要信息，回答后继续原意图；不明确时保留待处理状态。

每轮显示简短的实际条件及本轮变化，绑定原任务、结果、来源和证据版本。结果优先给清楚、简短且有依据的回答，详细图表与证据沿右侧摘要、底部详情和明确地图定位展开，保留原地图框架和两侧分工。AI理解、编排和解释，数值、比较与统计结论由已验证工具提供。

按能力逐项开放当前/历史查询、A/B/C、相似案例、独立复核和已登记预测实验的读取或显式执行；准备、任务操作、保存与导出复用原模块并保留各自意图和权限。提供本人限定的按需在线模型，落实供应方、模型版本、可外发字段、预算和超时政策，保留本地/规则及手动兜底。模块可先交付可靠A闭环，完整范围仍逐项验收，不因一个入口可用宣称全部AI完成。

## User Stories

1. 作为使用者，我希望在工作台直接提出研究问题，以便减少寻找多个入口的负担。
2. 作为使用者，我希望AI初始只占少量空间且可收起，以便地图始终是主视图。
3. 作为使用者，我希望快捷按钮与AI调用相同功能，以便两种入口不会得到不同口径。
4. 作为使用者，我希望看到当前实际可用的工具和范围，以便区分已支持、未接入和缺资料。
5. 作为本人，我希望明确要求分析且条件齐全时直接提交，以便不用重复确认同一个意图。
6. 作为本人，我希望仅改月份或范围时只更新草稿，以便不会悄悄重跑任务。
7. 作为使用者，我希望询问已有结果的含义时只读原证据，以便不会等待另一轮计算。
8. 作为使用者，我希望缺失或歧义条件被准确指出，以便补充必要信息后继续。
9. 作为使用者，我希望回答澄清问题后接续原意图，以便不必重复整句请求。
10. 作为使用者，我希望必要条件有多个时合并询问，以便避免逐字段反复打断。
11. 作为使用者，我希望明确看见沿用哪些条件，以便发现年份或区域继承错误。
12. 作为使用者，我希望本轮修改与原条件有简短差异说明，以便确认实际分析对象。
13. 作为使用者，我希望地图筛选、AI草稿、已受理任务和正在阅读结果分别保留身份，以便修改其中一个不会改写其他内容。
14. 作为使用者，我希望日、整月、事件窗口和预测签发日被分别理解，以便不会混用时间尺度。
15. 作为使用者，我希望公里半径和坐标经过合法校验，以便不用理解旧式角度接口。
16. 作为使用者，我希望“这里”“上一次”“另一片区域”等指代不清时先澄清，以便不误交任务。
17. 作为使用者，我希望连续或并发消息各自绑定正确上下文，以便迟到回复不会覆盖新条件。
18. 作为本人，我希望新会话或清空上下文有明确效果，以便旧对话不会暗中影响新分析。
19. 作为本人，我希望了解选定日期的锋面、海温和资料状态，以便先判断有哪些观测事实。
20. 作为本人，我希望历史频次仍以真实样本和范围解释，以便不把环境频次当活动响应。
21. 作为本人，我希望用自然语言运行完整月A并阅读距离和侧别证据，以便分析锋面与捕捞活动的空间关系。
22. 作为本人，我希望明确运行B固定海域事件响应，以便区分前7日、后1–3日和真实后1–7日。
23. 作为本人，我希望比较两个或多个已明确的区域，以便看到逐项兼容性和已有差值。
24. 作为使用者，我希望不兼容和失败区域仍有说明，以便不会只看到筛选后有利的结果。
25. 作为本人，我希望寻找相似历史情形并展开原响应，以便理解历史参考而非获得虚假成功率。
26. 作为本人，我希望独立复核只按已登记完整协议运行，以便对话不会改写研究冻结。
27. 作为本人，我希望读取或明确提交已登记的小范围预测实验，以便了解基线、提前量误差和锋面增量。
28. 作为使用者，我希望规则参考、归档实验、可核历史回测和观测被清楚区分，以便不把历史结果当今天预报。
29. 作为使用者，我希望无增益、反向或估计不精确被正常解释，以便研究结果不被美化。
30. 作为使用者，我希望每个关键事实能点开具体证据，以便核对指标、单位、时间和有效支持。
31. 作为使用者，我希望AI引用实际结果值而不自己补数，以便回答能独立复算。
32. 作为使用者，我希望真实零值、缺测、无事件、无对照和失败分别说明，以便理解没有结论的原因。
33. 作为使用者，我希望相似性、相关关系和预测增量有不同表述，以便不误认为因果或渔获保证。
34. 作为使用者，我希望一般原理与本次数据结论分别引用，以便知识说明不会冒充实证。
35. 作为使用者，我希望证据不足时得到明确限制和可操作下一步，以便知道还需什么资料。
36. 作为使用者，我希望摘要简短而证据按需展开，以便不用阅读大量评分规则。
37. 作为使用者，我希望只有明确定位才改变地图，以便阅读旧结果不会突然换日期或视野。
38. 作为本人，我希望任务提交、进度、失败、重试和取消复用公共任务中心，以便无需管理两套记录。
39. 作为本人，我希望重复发送或提交响应丢失时不会创建重复任务，以便避免重复工作和费用。
40. 作为本人，我希望关闭面板、离开再回来仍能查看原任务和回答，以便连续研究不依赖页面常开。
41. 作为本人，我希望停止生成回答与取消科学任务分别表达，以便知道实际停止了什么。
42. 作为本人，我希望资料未就绪时可选择一键准备，以便继续浏览地图并等待真实就绪。
43. 作为本人，我希望准备完成后由我再发起分析，以便不会形成意外的连续计算。
44. 作为本人，我希望保存选定结果及可选AI解释版本，以便日后追问时保留原含义。
45. 作为本人，我希望通过已有报告流程导出合法内容，以便AI不另外创造一套成果文件。
46. 作为本人，我希望重开旧回答时看到证据可读、权限及复算状态，以便不把过期引用当仍然可用。
47. 作为本人，我希望私人对话、任务和笔记不因公开演示被暴露，以便控制研究资料用途。
48. 作为访客，我希望继续使用公开地图和合法结果，以便在线AI本人限制不影响普通浏览。
49. 作为维护者，我希望直接请求也校验本人身份及逐源权限，以便不能绕过界面发起模型调用。
50. 作为研究者，我希望保留测试目标不会进入提示词、历史回复或缓存，以便不破坏独立验证。
51. 作为研究者，我希望AI检索和解释揭示的资料沿同一接触台账记账，以便已见资料不会重新包装为未见。
52. 作为本人，我希望知道使用的是规则、本地还是在线模型，以便理解能力、资料发送及费用边界。
53. 作为本人，我希望在线使用有已配置的模型、字段和预算，以便每次调用不必重复确认而不会失控。
54. 作为本人，我希望未获许可的资料留在系统内，以便读取权限不会被当成可发送外部模型的许可。
55. 作为本人，我希望超时、限流、预算不足和服务不可用有准确状态，以便可以选择手动功能。
56. 作为维护者，我希望模型循环、工具次数、上下文和输出长度有上限，以便不影响地图和已有任务。
57. 作为使用者，我希望模型回退时保留条件和限制，以便不同模型不会偷偷换问题。
58. 作为维护者，我希望外来文字不能改变工具权限或执行任意命令，以便系统行为受服务端合同约束。
59. 作为本人，我希望对话记录有可见的保存与清理规则，以便不无限积累敏感内容。
60. 作为使用者，我希望键盘和小屏也能阅读、澄清和查看证据，以便界面保持易用。
61. 作为负责人，我希望用预先登记的多轮用例核对任务和证据正确性，以便评价完整流程而非聊天效果。
62. 作为负责人，我希望真实模型、真实分析结果及合成故障分别留证，以便判断哪些能力实际完成。
63. 作为负责人，我希望按工具分批交付AI，以便可靠A能力不等待全部预测和多年实证。
64. 作为后续维护者，我希望保留模型、解释和工具合同版本，以便升级后仍可理解旧回答及复现限制。

## Implementation Decisions

### I01 归属、边界与增量复用

- [ ] 归属G4b及#13/#21，沿用#24界面、#95工作台、#109任务、#125成果、#141/#159研究与#176预测合同；本规格不替代、修改或关闭已有父级，不另造科学引擎、权限中心、任务中心或接触台账。
- [ ] 实施先核实际分支/服务、工具合同及输入支持；工具注册与Issue关闭只证明对应状态，不自动证明数据、模型或线上能力可用。基础后端稳定性是接入门槛，文档可先整理，不能在未验证基础上先做模型工具运行。
- [ ] 以可用工具纵向接入：当前/历史和A先形成核心，B/C、相似案例、独立复核与PRED逐项增加；每项记录只读/执行/真实资料证据，未接入显示准确原因，不将完整G3/PRED实证设为全部AI统一前置。
- [ ] 完整声明范围为上述工具的适用只读解释及本规格登记执行、准备/任务/保存交接和受控在线多轮；早期A里程碑不能标完整AI完成。新增来源或新研究算法另立规格。

### I02 原界面与同源阅读

- [ ] 左侧深色工作台仍为快捷功能和紧凑AI两个模块，筛选与图层各自浮层不占两个模块正文；右侧浅色保留当前/历史/预测，详细图表/方法在底部按需展开，不新增AI页签、常驻大统计栏或居中阻断框。
- [ ] AI初始输入加少量真实可执行建议，使用后可展开/收起记录；回答以短结论、实际条件和必要限制为主，长证据折叠。开关/生成/澄清期间地图可拖缩选点，保留原投影、海岸、网格、比例尺和既定色义。
- [ ] 原结果明确定位沿#107/#192等已有合同，普通阅读/解释不改全局日期、圆域或图层；图、表、摘要和回答标同一结果身份，多日/多区域不能伪装单日地图。
- [ ] 桌面完整操作，小屏保留基本输入、澄清、状态与证据阅读；键盘、Esc、焦点和滚动沿既有检查，状态提示不靠颜色或把握度百分数传达。

### I03 工具能力与统一服务接缝

- [ ] 以既有AI分析/能力服务为语言入口，必要扩展会话、轮次、结构化意图与结果引用，通过已有W/TASK受理及确定性查询调用；浏览器和模型都不直接读源档或研究底表，不为测试建第二业务服务。
- [ ] 每个工具登记任务/只读类型、必要条件、允许用途、输入/输出版本、权限、最大规模/成本类别、可取消/恢复行为和证据返回；只允许服务端白名单操作和合法参数。已有名称不构成科学语义兼容保证。
- [ ] 健康、能力、打开面板或查看历史采用轻量状态读取，不默认生成式探测、调用付费模型、扫档、准备或重分析；“配置了模型”“模型可达”“工具已验收”“资料合格”分别显示，公共响应不泄露内部地址/密钥。
- [ ] 工具返回实际规范化条件、支持/版本、任务/结果/证据引用、状态及限制；层间不能只传一段结论文字。兼容适配沿原合同，旧端点保留准确范围，不能把旧频次/角度窗口改名当A/B/C。

### I04 条件、上下文与轮次版本

- [ ] 分别保存已应用地图条件、AI待提交草稿、待澄清意图、已受理任务快照和选中结果；每轮绑定会话、消息/轮次、父上下文版本及选定证据，不以浏览器当前状态重建旧请求。
- [ ] 发送时固定上下文；明确文字优先于所选结果/草稿中的已知字段，继承规则和来源可核对。未应用坐标不自动当生效条件；新会话不无提示继承私人旧对话，选择继承当前已应用条件时显示该事实。
- [ ] 公里圆域、经纬度方向、日期/年月/窗口/签发语义由确定性校验处理；年份未知、多个候选区域或“最近”含义不清须澄清，不能回退最早档案日期、系统今天或把公里除常数当已核几何。
- [ ] 显示必要条件和本轮差异；地图后来变化不改已发送轮次。并发编辑按上下文版本处理，旧回答保留原身份，不覆盖当前草稿；指代多个可能结果时要求选择，不能随意取最新任务。

### I05 意图、澄清与直接提交

- [ ] 区分读取/解释、仅编辑条件、明确新分析/重算、准备、任务操作、保存/导出与不支持请求；自然语言不是任意执行授权。Q48条件齐全的本人明确分析指令直接提交，不再重复弹确认。
- [ ] 缺条件/歧义时只问必要信息，可合并询问并展示明确继承值；回答与原待澄清意图绑定，补齐后继续原明确执行意图。若用户仅问含义、改变目标或上下文已失效，不能当补齐后自动执行。
- [ ] “换成八月”“扩大范围”默认编辑；“换成八月再分析”可构成明确执行。“为什么有差异”只解释已有证据，缺所需结果则说明并提供显式任务入口，不能暗中运行新对照/统计。
- [ ] 前置变化、歧义未解、资格/权限/预算不足保留待处理或拒绝原因，不偷偷缩范围、换月、换源或补值。“准备后分析”拆开说明：本次可明确准备，准备完成只提示就绪，仍由用户另行发起分析。

### I06 确定性工具覆盖与科学语义

- [ ] 当前锋面/SST、最近锋面与环境历史频次使用已验证查询及真实覆盖/单位，区分点状态、线/对象距离、日F编号和固定圆域；不把示例海况、旧评分或环境命中率当渔业实证。
- [ ] A明确整月、H小时与E有效面积时间密度、距离/侧别、对照及相关组/区间；B明确固定区事件、锚日、前7日、后1–3日及真实后1–7日；C按原兼容合同分A/B板，保留所有候选、不可比/部分失败和已计算差值，不由AI新增平均、检验、排名或成功率。
- [ ] 相似案例消费#159/#165/#167等原检索与响应，说明候选库覆盖、特征/缺项与重复变体；辅助短窗只表达已验证关联/歧义/断档，匹配分数不变身份概率，也不把相似案例当独立预测验证。
- [ ] G3/PRED只在已登记且合格的协议/实验范围提交受控执行或读取已有结果，缺完整冻结不自动创建/选择/调参。解释保留独立性、输入可知时间、逐1/2/3日配对误差与覆盖、有/无锋面增量、空间/跨期适用范围；规则与归档条件/可核历史回测分开，不承诺当前滚动预报或渔获收益。

### I07 任务受理、有限编排与竞争

- [ ] 复用#99及后续受理、所有权、持久状态、取消/重试和预算；意图、会话轮次、计划步骤、公共任务/尝试与结果身份分别绑定，重复消息/响应丢失先查同意图记录，不靠按钮禁用防重。
- [ ] 明确复合请求可映射有限、可审阅的白名单步骤及依赖；每步有原意图、条件和范围，上限明确。失败保留已完成结果，不默默改计划或扩大工具集合，不构建无人值守开放式Agent循环。
- [ ] 解释生成、语言调用和科学任务分别有权威状态；停止回答只停止本轮后续语言工作，不能显示科学任务已取消。取消/重试科学任务须原权限和显式对象，按#101/#102处理完成竞争，不因生成失败重跑已受理分析。
- [ ] 关闭面板/离开不取消已受理任务，重开查询原记录；断网、服务重启或状态不明不自动重发。安全恢复消费TASK实际能力；恢复页面/任务后不自动再次付费生成解释或新建分析。

### I08 证据绑定与输出验证

- [ ] 科学数字、单位、比较方向、范围、样本量、区间和缺测状态从原工具结构化字段获得；引用精确结果及指标/分组/窗口，而非仅有一个存在的evidence编号。显示舍入/已登记单位转换由确定性格式化负责，派生科学量必须已有正式工具结果。
- [ ] 生成内容采用可核证事实引用与解释结构，服务端发布前校验引用确属本轮授权证据、版本/条件相容、数值/单位/方向及关键限定一致；无来源事实、越权引用、跨条件拼接或不支持的数值不能作为成功科学回答发布。
- [ ] 仅检查数字相同或让同一模型自评不够；关键事实优先确定性填充，文字结论用受控结构/词义约束及独立样例核查。无法可靠核证时保留已验证事实并降级模板/提示不足，记录拒绝原因，不宣称解决一切幻觉。
- [ ] 一般原理使用版本化领域知识并标为原理；本次观察、统计关联、描述差值、预测误差与建议分开。有效零、未知、缺测、无事件、未准备、不可比、区间不足、无增益/反向如实呈现，不能靠语言补成正向或因果。

### I09 解释与可操作下一步

- [ ] 首屏少量关键事实加短解释，附必要资料/方法限制和证据入口；完整条件、工具记录与方法按需展开，不能删除会改变结论含义的限定以追求简短。
- [ ] 对“说明什么”“为什么”“还欠什么”基于原结果解释指标、对照、支持与局限；未有因果证据时不能把相关解释成机制已证明，不能把活动集中解释成鱼多、收益或作业保证。
- [ ] 下一步给准确的可用动作与缺口，使用同一草稿/工具入口，不因建议被显示就执行。若证据只能说当前候选库无结果、样本不足或本范围无增益，回答保留该限定，不推广全海域/所有时期。
- [ ] 多份证据只按原合同可比部分解释；跨条件可并列阅读但不可新增联合显著性、拼接置信区间或挑选有利结果。关键研究边界不由模型自由改写。

### I10 准备、保存与导出的集成

- [ ] 查看任务、取消/重试、案例检索和保存/导出都经过原模块服务与当前权限；读任务或说明怎么导出不产生保存/导出副作用。明确保存须选定结果版本，明确导出须满足原用途/内容选择条件，不自动公开或发送他人。
- [ ] 消费REPORT已支持类型的案例/保护和报告合同；AI解释可作为明确选择的独立注释版本，记录来源、模型/规则版本和原证据，不能替换确定性正文或手改科学值。解释注释保存/导出所需最小适配属于本规格，原PDF/PNG/CSV平台不重建。
- [ ] G3/PRED等尚未具备REPORT类型适配的成果仍可合法阅读/追问，导出明确未支持并交接缺口，不假称PDF可用或复制其他类型模板冒充完成；新增研究类型完整报告另行验收，不将整套REPORT结项设为基础AI前置。

### I11 持久对话、版本与清理

- [ ] 本人会话保存最小轮次、实际条件/差异、澄清/执行意图、工具/任务/结果引用、已发布回答与模型/提示/解释合同版本、状态和时间；多轮不只依赖浏览器内存，不保存隐含推理过程或不必要原始提示副本。

- [ ] 会话轻量记录、可选长文本/模型临时内容、TASK科学记录及REPORT主动保存内容分层管理；给出实际字节/时限预算和可见清理规则。清空/删除会话不等于取消科学任务、删除原研究结果、解除其他成果保护或清除资料接触历史。

## Testing Decisions

主验收接缝已获用户确认：采用一条真实浏览器“多轮输入/澄清或显式操作→既有AI语言入口→同一受控工具及W/TASK服务→原任务/结果→可读回答与证据”的流程。以服务端记录、原确定性结果和独立已知期望辅助核对；只为必要适配扩展原入口，不新增测试专用业务服务。用户已确认以下验收边界。

1. **外部行为优先。** 在真实浏览器从当前已应用条件开始，完成“分析整月→追问指标→只改范围→明确再分析→比较区域→重开旧结果”的多轮过程，核任务受理次数、实际条件差异、当前选中结果及引用；仅出现聊天框、调用记录或截图不算通过。A先闭环，其他工具按实际能力分别加入。
2. **独立条件与证据小例。** 用可手工核对的日期、公里圆、H/E、零/缺测、事件窗口、C不可比和预测误差小例，核语言意图对应原工具数值、单位、方向、范围和限制；加入同值但不同时间/单位、引用存在却不支持结论、反向/无增益和缺失区间反例。不在AI重算科学引擎。
3. **真实服务、幂等与竞争。** 辅助API核本人/访客、消息重复/响应丢失、上下文并发/乱序、旧任务迟到、断网/刷新、停止生成与真实取消、明确重试、模型失败而任务成功；断言不重复付费提交或科学受理、不串条件、不伪报取消。服务端权威记录和实际操作留证，合成客户端状态只验对应分支。
4. **准备与成果交接。** 用实际TASK准备及REPORT已支持的合法小范围成果验证计划读取无副作用、明确准备、就绪后不自动分析、选定结果保存/注释版本、重开及允许导出；未知类型明确未支持。核保护、权限、原结果身份与文件内容，不重测全部PDF平台；新增注释若进入PDF，应实际渲染检查文字/来源及未覆盖原结论。
5. **资料、外发和保留集。** 用已知合法探索样例、混合权限证据、伪造身份、撤销许可、角色/接触服务失效和注入文字，通过实际服务检查检索/历史/缓存/提示投影/直接ID的边界。受控假供应方可捕获外发字段用于反例，真实在线只用已明确许可的最小样例；保留目标与敏感内容不靠真实泄漏来做实验。
6. **模型与有界成本。** 规则/本地回退按真实可用能力记证；在线方案在配置和预算落实后实际跑固定开发及独立验收用例，记录模型/提示/工具版本、响应、延迟和用量/计费可核状态。以受控故障验证限流、超时、未知计费、输出截断、非法工具、步数/上下文/并发/费用上限，不对生产做无界循环或压测。
7. **交互共用。** 沿现有浏览器交互/布局检查和后端API测试经验，操作两侧收起、AI展开、独立筛选/图层、地图、底部证据、键盘/Esc及手机基本阅读。原结果定位为明确操作，生成/长任务不阻断地图，旧观测和历史回测不能呈现在今天标题下。
8. **真实关口分账。** 各必需工具至少消费其对应已交接的真实合法成果，A整月、B真实事件窗口、C真实区域比较、G3案例/复核和PRED真实回测分别记证；没有来源成果时保留该工具真实集成未完成，不以合成成功或聊天正向结论替代。已有科学成果可复用，不为AI制造新显著性或要求预测增益。真实模型和真实科学成果的证据维度分开。
9. **既有测试与完成定义。** 复用现有自然语言参数、工具证据、模型不可用回退的API测试经验，以及工作台/数据/布局检查；旧角度近似和默认最早日期断言不能当新合同。完成需多轮正确执行/解释、同源证据、权限/保留隔离、持久重开、有界在线模型及手动降级均经实际验证；规格、代码、PR/合并和部署分别记录。

## Out of Scope

- 重做P0审计、A/B/C统计、G3检索/独立复核或PRED标签/训练/回测；AI只适配并消费已验收合同，不由模型产生科研数值、筛选有利结果或新建未登记研究。
- 重新设计已确认界面、替换原地图框架、另建任务中心/权限/接触台账/案例或PDF平台；必要AI会话、语言适配、解释注释版本及上述实际交接属于本规格。

# Ocean PRED 活动预测基线与独立历史回测实施规格

整理日期：2026-10-24。来源：总体规划L2/G4a、Q21/Q23–Q25/Q31及预测实验协议PRED-01–06、METHOD-06/07。状态：已发布 [规格 #176](https://github.com/NingRuo-code/Ocean/issues/176)，标签 `ready-for-agent`；验证边界已获用户确认。本轮未训练模型、运行回测或取得预测增益。发布标题：`[Spec] PRED 活动预测：可知输入、简单基线与锋面增量独立回测`。

执行任务已按用户确认发布为#177–#198：[22项任务与阻塞关系](../tickets/prediction-baselines-and-independent-backtest/README.md)。本行仅为本地导航，远端规格正文保持不变。

## Problem Statement

使用者希望知道：在某个历史时点，利用当时能够取得的活动、海温和锋面资料，能否判断选定海域未来1–3天的表观捕捞活动集中情况，以及锋面信息相比简单历史参照究竟增加了多少价值。

当前预测页仍是锋面信号、近几日持续性和历史频次组成的规则参考，带有旧式百分数和1/3/7日窗口展示。它不是以活动小时为标签训练的模型，也没有形成可信的资料时效、冻结切分、独立误差及增量评估。页面有预测入口、A/B相关性成立或找到相似案例，都不能证明预测能力。

正式实验需要避免未来信息、重复使用已查看测试资料、随机拆邻日邻格、比较不同测试子集以及只优化锋面模型。还须区分真实当时输入回测与使用事后归档资料的假设性实验，说明目标活动、空间支持和缺测，不能用鱼量、渔获、收益或作业成功率作替代承诺。

## Solution

提供显式提交的历史预测实验：选择已登记的区域/公里范围、签发时刻、逐日提前量和冻结协议，按P0核实的目标及输入支持生成可知特征，运行简单活动基线，再受控比较可解释模型和一类成熟树模型，独立评价不含/加入锋面信息的差异。

先完成局部研究和原生支持上的预测阅读，再在资料、空间验证和容量成立后扩展东海分布浏览。主输出为各目标日的活动强度，辅助输出为相对可知历史常态的变化；每个结果带单位、签发/目标时间、实际空间支持、输入时距、实验版本、误差和局限。地图与右侧预测入口只消费同源成果，模型训练/回测由本人主动发起，不因换条件自动执行。

交付可复算的基线、候选选择记录、冻结测试结果、锋面增量/无增益结论、失败分析和模型卡。资料不足可先交可行性、软件通路及有支持的基线，但对应真实模型、独立评估和空间推广关口保持未完成。当前滚动预报、完整AI和新增报告类型的系统导出另行验收。

## User Stories

1. 作为研究者，我希望明确预测的是表观捕捞活动，以便不会把结果理解为鱼量或渔获。
2. 作为研究者，我希望分别预测签发后第1、2、3天，以便不会混淆逐日结果和累计窗口。
3. 作为使用者，我希望先研究选点及公里范围附近海域，以便贴近实际参考场景。
4. 作为使用者，我希望后续可以浏览真实支持的东海分布，以便从区域概览缩小到局部。
5. 作为研究者，我希望主指标单位和空间支持明确，以便不同范围的活动强度可解释。
6. 作为研究者，我希望相对常态变化与主强度分开，以便低常态大增幅不会冒充高活动。
7. 作为研究者，我希望有效零、缺测和未知覆盖分开，以便不会制造虚假标签。
8. 作为研究者，我希望标签不会依未来锋面出现筛选，以便比较锋面价值时目标不被改变。
9. 作为研究者，我希望知道每项资料的观测、发布、版本与签发时间，以便判断当时是否可用。
10. 作为研究者，我希望事后修订资料有明确标记，以便不把归档实验说成历史实际预报。
11. 作为研究者，我希望真实可知时间不明时仍可做有标注的归档条件研究，以便保留诚实的实验范围。
12. 作为研究者，我希望活动、环境和锋面历史窗口按日历定义，以便缺日不悄悄改变输入含义。
13. 作为研究者，我希望只用签发前可得的活动历史，以便不会引用未来响应结果。
14. 作为研究者，我希望质量特征只来自当时已知信息，以便目标覆盖和误差不会泄漏进输入。
15. 作为研究者，我希望先核实真实联合覆盖与样本，以便不以单月或复制样本冒充完整预测资料。
16. 作为研究者，我希望探索、训练、时间验证与最终测试分开，以便方法选择不接触最终答案。
17. 作为研究者，我希望既有演示、G3复核和案例检索接触可追溯，以便不会重复命名为未见资料。
18. 作为研究者，我希望同一签发日和相关空间样本成组划分，以便邻格不会被随机分入两侧。
19. 作为研究者，我希望检查训练标签和输入窗口跨界，以便延迟标签与重叠窗口不造成泄漏。
20. 作为研究者，我希望时间泛化与空间泛化分别评价，以便不把原海域后期表现当新海域能力。
21. 作为研究者，我希望在最终测试前冻结目标、样本、模型和评价，以便不按测试结果改规则。
22. 作为研究者，我希望揭示后更改方法有新版本及新复核要求，以便保留真实研究过程。
23. 作为研究者，我希望先跑最近状态持续性基线，以便知道复杂模型是否值得使用。
24. 作为研究者，我希望再比较固定近期窗口均值，以便有简单可复算的历史参照。
25. 作为研究者，我希望资料足够时加入季节常态，以便不把季节变化全算作锋面增益。
26. 作为研究者，我希望基线缺输入时清楚拒绝或降级，以便不会偷偷使用未来记录补齐。
27. 作为研究者，我希望先建立可解释模型，以便理解条件和误差。
28. 作为研究者，我希望只增加一类有依据的树模型候选，以便控制复杂度和调参成本。
29. 作为研究者，我希望依据连续非负含零活动的诊断选分布，以便不会机械套计数模型。
30. 作为研究者，我希望预处理、插补和特征选择只在训练部分拟合，以便不泄漏验证答案。
31. 作为研究者，我希望早停也使用合格时间验证，以便工具默认随机划分不会破坏协议。
32. 作为研究者，我希望不含锋面和含锋面模型使用相同其他输入与预算，以便增量比较公平。
33. 作为研究者，我希望同一目标样本被所有对照一致评价，以便不能挑掉难预测的记录。
34. 作为研究者，我希望同时看到预测覆盖和未输出情况，以便少预测不能冒充误差更小。
35. 作为研究者，我希望分别报告1/2/3日误差，以便知道每个提前量的效果。
36. 作为研究者，我希望主误差和加权规则事先明确，以便不只展示最好指标。
37. 作为研究者，我希望锋面增量有配对误差与相关样本依据，以便不会把邻格当独立重复。
38. 作为研究者，我希望误差区间与单次预测区间分开，以便不把研究不确定性当成功概率。
39. 作为研究者，我希望按季节、海域、活动量和资料时距分析失败，以便知道何时不适用。
40. 作为研究者，我希望无增益、反向增益和区间不足同样保留，以便不预设研究答案。
41. 作为研究者，我希望热点辅助评价仅在有支持时启用，以便不会为画热点而选择测试阈值。
42. 作为使用者，我希望右侧预测摘要说明基准、目标日、强度和误差，以便快速看懂。
43. 作为使用者，我希望规则参考、归档回测和历史可知输入回测有清楚区分，以便不会误认正式预报。
44. 作为使用者，我希望预测与观测图层明确区分，以便目标日实况不被当作模型输出。
45. 作为使用者，我希望地图只显示实际预测支持，以便不会用插值或LOD创造精度。
46. 作为使用者，我希望改条件后保留旧结果原身份并提示待更新，以便不自动重复训练。
47. 作为使用者，我希望明确点击才提交耗时实验，以便地图仍可继续操作。
48. 作为使用者，我希望未支持的地点、半径、提前量或模型明确提示，以便系统不静默替换条件。
49. 作为维护者，我希望实验、训练产物和预测结果各有身份，以便旧模型不会冒充新版本。
50. 作为维护者，我希望只读已有成果不会自动取源、准备归档或训练，以便权限与成本可控。
51. 作为维护者，我希望本人执行与访客读取分别检查，以便测试目标和受限资料不会泄露。
52. 作为维护者，我希望执行有资源预算和真实状态，以便不会把训练拖垮服务器或伪报进度。
53. 作为维护者，我希望失败、中断和部分结果不覆盖已完成实验，以便保留复算依据。
54. 作为维护者，我希望使用成熟组件并记录环境和默认行为，以便模型能复现而非只写方法名称。
55. 作为负责人，我希望真实基线、候选训练、独立增量、空间推广分别记进度，以便准确跟进。
56. 作为负责人，我希望资料不足时知道还能完成哪些工作，以便不会以缺口报告冒充研究完成。
57. 作为后续集成者，我希望模型卡、误差图表与聚合证据同源，以便报告和AI正确引用。
58. 作为使用者，我希望手机能基本查看预测及限制，以便核心阅读不完全依赖大屏。
59. 作为研究者，我希望所有后处理和异常预测都可追溯，以便负值裁剪或变换不会隐藏问题。
60. 作为负责人，我希望当前滚动运行与真实作业效果另行验证，以便历史实验不被夸大为业务能力。

## Implementation Decisions

### I01 范围、现状与阶段

- [ ] 归属L2/G4a及#13，落实PRED-01–06/METHOD-06/07；复用P0#35、A#60、G3#141/#159、W#95和TASK#109，不修改或关闭既有父级/任务。
- [ ] 当前前端规则参考及其百分数、历史锋面频率不是活动监督预测基线/模型；旧1/3/7日规则窗口不扩张正式逐日1–3天研究，保留时独立标注，不混作新模型成果。
- [ ] 分别验收可行性/软件、真实基线、候选选择、最终独立锋面增量、局部分布和东海扩展；不以某项完成替代全部，也不要求正向或显著增益才能验收正确研究。
- [ ] 主目标为AIS表观捕捞活动强度，辅助为相对常态变化；不预测鱼量、渔获、收益或作业成功率，不将A/B关联或相似案例当预测验证。

### I02 真实可行性与用途资格

- [ ] 在读最终测试关系前登记候选区域、公里范围、年份/季节、实际粒度和提前量，核P0按预测用途的活动标签、输入及版本/许可，不将某层档案年限当联合支持。
- [ ] 复用A#71合法逐日H/E、几何及距离等加工合同，G3#143提供跨期覆盖，#144/#145提供接触与相关分区；按实际可用基础接入，不重复源审计或A数值引擎。
- [ ] 先盘点开发、选择与未见测试能否同时支持相应目标；一个完整月或反复演示的2024年七八月不自动够用，不复制样本、不虚设统一最小年数/组数。
- [ ] 资料、许可、实际访问、质量和独立性分别判定。未准备、缺测、读取失败、未知覆盖及无锋面但有效观测不同；缺前置列明能做的基线/描述及不能声称的范围。
- [ ] 真实样本不足时完成合法可行性和软件/已支持基线，真实模型与独立评估关口未完成；不自动购买、全档下载、扩容或放宽分析粒度，重要粒度变化沿既有ADR处理。

### I03 标签、固定几何与空间支持

- [ ] 首批目标为签发基准t之后第1、2、3个日历日的活动强度，分别标提前量；时区、日界及签发时刻冻结，累计/1–3日均值仅作为另有定义的衍生摘要，不能互换标签。
- [ ] 主标签使用P0认可固定区域/原生空间单元上的活动H/E及明确单位，保留小时和有效面积时间；有效零可作目标，未知/目标缺测不填零，E为零时不可计算。
- [ ] 目标几何、海陆/服务掩码和空间单元在训练/协议阶段确定，目标有效支持/质量可在事后核标签，但不能据测试活动值或未来锋面位置选择样本、调整圆域或决定只评价靠锋面的海域。
- [ ] 预测活动标签按其自身活动观测支持定义，不直接搬用依未来锋面/SST有效性或距离分带裁切的A结果作目标；复用A基础量时核实际分母/掩码，不能让加锋面组改变预测对象。
- [ ] 部分覆盖的实际E、缺失面积与标签含义必须说明；覆盖变化不能无记录地改成全固定区强度，不能外推未观测海域或用未来共同掩码回头美化历史服务范围。质量准入规则在揭示前固定并对所有对照相同。
- [ ] 登记原生预测单元与点位/公里圆映射、边界和聚合方法；密度不直接求和，不能用显示格/插值创造预测精度。首个固定圆可作小里程碑，但只有产生实际受支持空间单元结果才可称局部分布完成。

### I04 输入时效与归档条件

- [ ] 每项输入记录观测区间、可获得时刻证据、版本/修订、生效/加工与获取信息；每次签发只使用该时刻已合法可得的相应版本，观测日早于签发不自动证明版本当时存在。
- [ ] 划分可核历史当时输入回测和明确假设的归档条件回测；首次发布/修订信息不全或仅有事后重处理档案时标后者，不能声称真实历史运行预报或当前可执行时效。
- [ ] 标签只在评分时使用，训练/验证所需标签还须在对应拟合/选择时刻已经可得；签发后才发布的活动、未来锋面/SST、B后窗响应及G3结果不得回填输入。
- [ ] lag与滑窗按日历及可用性构造，注明最近可用活动距离签发多久、缺日/最大时距规则；不能把最近若干记录伪装固定几日或从未来回填。
- [ ] 输入质量/缺测特征只用签发时已知信息，目标日覆盖、事后匹配成功、最终有效样本标记和预测误差不能作特征；目标缺测可影响事后评分资格，但不改已保存预测。
- [ ] 历史可用性假设、延迟/修订敏感性与无法核实时的限制随结果保存；两组模型使用同一可知性模式，不将归档组增益与真实可知输入基线混比。近期实时资料接入仍归G6a。

### I05 分区、接触与冻结

- [ ] 在模型/特征/阈值选择前保存探索/训练、时间验证及最终测试清单与实际接触历史；G3独立复核、相似检索/人工查看过的目标均如实记录，不能换名称重当未见。
- [ ] 复用#144/#145的权威登记与组关系，新增预测用途、签发/输入/标签支持和相关性检查；不新建第二份互相冲突的保留集台账，普通浏览不得揭示封存测试目标。
- [ ] 时间验证按签发时间推进，同签发日空间批次及相关单元成组；训练标签越过验证/测试禁用边界或尚未发布时必须清除，不能只比较输入行时间戳。
- [ ] 检查重叠目标窗、相邻日、共享原生网格、重叠圆域及重复半径，依据真实支持/相关结构冻结隔离和分组，不机械指定一个通用间隔，也不对逐行邻格随机切分。
- [ ] 最终揭示前冻结标签/空间支持、资料时效、样本与排除、变换/特征、基线/候选及预算、早停/种子、指标/权重、推断、多重问题和后处理；冻结内容及实际揭示时间可查，不能倒填。
- [ ] 揭示后修改另立实验版本，原结果保留且原测试成为已接触；新的确认性声明需新合格未用于选择资料。时空泛化各有留出/组依据，时间后期测试不自动证明新海域泛化。

### I06 特征与加工隔离

- [ ] 特征按活动历史、时间/区域、环境基础、锋面和当时质量分组，记录定义/单位/窗口/版本及可知性；只用已取得资料，不承诺未接强度、天气或外部预报。
- [ ] 锋面候选限可知的最近距离、可判定侧别、出现/接近及短历史特征，未知侧别单列，不依赖深入生命周期、未来几何或事后确认的事件进入日。
- [ ] 先切分，再在各折训练部分拟合标准化、插补、编码、特征选择及常态/阈值；验证/测试只应用已拟合变换，不对全数据先求均值或按最终结果筛特征。
- [ ] 原生支持及合法聚合加工复用P0/A，训练输入与目标表及事后质量字段分开，记录样本/特征身份，禁止地图LOD或相似检索后窗摘要成为预测真源。
- [ ] 地点/区域编码可能记住已见位置，使用时记录服务支持和空间验证；各组可用/缺测掩码透明，不将锋面缺测记为没有锋面，不用未来目标质量作缺失指示。

### I07 可复算简单基线

- [ ] B0为最近实际可用且合格的活动状态延续，注明观测时距及冻结最大时距/缺项策略；无合法前值明确不可用，不取未来第一条记录。
- [ ] B1为训练阶段选定的固定近期日历窗均值，记录有效日/支持及缺日策略；近7日可作探索候选，不能在测试后挑最佳窗或变成最近7条记录。
- [ ] B2季节/区域常态仅在真实历史支持足够时启用，季节窗口、参考年份、权重/支持和不足处理在训练/时间验证选择；首轮拟合常态不读取最终测试标签。
- [ ] 三类基线按同签发规则输出逐提前量结果，同目标单位、空间支持和可知时间；不能以锋面出现率、旧规则分值或B响应增强标志冒充活动基线。
- [ ] 各基线保留实际可预测样本与失败/缺项、环境/配置和直接手算参照，允许B2暂不适用；基线齐全与独立模型评估分阶段，不因复杂模型未完成伪造预测。

### I08 成熟候选与有界选择

- [ ] 在真实训练/时间验证支持成立后建立一个可解释简单回归基线，并按诊断比较一个必要的加性/连续非负含零适配候选；再比较一类成熟梯度提升树，不承诺所有模型族同时实现。
- [ ] 分布、零值、响应/暴露量和相关性决定家族/链接/损失，活动小时不是整数计数，不能仅因非负就默认泊松或负二项；异常与非负后处理在选择期确定，不为测试临时改值。
- [ ] 复用成熟组件并登记原方法/官方实现、版本、默认行为、适配假设、环境和采用/放弃依据，先复现小型基线；不自写优化器，不以模型名称或特征数量证明创新。
- [ ] 同一时间/分组验证内调参、早停与选特征，限制候选数、预算及复杂度。工具默认随机验证不得静默使用；可关闭内部早停或传入当前安装版本支持的合格时间验证，但不得使用最终测试早停。
- [ ] 首轮最终测试使用预先冻结的拟合模型/训练截止；滚动重训若以后启用须另冻训练更新日程与标签可得性，不能看测试误差后临时重训。合法已可知活动lag可随签发更新，和模型重新拟合分开。

### I09 公平锋面增量实验

- [ ] 实验包含简单活动基线、非锋面输入模型及同模型家族加入锋面特征的模型；首先评价整组锋面加入/移除，再在样本足够时做有限预登记特征组分析。
- [ ] 配对组保持标签、源/时效版本、签发与目标ID、几何、训练/验证/测试切分及其他输入一致；“无锋面”组可保留相同SST/时间/活动特征，但不夹带由锋面生成的距离/侧别等派生泄漏。
- [ ] 对两组采用同等选择预算和验证方案，分别合理调参并记录全部尝试/失败，不能只优化锋面组或拿弱基线作为唯一对照；选择最终候选只看训练/验证。
- [ ] 预先确定目标有效性及模型可用性下的共同评价队列，区分完整服务候选、有效标签、各模型产出与配对样本；锋面缺测不改变目标定义，不能依据误差或响应值挑子集。
- [ ] 某组未输出/计算失败时保留失败率与适用覆盖，配对指标仅对明确共同支持解释，不能靠少预测困难样本宣称增益。条件子集比较同时报告排除及全服务覆盖，不将其说成全部请求效果。
- [ ] 采用同样本损失的配对差/技能衡量增量，方向、分母、聚合和不合格样本策略冻结；基准误差为零时技能不可定义，不输出无穷值，不把预测改善或重要性当因果证明。

### I10 误差、相关区间与失败

- [ ] 主指标为同目标单位的MAE，逐提前量报告；样本/签发日/区域/面积权重及跨提前量汇总在测试揭示前冻结，RMSE等辅助量单列，不只挑最好的一天或指标。
- [ ] 图表保留各模型绝对误差、配对增量、有效目标/预测数、覆盖/未输出、资料时距和排除，不能只报相对提升百分比或平均分掩盖支持差异。
- [ ] 配对增量的不确定性按相关时间块/空间组联合估计，保留同签发日、重叠目标、相邻空间和嵌套范围相关性；复用G3/A成熟分组方法，组不足只报描述和原因。
- [ ] 多提前量/模型/特征组的主次问题族及必要多重处理预先登记；误差增量区间不等于单次未来活动预测区间，没有另行有效方法与检验就不画预测置信带或概率。
- [ ] 按预定季节、海域、活动量、覆盖和输入时距分析失败；事后用目标强度分层仅作诊断，不变成签发时可用的选择/推荐规则。反向增益、无稳定增益、极端误差与区间不足均保留。
- [ ] 所有预测变换、逆变换、负值裁剪或上限处理在选择期冻结并同时适用于公平对照，保留原输出/异常计数和影响；不以合法累计大值为错误删测试样本。

### I11 真实独立证据关口

- [ ] 真实基线、模型选择和最终回测各自保留合法资料/目标支持、时效模式、接触/分区、实际拟合与结果证据，不用合成测试、旧规则百分数或单个探索月替代。
- [ ] 正式独立回测至少完成实际声明范围内t+1/t+2/t+3各提前量的冻结测试和有/无锋面配对，核直接复算/兼容复用；缺提前量或真实测试资料则该关口未完成，不选择性隐藏。

### I12 预测结果、模型与证据身份

## Testing Decisions

主接缝为既有工作台显式提交已登记的小范围历史预测实验，经实际服务/受控计算完成资格、冻结/分区、基线/候选及评估，返回同身份结果供右侧预测和底部阅读；已有结果直接读取。辅助API、独立手算小例和受控实验复算核对同一链路，不新开测试专用业务接口，模型选择和批处理也可复用同一计算适配。

1. **标签与支持的已知答案**：独立小日历/解析几何核t+1/2/3、日界、H/E、零/缺测、变化分母和空间聚合。仅改变未来锋面位置/缺测时活动目标和非锋面评价队列不应随之改变；全月共同掩码、只评价未来近锋面格等反例必须发现。
2. **时间与泄漏反例**：逐项核观测早但版本发布晚、训练标签尚未可得、活动延迟、未来SST/响应、目标质量作特征、日历缺口、重叠窗跨分区、邻格随机拆分、已看G3/检索资料和补填冻结。实际服务须拒绝确认性声明或转成清楚归档/探索状态，不能仅靠文案声明无泄漏。
3. **基线与变换**：手算持续性、固定日历均值、训练常态、零/缺常态与MAE/技能，核各提前量/支持及最近输入时距；预处理/选择/早停只拟合各折训练及合格时间验证，冻结测试不参与。比较锁定成熟组件的小例结果，不通过复制实现产生期望。
4. **公平增量与相关推断**：用独立已知配对损失核权重、误差差值、组保持及退化区间；无锋面/有锋面组检查相同目标ID、输入时效、其他特征、预算与排除，未输出/失败不静默删难样本；零基准、多提前量、少组、特征泄漏和测试后改后处理有明确行为。
5. **真实研究分维记证**：合法真实基线和选择实验、真正未用于选择的最终逐提前量配对回测、跨年/季节、空间留出及东海扩展分别记录实际支持；归档假设与当时可知输入分开。直接复算和兼容复用在冻结环境/种子/容差内一致，无增益正常验收，数据不足不勾真实关口。
6. **真实浏览器与状态**：验证明确提交/已有结果读取、实际状态、预测/观测及规则标识、右侧简短结果/底部证据、定位/改条件待更新、乱序、缺输入、失败/权限，地图保持非模态操作；实际核训练次数及无读取触发重训/准备。桌面与手机基本阅读各留证。
7. **成果与权限**：核协议/分区/模型/签发/目标/评价身份、逐源允许聚合与模型卡，未授权任务/目标/模型/底表读取被服务端阻止；半成品和中断不冒称成功，旧版本条件不变。必要TASK故障复用其既有合同，不重复生产恢复/备份平台。
8. **既有基础和界限**：沿P0支持、A逐日小例、G3接触/相关分组、W真实任务及原条件地图、原数据/交互检查风格补PRED行为；旧规则页断言不是新模型数值参照。本轮规格整理不运行应用实验，后续检查只登记实际执行内容。

## Out of Scope

- 不将预测真值改成鱼量、渔获、收益或捕捞成功率；不预设正向锋面增益，不把重要性、条件关系或预测改善说成因果。
- 不重做P0、A/B/C、G3独立复核/检索、W/TASK或REPORT底座；复用实际合同，不建设第二套接触/任务/保存体系。
- 不要求LSTM/Transformer、自创时空网络、全部概率模型或无限候选；超出首轮必要候选的模型、热点分类与单次预测区间只在明确协议和资料支持后另项启用。
- 不把整域扩展等同全球服务，不允许任意地点/半径外推，不以插值/地图精度冒充研究分辨率；条件性空间关口不足不得提前验收。
- 不接近期实时资料、外部7/10日预报或相对今天滚动运行，不自动滚动重训；这些属于G6a独立扩展，不以改日期标签实现。

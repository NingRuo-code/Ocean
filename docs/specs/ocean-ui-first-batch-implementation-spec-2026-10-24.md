# Ocean U1/U2 首批界面迁移实施规格

整理日期：2026-10-24。产品设计与验证边界已确认；本次将 Q47 及后续决定转成可实施范围。已发布：[规格 Issue #24](https://github.com/NingRuo-code/Ocean/issues/24)，标签 `ready-for-agent`。发布标题：`[Spec] U1/U2 首批界面迁移：工作台、统一筛选与可信结果展示`。

实施任务已按用户确认发布为 #25–#34：[任务与阻塞关系](../tickets/ui-first-batch/README.md)。此行是本地交付导航，不修改远端父规格正文。

## Problem Statement

使用者希望从地点、日期和公里范围出发，快速看懂附近锋面、海温和 AIS 表观捕捞活动，再按需展开研究。现有界面把筛选、图层、分析页签和长说明分散放置，两侧职责缺少区分，当前结果被评分规则及多余文字淹没。工作台仅完成非模态共存的首个切片，尚未整合为易用入口。

旧界面的推荐分数、实验规则推演和抽样历史还容易被理解成实际渔业概率、已验证预测或完整月证据。换日、缺资料和迟到请求若没有明确身份，会进一步造成误读。改造需要保留原地图操作和已有可信数据链，降低使用门槛，并明确尚未实现的能力。

本规格覆盖近期可执行的界面迁移与 U2 基础显示、时间状态，服务首批界面关口 GU。完整月研究、预测验证、论文加速及服务器容量仍由各自工作包交付。

## Solution

形成“左侧发起、中央探索、右侧读结果、底部看证据”的界面。左侧深色工作台同时容纳快捷功能与紧凑 AI 模块，筛选和图层由独立浮层呼出；右侧浅色保留当前、历史、预测三入口。两侧均可收起，地图在展开期间保持可拖动、缩放、查点与设置分析点。

当前页以一句事实、一个主数值和少量指标呈现所选任务结果。复杂图表、逐日表和方法说明进入默认收起的底部区域。所有结果沿用唯一一套已应用条件与资料身份；未接入、缺测、有效零、加载失败和结果过时有不同表达。

科学色带、精简图例和时间标识统一迁移。正式数值域未冻结时明确显示可用域及其适用范围，不把配色评审样例当全年标准。不能在本批完成的数据处理或计算，保留明确的待接入状态和依赖，不展示假结果。

## User Stories

1. 作为首次使用者，我希望从工作台按任务进入附近锋面或捕捞活动，以便不必先理解所有图层和研究方法。
2. 作为使用者，我希望通过深色左栏和浅色右栏区分操作与结果，以便快速找到入口。
3. 作为地图使用者，我希望独立打开和收起两侧面板，以便为地图或结果腾出空间。
4. 作为地图使用者，我希望展开工作台后仍能拖动、缩放和选点，以便连续探索海域。
5. 作为原系统使用者，我希望保留海岸线、经纬网、平面与球面视图、比例尺及定位操作，以便沿用熟悉的地图。
6. 作为使用者，我希望快捷功能与 AI 输入同时出现在左侧，以便在按钮操作与提问之间切换。
7. 作为使用者，我希望未接入的关系分析和区域比较说明其状态，以便知道哪些能力现在可以使用。
8. 作为使用者，我希望所有日期、坐标和公里半径集中在一个筛选面板，以便无需寻找分散的控制项。
9. 作为使用者，我希望筛选面板展开时不挤占快捷功能和 AI 模块，以便保留原有任务上下文。
10. 作为使用者，我希望日期和半径选择后沿用即时轻量更新，以便马上看到变化。
11. 作为使用者，我希望坐标沿用应用按钮和地图点选方式，以便未确认的输入不会改变分析点。
12. 作为使用者，我希望查看点、分析点和视图中心各有清楚含义，以便拖动地图不会偷偷改变分析条件。
13. 作为使用者，我希望点击地图可收起筛选或图层浮层并继续查点，以便少一次操作。
14. 作为使用者，我希望拖动、滚轮和缩放按钮不关闭浮层，以便比较参数时不被打断。
15. 作为使用者，我希望收起并重新打开浮层后仍保留本次输入，以便继续编辑。
16. 作为使用者，我希望刷新后仅恢复已应用的日期、地点、半径和图层，以便继续工作而不意外执行未确认输入。
17. 作为使用者，我希望重开网页不会自动重跑详细分析，以便避免不必要的计算。
18. 作为使用者，我希望图层开关从左侧独立呼出，以便右侧专注显示结果。
19. 作为使用者，我希望切换任务获得合理的默认图层搭配，同时能手动调整，以便看清不同关系。
20. 作为使用者，我希望普通刷新保留手动图层选择，以便当前观察方式不会反复被重置。
21. 作为使用者，我希望右侧只保留当前、历史和预测，以便 AI 与结果不再混杂。
22. 作为使用者，我希望当前页给出一句简短分析、一个主数值和两至三个辅助指标，以便立即读懂结果。
23. 作为使用者，我希望附近锋面摘要优先说明最近距离和方位，以便理解锋面与分析点的位置关系。
24. 作为使用者，我希望活动摘要给出真实小时数和资料支持情况，以便理解捕捞活动及其局限。
25. 作为使用者，我希望界面不再用未经验证的把握度或推荐分数表达结果，以便不会把观测事实误认为作业成功率。
26. 作为使用者，我希望详细证据默认收起且可按需展开，以便首屏保持简洁。
27. 作为研究者，我希望历史入口优先呈现已有整月结果，并支持进入某日再返回月份，以便在概览与实况之间切换。
28. 作为研究者，我希望没有可信整月汇总时直接看到缺口，以便不会把抽样记录理解为完整月统计。
29. 作为使用者，我希望预测入口显示基准日、目标日和验证状态，以便区分规则参考与正式活动预测。
30. 作为使用者，我希望历史观测始终显示真实日期，以便旧资料不会被称为今天实况。
31. 作为使用者，我希望播放遇到整日缺测或未就绪日期会暂停并解释，以便不会把空白当作没有活动。
32. 作为使用者，我希望海温同温同色、活动同小时数同标尺，以便跨日期比较。
33. 作为使用者，我希望局部海温增强明确标出当前范围，以便不会与固定色标混淆。
34. 作为使用者，我希望精简图例留在地图原位置并与可见图层一致，以便随时读懂单位和颜色。
35. 作为使用者，我希望活动对数显示仍可查询真实小时数，以便图形压缩不改变数字含义。
36. 作为使用者，我希望默认只显示最近和选中的锋面编号，以便减少遮挡且仍能查看其他锋面。
37. 作为使用者，我希望切日期后保留视角且旧观测不冒充新资料，以便不会读错日期。
38. 作为使用者，我希望快速切换条件后仅最新请求更新当前画面，以便迟到响应不会覆盖新结果。
39. 作为使用者，我希望有效零、覆盖未知、无记录、未就绪和请求失败有明确区别，以便判断结果是否可信。
40. 作为使用者，我希望暂时网络故障可有限重试，以便恢复使用且不会陷入持续请求。
41. 作为键盘或小屏使用者，我希望入口、关闭、焦点和滚动都可用，以便不依赖大屏鼠标操作。
42. 作为访客，我希望公开就绪资料仍可浏览，受限功能清楚说明原因，以便知道当前可用范围。
43. 作为研究者，我希望改条件后的旧详细结果保留原条件并标明待更新，以便不会被误认为新结果。
44. 作为维护者，我希望每个界面切片都有可复现验证和独立进度，以便审查、合并并接续后续数据与研究任务。

## Implementation Decisions

### 1. 范围、现状与依赖

- 本批完成 U1.2 两模块、U1.3 筛选/图层、U1.4 结果与详情，并接入 U2 基础外观、科学显示契约和时间状态。复用本地 U1.1 非模态实现，不把它的旧模态前版或样稿当最终产品。
- U1.1 的本地提交为 `53762af`；已有检查仅证明该切片，当作可复用起点，不等同整批通过、远端已更新或已部署。实施前核对目标分支及实际提交，保留用户和协作者的其他改动。
- 本规格服务既有 [U1 #15](https://github.com/NingRuo-code/Ocean/issues/15) 和 [U2 #16](https://github.com/NingRuo-code/Ocean/issues/16)，属于 [执行总纲 #13](https://github.com/NingRuo-code/Ocean/issues/13)。不重建总体路线，不以新规格关闭原工作包。
- 可立即实施布局、原功能迁移、输入状态、不可用表达、请求隔离和图例结构。正式跨时段色域、研究半径支持和完整活动显示验收依赖 P0/P1 对应子项；这些阻塞必须保留在后续票据，不能用占位结果勾选完成。

### 2. 面板与视觉

- 桌面为左操作、中央地图、右结果，左右均可独立收起并重新计算地图可用区域；工作台非模态，不使用阻断地图的遮罩或焦点锁。底部详情默认收起。
- 以已评审比例为起点：1440 宽左约 250、右约 326；更宽屏约 270/350。最终以文字可读、地图可操作和窗口适配验收，不把像素值作为跨设备固定布局。
- 左深右浅、冰蓝强调色、细线、直角展示区和少量切角按钮；中文优先，数字使用已有 Saira 字体资源。图标辅助识别操作，保留必要文字标签。减少装饰性编号、长副标题、光效和密集卡片。
- 中央地图沿用既有业务结构、投影和几何；允许本规格约定的科学配色、标签密度与透明度调整，不重建地图框架。
- 小屏两侧默认收起，呼出后可关闭和滚动；不要求同时并排展示三栏，但不得产生整页横向溢出或使地图永久不可访问。

### 3. 唯一条件与浮层

- 所有入口共用已应用日期、分析点、公里半径及图层状态，沿用现有数据适配层和计算路径，不创建工作台专属计算副本。
- 区分编辑中的坐标和已应用分析点。日期/半径选择触发既有轻量刷新；坐标经原应用动作或地图设置分析点才生效。半径保留当前可支持值，本批不擅自新增研究支持档位。
- 筛选、图层各有独立浮层；一次只展开一个，置于工作台邻近区域并按屏幕避让，不挤掉快捷/AI模块。浮层内编辑和滚动不误触地图。
- 点击地图关闭浮层并沿用原查点或选点行为；拖动、滚轮、缩放控件不关闭。普通地图查点不等于设置分析点。
- 收起保留当前会话输入；页面重开恢复已应用且仍合法的条件和图层。过期、不支持或损坏的恢复值给出可理解反馈并使用合法默认值，不伪装已完成恢复，不恢复未应用坐标。
- 面板内 Escape 优先关闭当前浮层或面板并返回对应入口；焦点已在地图时保留地图原 Escape 行为。非模态面板不能抢夺地图焦点。
- 改条件仅触发原有轻量读数与绘图。月度、事件、比较和其他详细分析由主动动作发起；旧详细结果保留其原条件和过时提示。

### 4. 快捷、AI 与结果

- 左侧同时显示快捷功能和紧凑 AI 模块。首层为附近锋面、捕捞活动、关系分析、区域比较，其余收进更多；未接入功能说明状态和前置，不能以演示数值代替。
- 切换快捷任务联动右侧当前摘要和默认图层搭配；给出简短反馈。普通日期/位置刷新不反复覆盖手动图层选择。
- AI 从右侧迁到左侧。保留已有确定性证据组织能力；输入区域在未接在线模型时明确说明未接入，不伪造聊天答复或把静态提示当 AI 调用。未授权访客不能借入口访问受限接口。
- 后续 AI 保持已确认规则：条件齐全、就绪且授权范围内的明确分析指令可提交，解释或改条件不自动发起重任务，未就绪归档不自动准备。本批不新增在线模型或后台任务系统。
- 右侧只保留当前、历史、预测。当前页一句事实、一个主数值和两至三个辅助指标；必要的日期和资料状态简短附带。附近锋面给距离/方位及支持的水温等事实；活动给真实小时数、支持情况及邻近锋面事实，不重新发明评分。
- 删除当前结果中的“可以看看”、把握度、未经验证的渔业推荐分数和大段评分规则。原计算若仍供兼容使用，不借此宣称完成算法替换；已确认删除的表达不能藏入详情继续当作有效结论。
- 历史默认整月入口：有可追溯汇总才展示；已有稀疏样例保持样例标识，不能冒充整月。支持时可从月份进入某日再返回；数据合同未提供时呈现未接入状态，不为此临时发明月度接口或启动整月计算。
- 历史和预测采用短分析、关键指标、一张主要图；更多表格、来源与方法放底部。没有主图资料就展示原因，不生成占位曲线。
- 预测保留实验规则参考时明确标“未独立验证”，显示基准日及目标日。只有实际历史观测可切入观测地图；规则外推不得变成未来实况图。正式活动预测等后续实验验收再接入。

### 5. 科学显示与数据含义

- 海温采用已确认的 NCL cmocean_thermal；活动采用 NCL MPL_Purples 反向较亮段。共用映射定义驱动图面与图例，保留来源和许可信息。
- 默认固定同温同色；手动局部增强显示当前值域和模式。活动跨日期固定颜色/大小标尺，对数变换只用于显示，读数保留实际小时数；多船累计可超过 24 小时。
- 16–33°C、0–1000h 是配色评审域，不作为全年正式默认值。正式域必须由数据清单及版本支持；若本批拿不到经核实的统一域，只发布明确限定资料范围的显示，正式跨期一致性子项保持阻塞。不能逐日自动取最小最大却标“固定标尺”。
- 原地图位置保留常驻精简图例，显示可见且就绪图层的颜色、单位及活动对数标识；说明点击展开。隐藏、失败或未接入图层不能继续显示成正常有效色带。
- 近景保留实际网格精度；本轮不增加平滑插值模式。检查源分箱与再次显示分箱，避免粗细层重叠造成假色块；不从已分箱源资料“还原”更高精度。
- 默认锋面编号仅保留最近和选中对象；其他可点选查看，锋面线不删。叠加活动时海温淡化且允许手动恢复；具体程度用真实样本评审，不将样稿系数视为数据结论。
- 活动全量显示必须取消默认分位筛选与 700 点硬截断；远景尺度聚合、近景完整有效视野格及守恒核对由 U2/P1 联合子项实现。该项进入后续依赖票据，未验收前不宣称整套 U2 完成；本批先明确当前显示范围与限制，禁止拿可见点数当活动全集。
- AIS 表观捕捞活动是小时代理，地图展示聚合不是锋面缓冲研究真源。遵守既有领域 ADR 的源粒度约束；发现实际粒度不一致时留给 P0 审计与尺度决定，不由界面改造静默改为另一研究口径。

### 6. 时间、加载和错误状态

- 历史日期明确显示实际日期，不写“今天”。图层日期、摘要条件和结果版本可对应；异日或异条件的旧详细结果有独立身份。
- 切日保留底图、视角和缩放，旧观测层立即退出当前观测表达；新资料到达再显示。不得在加载时留下旧图却配新日期。
- 复用现有异步入口，用日期、条件、视野和资料版本等必要身份拒绝过期响应；取消不能保证的请求也必须防止结果覆盖。某图层失败不应把其他已就绪图层数值清成零。
- 分别表达加载中、已就绪、有效记录零、没有记录、覆盖未知、整日缺测、未准备、权限不足和请求失败。没有记录只有在来源明确保证完整观测时才可判为零；没有支持信息时说明未知。
- 播放遇到整日缺测或未准备日期暂停并说明，用户可选择继续下一有效日期；准备资料入口仅在既有能力与权限支持时提供，不新增自动归档任务。
- 临时网络/超时自动重试一次，仍失败提供手动重试；权限不足、确定无资料不自动重试。用户切换条件后，旧条件重试不能抢占当前结果。
- 概览后明细、有界缓存、邻日概览预取、绘制优化及 3/1/2 秒目标留在 P1 实测验收；本批状态和请求身份设计需可复用，不把静态截图或单接口耗时当性能达标。

## Testing Decisions

### 1. 已确认的主要验证入口

以现有 Edge 浏览器端到端用户流程为主入口，覆盖“呼出工作台→统一筛选→地图探索→阅读结果→展开证据→关闭与恢复”。布局检查仍运行在同一浏览器页面，数据检查作为数字参照沿用既有工具。无需为本批新增一套测试专用业务接口或按内部函数拆分大量单元测试。

用户已于 2026-10-24 确认：“按上述边界验收并发布规格（推荐）”。验收以真实浏览器行为、同源数字和布局/异常状态为边界；性能算法、统计及预测分别在后续工作包验收。

### 2. 测试原则与既有基础

- 好的检查验证用户可见结果、输入作用、请求行为和可追溯数字，不绑定内部变量、CSS 类名、函数拆分或固定卡片数量。必要的自动化定位可稳定，但不把实现细节本身当产品要求。
- 复用已有浏览器交互、布局和数据一致性检查；已有真实拖动、滚轮、点选、非模态与焦点检查优先保留。外部操作优先通过实际指针/键盘执行，不只调用内部刷新函数来证明交互。
- 迁移右侧三入口、当前简短结果与图层布局时，同步替换旧四页签、评分格、顶栏编号及旧抽屉假设；保留仍适用的地图几何、真实读数和数据来源回归。不能用总通过数替代需求覆盖。
- 色带无需逐像素锁定截图；验证同值同映射、图例/单位/模式与图面一致，并对代表性真实样本进行人工视觉检查。

### 3. 必须覆盖的情景

| 情景 | 可观察验收 |
| --- | --- |
| 两侧展开/收起 | 地图尺寸正确，真实拖动/滚轮/点选仍可用，无阻断遮罩和焦点锁 |
| 筛选编辑/应用 | 即时日期/半径生效；未应用坐标不改变结果；地图设置分析点同步全部入口 |
| 点击与拖动区分 | 地图点击关闭浮层并保留查点；拖动/滚轮/控件缩放不关闭浮层 |
| 输入恢复 | 会话内收起保留草稿；页面重开只恢复合法已应用条件，不启动详细计算 |
| 快捷和图层 | 任务切换给出搭配反馈；普通刷新保留手动选择；未接入任务没有伪结果 |
| 当前/历史/预测 | 三入口和简短事实正确；历史样例不冒充整月；实验预测不冒充观测 |
| 同源数字 | 已知地点/日期的水温、距离、活动读数与实际输入或独立参照相符；没有资料不输出假零 |
| 时间和缺日 | 历史日期准确；切日保留视角并移除旧观测表达；播放缺日暂停且不自动准备资料 |
| 乱序与失败 | 延迟旧响应不能覆盖新条件；临时失败仅自动重试一次；权限/无资料不进入自动重试 |
| 科学图例 | 同源映射、真实单位、局部增强标记与可见就绪图层一致；未知域不伪称全年统一 |
| 详情与过时结果 | 默认收起；展开有实际证据；改条件后保留原结果身份并标待更新 |
| 键盘和小屏 | Escape/焦点不抢地图；1440/1280及390宽代表窗口无整页横向溢出，入口可读可达 |

- 使用仓库可合法分发样本核对真实数据；对超时、乱序、有效零、未知覆盖等不稳定路径，在现有浏览器检查中使用受控响应。此类检查只证明界面合同，不证明线上覆盖、权限已部署或完整月真实资料有效。
- 本批不新增受限端点；若发现原有权限不足，独立登记并由服务端工作包验收，前端隐藏按钮不算权限保护通过。
- U2 全量活动/聚合子项后续另以完整有效输入核对总小时守恒、视野明细完整性和跨日期尺度，不以本批结构验收代替。

### 4. 完成证据

每个切片记录变更范围、实际运行的检查及结果、代表性截图、提交与残余依赖。首批整体通过上述浏览器流程、数据参照和布局检查后，才可提交 GU 验收。文档整理本身只检查结构、链接和内容一致性，不冒称应用检查已重跑。PR、合并、部署和线上验证分别登记。

## Out of Scope

- 完整月 A、固定区域事件 B、区域证据 C 的新计算，以及跨年/跨区统计、显著性和独立复核；本批只承接已有可信结果与未就绪状态。
- 正式活动预测训练、标签与切分冻结、基线和锋面增量验证，实时滚动预报和外部未来 7/10 天海温接入。
- 在线模型购买/接入、多轮工具执行、完整后台任务中心、服务器重启恢复、成果保留/清理及报告导出产品化。
- 年度色域和研究半径的科学冻结、来源粒度变更、全时段活动重新加工、远景聚合与全量近景显示的完整性能实现；这些仍是 U2/P0/P1 的必需后续项，没有取消。
- imMens、Mosaic、COG/Zarr、Worker、Canvas/WebGL 等候选的实验与采用决定，服务器容量和费用结论；按实测性能专项推进。
- 替换原地图框架或投影、平滑插值伪造精度、区域综合推荐排名、渔获或收益预测。
- 自动合并、部署、扩大公开数据范围或将受限资料提交到仓库。

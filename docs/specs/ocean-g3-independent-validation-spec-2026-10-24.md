# Ocean G3 跨年份、季节与海域独立复核实施规格

整理日期：2026-10-24。来源：总体规划G3、STAT-07和METHOD-01/05/07；承接P0、A/B/C及其冻结方法。状态：已发布 [规格 #141](https://github.com/NingRuo-code/Ocean/issues/141)，标签 `ready-for-agent`；验证边界已获用户确认。本轮未实施计算或取得新实证。发布标题：`[Spec] G3 独立复核：跨年季节与海域的关系稳健性`。

执行任务已按用户确认发布为#142–#158：[17项G3任务与阻塞关系](../tickets/g3-independent-validation/README.md)。本行仅为本地导航，远端规格正文保持不变。

## Problem Statement

使用者希望知道：系统在一个月份发现的锋面与表观捕捞活动关系，换到其他年份、季节或海域后是否还成立，哪些条件下可以提供作业参考，哪些条件下证据不可靠。单月叠图、重复查看的七八月案例或几组区域并列，不能回答独立复核问题。

当前已有历史频次、旧响应表和逐行重采样实验；正式A/B/C规格已明确支持、分母、事件、对照和相关样本，但尚未交付可执行的跨期独立复核流程。C负责描述比较，不承担新的跨区域显著性推断。不能把历史锋面档案年限当作锋面、SST与活动的联合可用年限，也不能把旧演示表包装成未见样本。

需要将方法选择与最终复核隔离，保留全部预定候选、失败和反向结果，区分资料不足、估计不精确与关系发生变化。验证不以正相关或显著为通过条件，也不把表观捕捞小时解释为鱼量、渔获、收益或因果效应。

## Solution

提供显式提交的G3复核请求：选择已冻结的研究协议、探索/选择/复核分区及待验证年份、季节和海域，先读取P0支持与实际数据接触记录，再按原A/B计算合同取得或计算各层结果，形成同身份的复核表、效应图、敏感性和证据包。

先验证东海跨年份与季节，再在共同覆盖和可比性成立时进入其他海域。A月度空间关系与B固定区域事件响应分别复核；A可先交付，B窗口及事件条件成熟后接入。每条结论明确对应哪种时间、海域、指标和支持范围。分层重复分析是基础；只有预先登记的目标、权重和相关样本依据成立，才计算跨层汇总、差异检验或条件解释模型。

交付一份可以复算的研究记录，而非自动评分或作业推荐。资料不足仍可完成可行性调查和软件边界验证，但对应真实独立复核关口保持未完成；相似案例检索、预测独立回测及完整工作台/报告接入另行验收。

## User Stories

1. 作为研究者，我希望明确复核的是A空间关系还是B事件响应，以便不会混合不同研究问题。
2. 作为研究者，我希望先查看锋面、SST和活动的共同覆盖，以便选择真实可研究的年份和海域。
3. 作为研究者，我希望区分有效零、缺测、未准备、读取失败和无事件，以便正确解释空结果。
4. 作为研究者，我希望记录实际分析粒度和合法使用范围，以便不会以展示数据替代研究真源。
5. 作为研究者，我希望先在东海跨年份和季节复核，以便逐步扩大可信范围。
6. 作为研究者，我希望其他海域独立通过资格与可比检查，以便不能因东海可用就自动推广。
7. 作为研究者，我希望探索、方法选择和最终复核资料明确分开，以便避免反复调参后自证。
8. 作为研究者，我希望已查看和已用于调参的资料留下记录，以便不能重新命名为未见样本。
9. 作为研究者，我希望不确定是否接触过的资料明确降级，以便不会声称不存在的独立性。
10. 作为研究者，我希望冻结前只进行允许的支持审计，以便区分资料盘点与提前查看目标结果。
11. 作为研究者，我希望冻结候选年月、季节定义和海域清单，以便结果出来后不会只保留有利样本。
12. 作为研究者，我希望预先确定主指标、距离带、侧别、半径及事件定义，以便跨期使用同一方法。
13. 作为研究者，我希望预先确定分母、对照、分组和区间方法，以便复核有明确统计含义。
14. 作为研究者，我希望区分主要问题与探索和敏感性，以便控制大量比较造成的误读。
15. 作为研究者，我希望协议变更生成新版本并保留旧结果，以便追溯结论变化原因。
16. 作为研究者，我希望已揭示的复核资料不能再次充当同一改进方法的未见验证，以便保持诚实边界。
17. 作为研究者，我希望检查跨月窗口、共享对照和空间重叠，以便避免探索与复核暗中共用相关样本。
18. 作为研究者，我希望明确登记分组和必要隔离，以便相邻日与邻格不会被当作独立重复。
19. 作为研究者，我希望复用A/B的实际计算和结果身份，以便不出现另一套数值引擎。
20. 作为研究者，我希望已完成结果只有版本和条件匹配才可复用，以便更新资料不会混入旧复核。
21. 作为研究者，我希望缺少合格结果时由明确请求调用受控计算，以便不会静默批量分析或准备归档。
22. 作为研究者，我希望A逐月保留小时与面积时间分母，以便跨期密度可以复算。
23. 作为研究者，我希望B保留锚日、实际窗口、对照和相关组，以便前后变化仍符合固定区域协议。
24. 作为研究者，我希望不同年份的侧别未知、覆盖不足和匹配失败保留，以便看到真实限制。
25. 作为研究者，我希望年份与季节交叉列出，以便不会把年份变化和季节变化混为一种证据。
26. 作为研究者，我希望每个层展示效应大小、区间和有效独立样本，以便了解方向之外的信息。
27. 作为研究者，我希望跨层汇总明确目标和权重，以便不会把总小时、密度与平均效应混算。
28. 作为研究者，我希望联合差异计算保留共享样本相关性，以便不从两个区间端点伪造显著性。
29. 作为研究者，我希望样本不足时降级为描述结果，以便不生成虚假的精确结论。
30. 作为研究者，我希望统计检验登记假设与多重比较处理，以便不会在大量组合中挑显著结果。
31. 作为研究者，我希望稳定性结论有明确的科学判据，以便不把差异不显著当作等效证明。
32. 作为研究者，我希望无关系、反向和异质性同样呈现，以便知道系统的失效条件。
33. 作为研究者，我希望敏感性只按冻结矩阵执行，以便避免通过无限试参数选择答案。
34. 作为研究者，我希望分清支持变化与方法变化的影响，以便解释为何结果不同。
35. 作为研究者，我希望合法累计的大活动值被审慎检查，以便不会为获得好结果随意删除。
36. 作为研究者，我希望条件解释模型在资料支持后才启用，以便不以复杂模型掩盖样本不足。
37. 作为研究者，我希望先比较简单解释基线和一个有依据的候选，以便控制实验范围与成本。
38. 作为研究者，我希望按小时的真实分布选择模型，以便不把连续活动小时误当整数计数。
39. 作为研究者，我希望所有拟合、预处理和方法选择避开最终复核资料，以便不会发生信息泄漏。
40. 作为研究者，我希望只解释实际可测条件，以便不会声称消除了未观测混杂。
41. 作为读者，我希望看到覆盖图表、分层效应和失败清单，以便了解结论适用于哪里。
42. 作为读者，我希望图表、摘要和证据来自同一次冻结结果，以便数值可以逐项核对。
43. 作为维护者，我希望运行记录包含版本、分区、种子和真实状态，以便按原条件复算。
44. 作为维护者，我希望过期、部分失败和中断结果不冒充完整成功，以便保持证据可信。
45. 作为维护者，我希望受限输入与合法聚合成果分开，以便分享不会暴露AIS细粒度资料。
46. 作为负责人，我希望分别记录软件能力及跨年、季节、海域真实验证进度，以便准确跟进。
47. 作为后续预测研究者，我希望知道哪些资料已被本轮使用或查看，以便另设真实独立预测评估。
48. 作为后续集成者，我希望获得稳定的G3阅读和证据合同，以便再接工作台、报告和AI。

## Implementation Decisions

### I01 范围、现状与交付层级

- [ ] 关联执行总纲#13及STAT-07/METHOD-01/05/07，复用P0规格#35、A#60、B#72及C#85；不修改或关闭已有父级与执行任务，不新增重复的A/B引擎。
- [ ] 当前旧逐行bootstrap/符号翻转和历史频次仅作已有基础，不宣称已经具备相关样本安全、跨年或独立验证能力；C的描述性比较不自动升级为推断。
- [ ] 区分共同覆盖可行性、软件正确性、A真实复核、B真实复核和跨年/跨季节/跨海域各实证关口；不能以任何单项完成替代全部完成。
- [ ] 交付核心为显式复核请求到确定性结果/证据的闭环；条件模型与外海域分别列启用条件。无显著关系或负向结果可以通过方法验收。

### I02 联合资料资格与候选全集

- [ ] 在读取目标效应前登记候选区域、年月、季节、半径、资料来源和所需A/B类型；先审计三层共同支持，保留全部候选及纳入/排除理由。
- [ ] 每个候选复用P0真实产品、来源/处理版本、粒度、单位、许可、有效零/缺测和覆盖合同；未准备、失败、无覆盖、未知零语义和有效零分别编码，文件存在不算合格。
- [ ] A完整处理全月日历并披露有效支持，B检查前7日、事件日、后1–3日与真实后1–7日及识别所需上下文；不能外推窗口、补零或用粗展示网格冒充目标分析粒度。
- [ ] 覆盖/样本门槛依据源精度、支持和所选推断评估后冻结，不在本规格虚设统一最小样本量；取得某个年份或海域锋面归档不等于取得联合研究资格。
- [ ] 不具备合法资料的候选返回具体缺口和准备需求，禁止自动扩容、购买、全档下载或放宽门槛；归档准备沿用TASK，不因准备成功就自动计算或获得研究资格。

### I03 接触历史、分区和方法冻结

- [ ] 建立版本化分区清单，逐项记录资料/事件组身份、探索/选择/最终复核角色、接触用途、时间与已知分析记录；既有2024年七八月演示及反复探索样本不自动认定独立。
- [ ] 允许冻结前按覆盖元信息做资格审计；若审计或可视化已揭示目标关系、目标效应或用于选择方法，登记接触并调整独立性结论；来源不明的既往接触标不确定，不能仅凭新建清单声称盲法。
- [ ] 冻结物包含研究目标量、候选全集/分层定义、实际几何/半径、距离带/侧别、H/E、事件/锚日/窗口、对照、排除/异常处理、相关分组、主次问题、权重、推断和敏感性，绑定源及软件方法版本。
- [ ] 冻结时间早于最终目标关系读取或计算；保留不可静默覆盖的协议身份、内容校验与修改记录，内部可审查登记即可，不强制外部注册平台。
- [ ] 揭示后更改方法生成新版本，明确旧资料成为探索性或重复检验；新的确认性声明需要新的合格未用于选择的资料，无法取得则保留限制，不倒填冻结时间。

### I04 分区的相关性与泄漏检查

- [ ] 根据A时间块/空间支持和B窗口/相关事件/共享对照建立跨月、跨区域可追踪的相关关系，不能每个月重新编号就把同一组当新独立样本。
- [ ] 检查探索、选择与复核之间的共同目标记录、重叠几何、跨边界窗口及共用对照；按真实依赖采取整组划分或有依据的时间/空间隔离，报告仍存在的相关性。
- [ ] 冻结分区前根据已知时间/空间支持确定隔离规则；不使用任意统一天数来声称完全独立。仅地理不重叠不自动证明外海域独立，只有不同年份也不自动消除方法选择接触。
- [ ] 违规分区不得输出确认性标记；允许保留明确标注的探索结果。后续预测另设可知时间、标签窗口和切分协议，本轮未见不自动等于预测未见，本轮已看也不隐去记录。

### I05 显式执行、复用与身份

- [ ] 复核请求声明协议/分区版本、候选清单、A/B类型、实际资料版本和资源限制；复用现有API或受控计算入口，A路径不等待B、C全部交付。
- [ ] 逐项验证资格和方法兼容，条件/资料/方法身份精确匹配时读取已冻结A/B结果；需新计算时显式受控调用原引擎，不在只读打开或调整界面条件时偷跑。
- [ ] A复用#67冻结协议及#71交接的合法逐日基础量；B复用#80冻结及#84交接的真实事件/匹配/相关组依据。若缺少联合推断所需基础，列明实际缺口，不反推细粒度源数据。
- [ ] 顶层结果身份包含复核类型、候选集合、协议/分区/资料/方法版本与各子结果身份；缓存、图表和重试不得混入其他批次。一个候选失败可形成部分结果，但缺项状态与总体完成状态分别记录。
- [ ] 需要后台服务时复用W权限/持久记录及TASK有界排队、安全恢复或明确中断，普通访客不获得重计算权限；独立受控研究入口不依赖完整任务中心、报告或AI完成。

### I06 同语义分层重复与可比性

- [ ] A按月份和研究条件重复原目标量、分母及同月对照，保留逐日H/E、有效支持、未知侧别和排除；B按固定几何、真实窗口和原对照协议重复，A/B不混成同一效应。
- [ ] 年份×季节×海域的候选格完整列出，季节的月份归属、跨年季节标签与聚合规则冻结；不把跨年同季比较和跨季比较混作同一维度通过。
- [ ] 来源和处理版本可以因实际年份有不同内容，但单位、产品语义、几何、目标量和覆盖规则须可比；结构改变、检测算法更替、AIS接收/分类变化分别说明，不要求不同年份文件内容相同。
- [ ] 不可直接比较时分开分析或返回具体不可比项；统一名称、插值、重采样和粗化不自动修复源语义差异，不能把观察到的活动变化全部归于锋面。

### I07 分层效应与跨层汇总

- [ ] 先输出逐层效应、区间/不可估原因、小时、面积时间、有效日期、事件/相关组数、覆盖与匹配质量；总记录行数和有效独立样本分开。
- [ ] 可加的H与E仅在支持不重复且语义一致时相加；sum(H)/sum(E)明确为支持加权的描述密度，不冒充各月平均效应、典型海域效应或因果效应。
- [ ] 任何跨层平均、差异或联合目标量须在揭示前冻结层级、权重、重叠去重和不合格层处理；禁止先看结果再改权重、等权平均所有重复半径或将A/B混池。
- [ ] 如计算跨层差异/汇总的不确定性，必须取得合法的共同基础量、组成员或联合重复估计，并保留共享日期/事件/对照相关性；不能平均区间端点、相减区间端点或以区间不重叠充当正式检验。
- [ ] 核心分层复核可独立完成；联合估计假设/基础不足时只给描述值及不能推断的原因。不得为强行输出总效应引入未经论证的元分析或第二套统计引擎。

### I08 推断、稳定性与多重问题

- [ ] 沿用A/B按时间块、相关事件及空间支持处理相关性的协议，重采样保留组内结构、共用对照及嵌套半径关系；有效组不足时不输出伪精确区间。
- [ ] 正式检验明确零假设、统计量、可交换性/对称等适用假设、区间含义、种子与重复次数；没有合法检验时不伪造p值，也不把重采样自动当随机试验。
- [ ] 预先区分主问题族、次要/探索和敏感性，登记多重比较处理范围及无法计算成员；如开展确认性多项检验，优先复用适用的成熟校正，方法与依赖假设随冻结协议记录，不要求实现方法大全。
- [ ] 同时保留实际效应、原始/调整后检验证据、样本和未完成项；校正不能修复样本伪独立或无效原检验，不能仅对看起来显著的子集校正。
- [ ] “方向相近”“差异未显著”与“实际等效/稳定”分开。无事先有依据的等效容许范围及合适程序，不宣称证明稳定；无明显关系不等于证明没有关系。
- [ ] 稳健性结论以量级、区间、异质性、预定敏感性和支持范围共同解释，不输出综合评分、把握度百分比、成功率或推荐排名。

### I09 有界敏感性和失效调查

- [ ] 复用A/B已实现的有依据边界、半径、距离带、覆盖、事件/匹配和分组候选，预先冻结有限矩阵；不重复建立另一套A/B敏感性产品。
- [ ] 对照同支持的算法/参数变化与支持本身改变，分别记录样本组成、H/E、有效组和效应变化；不把缺项较多的变体误称稳健性通过。
- [ ] 合法大累计值、单层/少数组主导和匹配质量做影响检查，异常规则不得依据效应正负调整；诊断后新提出的变体标为事后探索。
- [ ] 反向、接近零、区间宽、失配、缺测和不同年份/海域不一致均保留，给出有证据的适用边界与待调查问题，不生成未经计算的解释。

### I10 METHOD-05条件解释模型分支

- [ ] 只有共同支持、有效零/分布、可测协变量与有效组足够时启用；否则交付候选证据卡与不能建模原因，不阻塞核心A/B独立复核。
- [ ] 先建立可解释简单回归基线，再依据探索/选择资料诊断选择一个必要的GAM或适合连续非负含零量的候选；不承诺同时完成全部Tweedie、两部分模型或深度网络。
- [ ] 活动小时不是整数计数；响应单位、链接、暴露量/权重、零值机制和模型假设显式确定，不能因非负就默认泊松。使用成熟库并锁定版本，保留采用/放弃证据和运行成本。
- [ ] 仅使用真实具备的季节、位置、距岸、水深等合法协变量；缺项不由AI填充。不声称控制全部混杂，不把条件系数、重要性或拟合改善当因果或预测泛化。
- [ ] 拟合、标准化、插补、特征/平滑复杂度和候选选择限定在探索/选择资料，保留分组/时间隔离；最终复核仅执行已冻结的评估。不适用或外推超支持时明确拒绝/降级。

### I11 复核结果、证据及读者理解

- [ ] 阅读包绑定请求、协议/分区、接触历史、子结果和实际支持，提供年份/季节/海域支持表、分层效应图/表、局限、全部候选与敏感性，不只输出一句关系成立。
- [ ] 主图、表、摘要与机器可读聚合证据同源，明确单位、目标量、权重、样本、区间与独立性状态；A与B、真实资料与合成例、探索与确认性分开标识。
- [ ] 输出执行清单、环境/软件/资料/参数版本、种子、排除、实际耗时/资源、容差和复算方法；源资料清理、授权变化或缺失时明确可读与可复算是不同状态。
- [ ] 只交付授权聚合内容，逐源核对许可及署名；受限AIS、可还原细网格、个人路径和凭据不进入公开证据。聚合是否可共享不能仅靠文件变小判断。
- [ ] 交接稳定G3类型、状态和阅读包；REPORT#125新增G3适配、W浏览器联动、AI解释和相似案例另列任务，既有A/B/C报告不冒称已支持G3，也不反向阻塞研究核心。

### I12 真实研究关口与依赖边界

- [ ] 冻结前记录每个拟验收维度和A/B路径的真实候选、可行性及必须具备的支持；需要不同年份、不同季节或外海域才能分别声称相应验证，不以同年多月代替跨年。
- [ ] 东海A跨期可先验收，B在真实独立事件和窗口可用后验收；外海域在单独资格成立后执行，不将所有外海域数据准备作为东海首批复核的全局阻塞。
- [ ] 真实跨年、季节和外海域均保留直接复算与同身份复用核对；不能仅有合成数据就勾选实证通过。确认性资料不足时记录未完成维度和取得新资料/缩小声明的条件。

## Testing Decisions

采用一个最高层业务接缝：显式G3复核请求进入现有API或受控计算入口，经过实际资格/冻结/分区检查和原A/B执行或兼容复用，产出同身份的结果与证据。辅助检查只用于核对该流程，不新建测试专用业务接口，不要求先做完整浏览器界面。

1. **端到端确定性行为**：从真实请求条件核对协议、分区、候选全集、实际调用/复用、分层效应、部分失败及证据身份。条件不兼容、缺协议、接触历史不明和不合格支持必须返回真实状态；打开阅读结果不得隐式计算或准备资料。
2. **独立已知答案**：使用可手算多年份/季节/区域小例，核对H/E和单位、总密度与层均值权重差异、零/缺测、有效支持、重复半径、跨月事件、共用对照、相关组及未合格层。预期值由独立推导给出，不通过复制实现产生。
3. **独立性与冻结行为**：设计接触目标后补登记、协议改版、探索/复核目标重合、相关窗口越界、同组多标签和拟合预处理泄漏等反例；必须阻止确认性声明或明确降级，并保留旧记录。
4. **推断与边界**：核对成组重采样/联合差值保留共享依赖、零分母/零基线和退化区间、少组拒绝、多重问题全集及校正映射；阻止端点相减、平均区间或差异不显著自动判稳定。以独立小例和已锁版本的成熟方法结果交叉核对，随机结果使用冻结种子和预定数值容差。
5. **真实复核分维记证**：在冻结协议及合法未用于选择的真实共同覆盖上执行，分别记录A/B、跨年、季节和外海域实际完成范围；直接复算、兼容复用及图表证据一致。真实资料不足保持对应关口未完成，无关系/反向不算测试失败。
6. **条件模型启用后**：检查真实响应分布、单位/暴露量、协变量可用性、训练/选择/复核隔离、诊断和不支持时降级；不以合成拟合成功替代真实模型适用证据，不强制该分支阻塞核心流程。
7. **复用现有测试基础**：沿用P0资格/版本、A/B独立小例与真实复算、C兼容判定及现有服务/实验检查风格；只为G3新增的冻结、跨层相关、汇总和外推行为补验证。实际后台服务需复用并核对W/TASK权限和中断语义，不重复建设恢复/压测平台。
8. **交付记录**：分别列软件检查、合成故障、真实资料资格和真实研究证据，记录运行环境与未执行项。输出G3阅读合同即可；工作台浏览器、系统内PDF渲染、AI和生产部署在相应集成规格验收。

## Further Notes

本规格将总体规划G3拆为“独立复核”和后续“相似案例/辅助匹配”两个范围。独立复核落实STAT-07与METHOD-05；后者检索历史可比情形，不能替代独立验证。预测研究另设协议及数据使用台账，不能以本轮关系复核直接证明预测增益。

当前已发布的规格和任务是合同来源，非完成证明：P0#35/#41/#43、A#60/#67/#71、B#72/#80/#84、C#85/#94、W#95、TASK#109、REPORT#125。具体执行票按真实交付依赖建立，不给所有G3子项统一挂上全部模块，也不让既有模块反向等待G3。

方法沿用成熟统计实现，Ocean定制联合支持、依赖分组、分区接触、目标量和解释边界。可参考[statsmodels多重检验校正官方文档](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)提供的成熟方法入口；选择及其适用假设仍由冻结协议决定。条件解释分支可参考[statsmodels GAM官方文档](https://www.statsmodels.org/stable/gam.html)，不将工具支持的模型族自动当作活动小时的正确分布。

对条件模型的分组隔离可参考[scikit-learn分组交叉验证说明](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-iterators-for-grouped-data)。该文档提供模型评估基础，Ocean仍须检查实际事件窗口、共享对照、时间与空间支持，不能把现成划分器当作研究独立性证明。

对旧领域说明里的固定增强阈值、固定远距离对照或移动缓冲表，沿用A/B后续正式合同的澄清，不静默恢复为G3数值规则。粒度或核心数据定义改变时记录影响并按既有ADR流程处理；本规格不改写原ADR。

冻结参数、实际资料年份、样本/组数、最终模型和稳定性容许范围均须由合法资料审计及探索证据确定并留档；没有依据时明确待定和不能声称的内容。实施完成、真实独立验证、PR、合并和部署分别记证。

# Ocean 捕捞活动预测实验实施协议

日期：2026-10-24。范围：L2/G4a 的独立历史回测。当前只有规则参考基础；本文提供实验实施设计，尚未训练模型，也未冻结最终资料、模型和参数。近期资料滚动运行与外部7/10日预报属于后续 G6a。

总入口：[总体规划](../plans/ocean-master-plan-2026-10-24.md)。统计口径：[统计协议](ocean-statistical-analysis-protocol-2026-10-24.md)。

对应[活动预测基线与独立历史回测实施规格](ocean-prediction-baselines-and-independent-backtest-spec-2026-10-24.md)已展开本协议，并发布为[规格 #176](https://github.com/NingRuo-code/Ocean/issues/176)；协议与规格均不代表真实训练/回测完成。

## 1. 用户任务和研究问题

在历史签发时点及可用输入条件下，预测选定位置/公里范围内未来1–3天的活动集中程度，强度为主、相对历史常态变化为辅；随后扩展东海浏览。检验加入锋面信息能否在简单基线之外带来额外参考价值。

输出不称鱼丰度、渔获、收益或捕捞成功概率。正式研究可得“未发现稳定增益”；交付仍须有公平对照、误差与边界，不为了上线预测图而省略失败结果。

## 2. 启动前置

- P0 已核实活动、锋面及必要环境资料的联合覆盖、实际粒度、有效零/缺测语义和来源时效。
- A 提供经过核对的区域逐日活动指标及特征加工；G3 提供足够且可划分的独立时段/海域样本。
- 已识别演示、反复探索和方法选择用过的样本，不能自动重新命名为未见测试集。
- 已能记录资料/特征/方法版本、签发时间与目标支持；存储和单次计算规模可控。

首个完整月用于描述和关系闭环，不自动足够训练、调参和最终验证。若样本不足，交付基线与可行性结论，保留实验入口状态；不复制样本凑训练量。

## 3. 标签、空间与时间合同

### 3.1 目标标签

首轮实验候选按日分别预测 `t+1`、`t+2`、`t+3` 的有效活动强度，并独立报告各提前量；如提供1–3天累计/均值摘要，应明确定义其聚合与分母，不能与逐日提前量互换。该标签方案在资料审计后冻结，页面窗口与训练标签一致。

主标签沿用统计协议的有效支持活动指标，例如 `h/(km²·d)`；原始小时可作为并列辅助量，不能将不同区域大小的总量直接解释为集中程度。位置/半径查询与基础预测空间单元的映射须固定，展示插值或 LOD 不创造更高预测精度。

辅助变化指标使用仅由训练/历史可知资料计算的常态；基线为零或缺测时不输出无穷变化。热点识别只在主强度实验成立后作为辅助评价：阈值在训练资料上定义并冻结，不按每个测试日的结果反选。

### 3.2 可知时间

每项输入记录观测时间、首次可用/发布信息、获取时间和加工版本，另记录预测签发时刻及目标日期。最近可用活动可能早于签发日，所有 lag 特征按真实可用性构造；未来响应表的后1–3日/后7日结果不得回填成输入。

无法复原首次可用时间或使用事后重处理资料时，只能报告明确假设的归档条件回测；不能称为当时实际运行预报。对于“相对今天”的预测，另待 G6a 验证近期输入链，不能通过改日期标签实现。

### 3.3 有效样本

仅在目标值有效且满足预定义覆盖规则时计入相应指标；不同模型使用相同测试样本及纳入规则。缺失输入的处理只在训练数据拟合，保留缺测标记；目标缺测不通过填零制造训练标签。

## 4. 特征分组

| 特征组 | 候选内容 | 约束 |
| --- | --- | --- |
| 活动历史 | 最近可用活动、过去日均/波动、历史出现情况 | 固定日历窗口，缺日不能悄悄变成“最近若干条记录” |
| 时间/区域 | 季节、月份及合法区域编码/位置等 | 高基数身份可能记住地点，需独立海域检验 |
| 环境基础 | 可知 SST、温差或其他已取得环境量 | 代理量与原生强度分开，不承诺尚未接入资料 |
| 锋面 | 最近距离、可判定侧别、出现/接近与短窗口环境特征 | 不依赖深入锋面生命周期追踪；不得引用未来几何 |
| 质量 | 可用时距、覆盖与缺测标记 | 解释模型失效，不能利用仅在事后可知的目标质量 |

所有加工、标准化、缺失填补、阈值及特征选择都只用训练/调参资料；独立测试结果不参与选择。

## 5. 基线与候选模型

| 层次 | 实验 | 进入条件与作用 |
| --- | --- | --- |
| B0 持续性 | 最近有效活动状态延续 | 所有合格任务的基础参照，注明观测时距 |
| B1 近期均值 | 预定义近期日历窗口的活动均值 | 窗口及缺日策略在训练阶段固定，例如近7日作为候选 |
| B2 季节常态 | 同季节/区域历史活动常态 | 历史支持足够时才用，不因缺资料伪造常态 |
| M1 可解释模型 | 简单回归/加性模型，按目标分布选择家族 | 样本与诊断支持；优先解释距离/环境与活动的条件关系 |
| M2 非线性模型 | 一类成熟梯度提升树实现 | 与 M1 同等条件比较，限制复杂度及调参预算 |

Tweedie、含零的两部分模型或 GAM 仅是适配连续非负活动指标的候选；通过分布和零值诊断选择，不同时承诺全部实现。小时不是整数计数，不直接把泊松/负二项计数模型当默认答案。

先复现成熟方法，避免自行重写优化器。只有明确瓶颈、足够样本及公平基线后才考虑更复杂时空模型；LSTM/Transformer 不作为研究版必交，也不以模型名称证明创新。

## 6. 冻结切分和防泄漏

1. 在选择模型和热点阈值前登记探索/训练、验证与最终测试时段，记录哪些资料已被反复查看。
2. 按时间推进构建验证；同一签发日的空间样本作为整体处理，避免随机将相邻日/网格分到两边造成过度乐观。
3. 检查每个样本的特征与标签支持区间。训练标签跨越到验证/测试禁用区时清除相关样本；隔离长度依据预测窗口与相关结构预先确定，不机械套一个天数。
4. 空间泛化单列海区或空间块留出，结合相关尺度确定分块；时间顺序切分不能代替空间检验，反之亦然。
5. 调参、早停、数据变换及特征选择使用训练/时间验证资料；实现时检查工具默认随机验证行为，不能默默将其用于时间序列。
6. 最终测试集只用于冻结后的评估。若据其结果改变方法，生成新实验并另找独立复核资料，不把同一测试集反复当未见数据。

切分年份由实际共同覆盖决定，不提前承诺2017–2024每年都有合格联合输入。资料不足以同时支持目标泛化层次时，降低结论范围并说明限制。

## 7. 公平对照与锋面增量实验

实验组至少包含：简单基线、非锋面输入模型、在相同非锋面输入上加入锋面特征的模型。后两组固定模型家族、资料、标签、训练/测试样本、其他输入、调参预算和评估方式；分别合理调参且完整记录，不能只优化锋面组。

首先作整组锋面信息的加入/移除实验；样本足够再拆分距离、侧别等特征组。解释增量误差和适用场景，不把特征重要性或预测改善当作锋面造成活动变化的因果证明。

## 8. 指标、区间和失败分析

主强度输出预先登记 MAE 等同单位误差，逐一报告1/2/3日提前量；RMSE 等可作辅助，说明大误差影响。若聚合跨提前量结论，权重在验证前冻结，不只挑表现最好的一天。

采用同样本配对比较基线/模型误差；可报告相对技能，但参考误差为零时返回不可定义，不输出除零结果。按时间块/海区评估增量区间，不把每个邻格当独立样本。

热点辅助指标使用冻结阈值和相同有效支持，报告精确率、召回率及样本比例；只有输出概率时才验证校准。辅助评估不改 C 的“无综合推荐排名”边界。

必须分海区、季节、覆盖、活动量级和资料时距检查失败。以下均保留：某提前量无增益、跨季节失效、对照模型相近、无法估计有效区间及资料不足。

## 9. 研究结果与界面接入

每个预测结果携带：历史签发/基准时刻、目标日/窗口、提前量、空间支持、资料时距、单位、数据/模型/特征版本、误差摘要、实验状态和不可用原因。输出图、数值、报告与 AI 引用同一结果身份。

规则参考与训练模型结果分开标注；未通过独立验证时不宣称可靠作业预报。页面允许解释实验结果与局限，不能把概率未经校准或负预测裁剪等后处理隐去。

成果包括实验协议、切分与样本清单、基线和模型配置、环境/种子、逐样本或允许的聚合误差、对照图、失败报告、模型卡与复算依据。受限活动资料与可反推的中间数据不提交 Git，不因研究模型训练自动允许资料外发。

## 10. 实施子项与关口

| 子项 | 前置 | 交付与完成条件 |
| --- | --- | --- |
| PRED-01 可行性与样本合同 | P0/A/G3 支持信息 | 目标单位、实际年份/区域、时效假设及不足清单 |
| PRED-02 标签与特征管线 | 01 | 版本化逐日标签、可知特征、手工检查和泄漏检测 |
| PRED-03 基线实验 | 01/02、冻结初始切分 | B0/B1/B2 的同样本误差与适用支持 |
| PRED-04 候选复现与选择 | 03、训练/验证样本 | M1/M2 受控比较、预算、诊断和选择依据 |
| PRED-05 独立增量评估 | 冻结全部方法、测试封存 | 无锋面/有锋面对照、分提前量和跨期/海区误差与区间 |
| PRED-06 页面/报告接入 | 05 的明确结论 | 时间身份、版本、误差、失败及实验状态一致，可复算 |

门槛依次是数据可支持 → 协议冻结 → 基线可复算 → 候选选择 → 独立评估 → 限定范围展示。取得正向增益不是研究完成的强制条件；如果未来要把实验能力推广为稳定作业工具，需要另外定义可接受误差、时效和真实应用验证。

## 11. 方法来源与后续文献工作

沿用[方法安排](../plans/ocean-methods-selection-and-validation-2026-10-24.md)中的官方方法入口：GAM、Tweedie、成熟梯度提升树、时间顺序验证和空间分块参考。实施时登记所用版本及默认行为，不以当前文档名称代替可运行环境记录。

文献补充针对相同预测目标和可用输入，至少记录论文任务/标签、时空尺度、资料滞后、切分、基线、贡献和限制；选择一个可合法复现的适配候选，而非无条件追求“最新模型”。新增方法通过相同协议比较后才能替换基线或主模型。

# Ocean 统计分析实施协议

日期：2026-10-24。范围：P0/#14、A/#18、B/#19/#9、C/#20 及 G3 稳健性复核。本文是实施设计与冻结清单，不是已经完成的统计研究。产品目标和 A→B→C 顺序已确认；数据支持范围、距离分组、事件阈值及检验参数须经审计和探索样本核对后冻结。

总入口：[总体规划](../plans/ocean-master-plan-2026-10-24.md)。方法路线：[方法选型安排](../plans/ocean-methods-selection-and-validation-2026-10-24.md)。

## 1. 研究问题与允许的结论

| 模块 | 必须回答 | 输出 | 解释边界 |
| --- | --- | --- | --- |
| A 完整月空间关系 | 捕捞活动是否更集中于某些锋面距离、侧别或环境条件？ | 分布地图、距离关系图、侧别比较、逐日支撑、对照及区间 | 相关与条件差异，不解释为鱼量或因果 |
| B 固定海域事件 | 锋面进入/接近固定海域后，活动相对前期及同日背景怎样变化？ | 事件清单、前后窗口表、时滞图、对照与独立样本数 | 观察到的响应，不把前后变化全部归因于锋面 |
| C 区域证据比较 | 几片海域在相同条件下有哪些差异，证据是否足够？ | 统一比较表、图、优势和限制、不可比原因 | 不作综合评分、捕捞成功率或推荐排名 |
| G3 扩展复核 | 结论在东海不同年份、季节和后续海域中是否稳定？ | 冻结协议的独立复核及失效条件 | 不以单月或单海域推广全部海域 |

“有稳定差异”“无明显差异”“不确定性大”“资料不足”都可作为诚实结果。验收要求方法正确和结果可复核，不要求正相关或显著。

## 2. P0 先交付的数据与方法合同

### 2.1 覆盖审计

锋面、SST、活动资料分别记录：产品/来源、空间范围、日期、时间粒度、实际网格、单位、版本、获取/处理方式、许可与可公开边界。按所需分析计算共同支持，不能用某一层的年限代替联合年限。

逐日清单覆盖完整日历月份，记录有效、部分覆盖、缺测、未准备和失败。所谓完整月是完整处理并披露全月支持情况，不是将缺日补零或声称每天处处有效。覆盖阈值冻结前不默认一个月全部可用于推断。

资料状态至少区分：

- 有效记录，包括来源语义明确的零值；
- 无记录但覆盖/零值语义不能确认；
- 已有归档但未在线准备；
- 产品无覆盖、观测缺测或部分覆盖；
- 读取/网络失败及权限问题。

AIS 记录有效不等于真实海上所有作业已被观察；接收、开关、船型识别和算法局限随结果说明。只有来源文档及处理语义支持时，才能把未出现的格解释为该指标的零。

### 2.2 粒度与几何

ADR-0001 的 0.01°分析目标、现有 0.1°活动展示资料及 0.05°锋面/SST 必须分别登记。先核对实际获得的分析真源；若采用其他粒度，应给出偏差、尺度支持与敏感性结果，并依既有 ADR 流程评审，不靠改界面名称消除差异。

固定区分：公里圆形分析区域、地图视野 bbox、距离锋线的缓冲/距离带。空间判断使用地理距离/面积，声明距离算法与容差；经纬度格子的面积不能在不同纬度直接当作常数。

边界格主方案由源网格语义决定：格心归属，或在假设清楚时按交叠面积分摊。采用分摊时说明格内均匀假设，并与格心方案比较边界偏差；不得把未知的格内活动位置说成精确观测。重叠锋面缓冲按空间并集或互斥归属去重，嵌套半径不相加。

### 2.3 冻结资料

产物：覆盖清单、来源/处理版本、受支持月份/区域/半径及拒绝条件、几何规则、有效分母、测试案例和参数协议。资料缺项时明确哪些输出暂不能支持，不通过降低质量门槛隐藏缺口。

## 3. 共用分析表与结果身份

| 记录 | 必备信息 |
| --- | --- |
| 逐日空间基础表 | 日期、格点/空间单元、几何/面积、活动小时、各层有效状态、最近锋面距离、可判定侧别、SST及可用代理量 |
| 区域逐日表 | 区域身份、日期、分组、小时分子、有效面积、有效支持/覆盖、纳入/排除原因 |
| 固定区域事件表 | 区域、事件起止/锚日、判定依据、相关事件组、窗口完整性、处理版本 |
| 对照匹配表 | 事件/日期、对照区域、筛选与可比条件、权重、匹配失败原因 |
| 结果快照 | 提交条件、原资料/方法版本、参数、样本与排除、分子分母、效应/区间、图表、局限与复算依据 |

结果身份至少包括任务类型、位置/区域、公里半径、时间范围、资料版本、方法与参数版本。地图抽样、屏幕聚合或可见点集合不得作为分析真源。

## 4. 指标和分母

以下定义作为实现基线，具体有效支持需先过 P0：

- **活动总量**：给定区域/窗口内来源定义的表观捕捞小时之和。必须写明窗口长度与支持范围。
- **日均活动**：同一明确区域支持上的总小时除以有效日数。支持面积变化明显时，同时报告面积，不能只用日均掩盖变化。
- **面积时间密度**：`H / E`；`H` 为共同有效支持上的小时，`E = sum(每日有效面积 × 对应有效天数)`，单位 `h/(km²·d)`。跨距离带比较使用各自正确面积分母。
- **锋面频次**：在同一空间单元上的锋面有效出现日数/有效锋面观测日数。月度频次只是背景，不代替活动与锋面的逐日关联。
- **差值**：两个支持可比组的同单位指标之差，同时保留原始分子、分母和样本。
- **相对变化**：仅基线为有效正值时计算；基线为零或未知则报告绝对差及原因，禁止无穷增幅。

不能把总量、日均和密度混为一个“强度”。默认主图按研究问题选择统一指标，详细表保留分子分母；聚合加权方式在协议登记，不做“平均值再随意平均”。

## 5. A：完整月空间关系

### 5.1 处理流程

1. 输入选点、公里半径、月份及版本，先检查支持；未就绪与无资料分别返回。
2. 逐日对齐锋面、SST、活动及共同有效支持，保留没有可用记录的日期和原因。
3. 计算最近锋面距离及可判定侧别，构建互斥距离带；未知侧别单列，不硬分冷热。
4. 在每个日/距离带/侧别计算活动分子与有效面积，聚合成月度结果。
5. 构建同月可比对照，检查覆盖、海域环境与样本差异；没有合格对照就限制结论。
6. 输出月度分布、距离关系曲线、侧别差异及逐日证据；默认主界面只取一张主图和简短摘要。

距离带边界、近/远界限和覆盖门槛根据源分辨率、样本和研究尺度试验冻结；不以最终显著性选参数。原始强度字段未接入时，温差/梯度只称代理量，说明计算支持与缺测规则。

### 5.2 推断与敏感性

先报告效应及按日期/区域分组的不确定性，再决定是否满足某项正式检验假设。空间邻格和相邻日期具有相关性，不能把每一行当独立重复。

至少比较几何边界规则、多个支持半径、距离带、覆盖门槛和异常大活动格的影响。异常值处理规则先冻结；不能删除不利样本或把合法多船累计大值当错误。距离、侧别和多个半径的多重分析预先区分主检验与探索，避免只展示显著结果。

### 5.3 A 的完成条件

- 一个经过 P0 认可的完整月候选可复算；日期/有效支持与排除清单可查。
- 基准点、异点、区域边界、缺测、有效零和无稳定关系案例均有真实或明确标注的边界验证。
- 直接计算与缓存/聚合路径在预定数值容差内一致。
- 图、表、摘要、导出和工作台条件一致；月度叠图不充当同日关系证据。

## 6. B：固定海域事件响应

### 6.1 事件定义

研究区域在整个事件窗口固定，不随锋面移动。以锋面进入/接近固定区域的空间关系定义事件，登记候选起止、锚日、阈值、连续日合并和再次触发间隔；不依赖每日局部 F 编号具有长期身份。

事件判定阈值和持续性规则在探索样本中检查源精度与误触发后冻结。保留全部候选、入选、排除和相关事件分组，而非只保留活动增强案例。固定区内多锋面同时出现时记录归属不确定性，避免伪造单锋面因果身份。

### 6.2 时间窗与对照

以前7日为基线，分别研究后1–3日和后1–7日，事件日如何处理在协议中固定。使用统一面积/有效日口径，不直接比较7天总量与3天总量。月初月末所需相邻月份资料不足时补齐或返回窗口不足，不能用后3日推算后7日。

同日对照排除接近锋面的区域，并在可用资料允许时匹配季节、位置、距岸、水深及覆盖。旧“远于50km”最多是一项候选筛选，不自动证明可比。保存匹配误差、支持范围、匹配率和失败事件；不从任意空海域构造低背景。

分别报告事件区前后差、事件区与同日对照差；若构造“事件变化−对照变化”，须说明计算和混杂假设，仍不直接标为因果效应。

### 6.3 相关样本与不确定性

相邻事件、重叠窗口和嵌套半径分组处理。先定义有效独立事件/时间块，再作分组 bootstrap 或符合条件的置换/符号翻转；组内结构保留。重采样次数、种子、区间方法及检验假设预先记录。

旧脚本逐行 bootstrap 和符号翻转可以复用代码结构，但须针对相关性改造。有效独立样本不足时以案例和描述结果呈现，不输出看似精确的置信结论；不强行设置无依据的统一最小样本数。

### 6.4 B 的完成条件

事件可从结果追到固定几何、锚日、窗口、对照和原资料；真实后7日支持存在；独立样本与原始记录数分开。正向、反向、无变化、无法匹配和窗口不足均能解释。

## 7. C 与 G3：比较和独立复核

C 在相同时间定义、单位、研究半径与方法版本下并列区域证据；不同有效面积/覆盖须标明。某区域不支持一项指标时保留空态及原因，不补数或强行排名。

G3 在单月探索后先扩展东海跨年份/季节，再扩展其他海域。探索、方法选择和最终复核样本分开；最终复核不能再依据结果修改距离带或事件定义。跨期无稳定关系也保留。

资料充分时再比较回归/GAM或适合连续非负、含零活动的候选模型，检查可测混杂、非线性与相关性。模型家族和链接函数随分布诊断确定，不默认把小时当整数计数。解释模型和预测模型可以复用特征合同，但研究结论分别验收。

## 8. 借鉴、定制与产物

复用成熟汇总、bootstrap、置换和回归工具；Ocean 独立设计共同支持、几何与事件、对照、相关分组和解释边界。每项借鉴记录原论文/官方实现、适用假设、复现方式、修改处及限制；不要求先自创检验公式。

建议产物目录仅作逻辑约定：覆盖/方法清单、逐日聚合摘要、事件/对照索引、统计汇总、图表、报告、运行清单。源数据与受限细粒度资料留在许可允许的存储；Git 只记录允许公开的协议、脚本、元数据和成果。

运行清单包含输入摘要/版本、提交、参数、软件环境、种子、开始/完成状态、排除及残余问题。资料不可用时允许查看旧快照，同时明确不能复算的原因。

# Ocean A 完整月空间关系分析实施规格

整理日期：2026-10-24。关联既有 A #18、统计协议 STAT-02/03 和执行总纲 #13；复用 P0 #35 及其任务合同。状态：已发布 [规格 #60](https://github.com/NingRuo-code/Ocean/issues/60)，标签 `ready-for-agent`；验证边界已获用户确认。发布标题：`[Spec] A 完整月空间关系分析：公里范围、锋面距离、侧别与捕捞活动证据`。

实施任务已按用户确认发布为#61–#71：[任务与阻塞关系](../tickets/a-monthly-spatial-analysis/README.md)。本行仅为本地导航，远端规格正文保持不变。

## Problem Statement

使用者希望选定地点、公里范围和月份后，了解捕捞活动相对锋面的位置分布：距锋面多远的水域活动更集中、冷暖侧是否不同、这种差异是否只是有效面积或资料覆盖造成，以及结论有哪些限制。这些问题需要同日空间配对后再汇总，不能仅把月度活动图与锋面频次图叠放。

现有历史查询主要统计锋面出现频次和样本覆盖，部分接口仍用经纬度方框；已有响应查询汇总固定预计算事件记录。它们不等于任意受支持位置、公里圆内的完整月活动—锋面关系分析。显示限点、旧事件表、稀疏同日样例及未核实的零值/粒度，不能充当完整研究输入。

A 需要交付第一个可复算、可解释的整月空间分析闭环，为后续 B 事件前后响应、C 区域证据比较及预测增量验证提供基础。科学目标是检验关系，而非预设一定证明正向关系、鱼量增加或捕捞收益。

## Solution

提供显式的确定性月分析入口：接收分析点、公里半径、月份和版本，先读取 P0 支持判定，再对所有日历日逐日匹配活动、锋面及本分析需要的环境条件，形成带来源身份的空间基础量和日级汇总。

以互斥距离带、可判定冷暖侧及同月可比对照汇总真实活动小时与有效面积时间，输出月度分布、距离关系主图、侧别比较、逐日支撑、效应与合格时的不确定性。未就绪、未知、无合格对照和样本不足均有明确结果，不补数、不强分侧别、不强求显著。

结果保留提交条件、输入及方法版本、纳入/排除、分子分母、对照、敏感性和复算证据。图、表、摘要和允许导出的成果由同一结果快照派生；工作台与 AI 后续消费这些结果，不另算数字。

## User Stories

1. 作为研究者，我希望选择受支持海域内任意分析点，以便分析不再局限于固定示范锚点。
2. 作为研究者，我希望用公里半径定义研究范围，以便范围具有明确地理含义。
3. 作为研究者，我希望明确选择一个日历月份，以便知道研究包含哪些日期。
4. 作为使用者，我希望提交前知道数据是否支持该条件，以便不把未准备误认为没有活动。
5. 作为研究者，我希望所有日历日都有纳入或排除记录，以便完整月不掩盖缺日。
6. 作为研究者，我希望活动与锋面按同日匹配，以便不同日期的叠图不冒充空间关联。
7. 作为研究者，我希望区分地图视野、分析圆和锋面缓冲，以便拖动地图不改变研究范围。
8. 作为研究者，我希望使用完整有效分析输入，以便热点过滤和屏幕聚合不改变结论。
9. 作为研究者，我希望知道实际资料粒度及其支持的尺度，以便粗展示资料不会冒充精细观测。
10. 作为研究者，我希望有效零与未知覆盖分开，以便不会将没有记录的海域当作零活动。
11. 作为研究者，我希望最近锋面距离有明确搜索支持，以便资料边界外的锋面不会被错误忽略。
12. 作为研究者，我希望没有检出、搜索范围不足和真实无可用距离分开，以便不会随意被归入远距组。
13. 作为研究者，我希望距离带互斥且边界规则一致，以便活动和面积不重复累加。
14. 作为研究者，我希望冷侧、暖侧和未知侧分别呈现，以便不把模糊位置强行分类。
15. 作为研究者，我希望多个锋面重叠时有明确归属，以便同一小时不被重复计算。
16. 作为研究者，我希望每组同时显示活动小时和有效面积，以便不把水域更大误读成活动更集中。
17. 作为研究者，我希望总量、日均和面积时间密度分别命名，以便比较时不混淆单位。
18. 作为研究者，我希望月汇总由可加分子分母重算，以便不会被不恰当的均值平均扭曲。
19. 作为研究者，我希望比较近锋面区域与同月可比背景，以便知道差异是否超出一般活动分布。
20. 作为研究者，我希望对照记录匹配条件和失败原因，以便无法匹配时不生成虚假的低背景。
21. 作为研究者，我希望可用环境条件及未控制因素明确列出，以便理解相关性解释的限制。
22. 作为研究者，我希望水温或梯度分析只使用实际支持资料，以便缺少字段时不靠推断补齐。
23. 作为研究者，我希望温度梯度代理与原始锋面强度分开，以便不会将不同指标混称强度。
24. 作为研究者，我希望查看每一天对月度结论的贡献，以便识别单日主导或覆盖异常。
25. 作为研究者，我希望效应大小和不确定性一起呈现，以便不只关注显著与否。
26. 作为研究者，我希望相邻格和相邻日的相关性被保留，以便行数不被当作独立样本数。
27. 作为研究者，我希望样本或假设不足时只报告描述结果，以便不出现看似精确的区间。
28. 作为研究者，我希望比较半径、距离带和覆盖规则的敏感性，以便知道结论是否依赖某个选择。
29. 作为研究者，我希望合法多船累计大值不被随意删除，以便数据处理不会偏向预期结果。
30. 作为研究者，我希望参数与主分析在正式计算前冻结，以便不能看显著性后挑选方案。
31. 作为使用者，我希望结果给出一张主图和简短解释，以便不必先理解全部统计细节。
32. 作为研究者，我希望按需查看距离、侧别、对照和逐日表，以便复核主要结论。
33. 作为使用者，我希望旧结果清楚保留原条件，以便改日期或地点后不会误读为新结果。
34. 作为研究者，我希望同输入直接重算与缓存结果一致，以便优化不改变研究意义。
35. 作为研究者，我希望图表、摘要和导出共享同一结果身份，以便不会数字互相矛盾。
36. 作为维护者，我希望未通过支持判定时返回具体前置，以便安排补资料或降低可声称范围。
37. 作为研究者，我希望无明显关系、反向差异和资料不足同样保留，以便系统不只展示有利案例。
38. 作为研究者，我希望合成小例与真实完整月验证分开，以便测试通过不冒充真实科学证据。
39. 作为访客，我希望只读取已批准公开的就绪结果，以便不会触发后台研究计算或泄露细资料。
40. 作为维护者，我希望显式执行、失败与结果发布有清楚状态，以便中断或部分产物不会被当成完成。
41. 作为后续模块开发者，我希望获得稳定基础表和结果合同，以便 B/C、工作台及性能实验复用。
42. 作为项目负责人，我希望 A 的完成由真实可复算案例和边界证据判断，以便不依赖是否发现正相关。

## Implementation Decisions

### 1. 范围、现有基础与真实依赖

- 本规格细化 [A #18](https://github.com/NingRuo-code/Ocean/issues/18)，属于 [执行总纲 #13](https://github.com/NingRuo-code/Ocean/issues/13)，承接 STAT-02直接参照和STAT-03月度关系。已读取 #18 最新正文与评论，仍开放、暂无评论；本轮未实施或运行新的科学分析。
- 复用现有确定性查询、历史读取、数据适配及实验产物结构。旧历史频次、经纬度方框、固定事件表及逐行bootstrap不作为A已经完成的证明，也不悄悄改名成月度活动关系结果。
- P0 [#39](https://github.com/NingRuo-code/Ocean/issues/39) 提供几何/分母，[#41](https://github.com/NingRuo-code/Ocean/issues/41) 提供月度资格，真实资料关口证据由 [#44](https://github.com/NingRuo-code/Ocean/issues/44) 承接。软件小例与合同可先推进，正式候选月计算须对应用途的实际支持通过，不能只以这些Issue关闭替代数据资格检查。
- 首选东海2024-08，输入必须支持任意受支持点，而非只对预置坐标查表。现有10/20/30km仅为已有档位，研究支持由P0决定；不擅自批准其他半径或把名义覆盖解释为任意海域均可分析。
- ADR-0001的0.01°活动分析目标保留；0.1°展示、0.05°锋面/导出及实际SST来源分别登记。真源不能满足时保留阻塞，粒度替代需相应评审，不靠插值或改字段名通过。
- [#21](https://github.com/NingRuo-code/Ocean/issues/21) 在A验收后接入工作台，不能让A反向等待整个W完成；A先交可独立调用的确定性入口、图表及结果合同。P1 [#57](https://github.com/NingRuo-code/Ocean/issues/57)/[#58](https://github.com/NingRuo-code/Ocean/issues/58) 消费A的稳定输入与参照，A不得反向依赖它们形成循环。近期地图性能和完整AI不是A数值参照的前置。

### 2. 输入资格、状态与结果身份

- 请求包含用途/任务类型、分析点或固定区域、公里半径、具体年月、P0支持快照、源/处理/方法/参数版本；明确主分析、对照和敏感性设置。规范化只消除等价表示，不自动换月、换点、扩圆或降低质量要求。
- 读取P0同用途判定，核对完整日历、必需层与共同有效支持。基础活动—锋面关系要求相应两层；侧别、SST或梯度子分析额外要求其确切输入。可选强度或海况未接入不阻塞不使用它们的主分析。
- 支持、有限支持、未准备、无资料、未核实、权限不足及执行失败有稳定状态和原因。未通过主分析门槛时返回缺失前置；允许的部分描述保留限定范围，不能冒充正式完整月结果。
- 资料可用性与任务执行状态分开。显式提交与只读结果消费分开，打开历史页或修改条件不自动重算整月或准备归档；访客读取公开就绪结果，本人详细执行沿用服务端授权合同。
- 任务记录提交时条件和版本，执行中改条件不改变该任务；运行、失败/中断、完成状态可查，校验完成后才发布结果。复用可用的最小任务适配，不在A复制完整排队、重启恢复或任务中心。若公共运行能力尚缺，先交显式受控执行与不可变产物，不能将其称为完整后台任务产品。
- 结果身份涵盖请求、原资料、空间/时间支持、方法/参数/质量规则、对照与运行版本。新计算不覆盖旧快照；图表、证据、缓存和导出引用同一身份。

### 3. 直接计算参照与逐日基础量

- 首先对合法小样建立不依赖显示筛选或预聚合的直接参照，贯通资格→真实数据读取→日级配对→分子分母→月汇总。用独立手算/可信几何参照核对，不以优化路径生成自己的期望答案。
- 全月按日历枚举，逐层读取并记录有效、部分、零、未知、缺失和失败。成功读取与有效观测分开，缺日不补零或被悄悄跳过，整月计算不等于每天处处有效。
- 活动源格/分析单元保留日期、几何身份、源粒度、真实小时和有效状态；同日配最近已检出锋面距离、侧别及所需环境量，附来源和处理证据。展示格或活动分位/700点限集不能充当分析输入。
- 不强迫不同网格简单逐像元对齐：遵循P0空间归属与共同支持合同，以源语义明确的格心或交叠方案配对；必要的环境取样说明匹配偏移和范围，不将邻格值冒充目标格精确观测。
- 逐日汇总保留区域、距离带/侧别、小时分子、有效面积/时长、纳入/排除及证据。基础细表仅供许可范围内内部计算；公开图表和接口默认使用允许的聚合，不传出可逆细网格。
- 每层、每日和分组有分子/分母守恒核对，报告未归属或未知部分；重复源、重叠缓冲和多锋面不得造成重复计时。直接参照通过后才加索引/结果缓存，优化前后按冻结容差一致。

### 4. 距离、侧别、边界与环境量

- 目标距离是分析单元在已核实支持内到当日最近已检出锋线的地理距离，区别于分析点到对象中心或地图像素距离；源格语义与误差随结果声明，不把格级位置称为实际船舶轨迹。
- 最近锋面搜索范围不被用户圆或屏幕裁切截断。根据最大距离带、数据分辨率和误差配置必要的额外搜索支持，核对圆外近锋面及数据边界。若仅有有限搜索范围，保留下界/范围未知状态；不能将没有搜到线自动当无限远或真实无锋面。
- 有效观测下未检出、锋面层缺测、搜索支持不足和可判定距离分开。下界是否足以确定某个距离带依冻结规则判断，不捏造精确距离曲线点。
- 距离带互斥，端点、最外带和未确定组规则版本化；同一空间单元对同一主分析只归属一次。主规则先用源精度和几何小例确定，不根据活动差异挑边界。
- 冷/暖侧基于实际产品支持及一致归属规则；多锋面歧义、线附近不确定或缺资料时保留未知。侧别已知子集的分母单独报告，不能拿全部活动作其分子、已知侧面积作分母。
- 边界格、陆地、未知覆盖、跨范围圆及重叠归属复用P0冻结规则。分摊采用格内均匀等假设时说明限制；分析圆固定，不随每天锋面移动，也不因视图变化改变。
- SST记录单位、有效支持与取样方式；梯度/温差如果计算，只标相应代理和单位/尺度，记录空间方法与缺测。未接入真实强度产品不输出“真实锋面强度”。这些子分析不能暗中改变主分析样本而不披露。

### 5. 指标、月汇总与主要估计量

| 指标 | 计算与解释合同 |
| --- | --- |
| 活动总小时 | 当前区域/分组的共同有效支持上真实小时之和；保留时窗和覆盖，不等于渔获 |
| 同支持日均 | 在明确可比支持上的总小时除有效日数，面积变化同时报告；不以日均掩盖支持变动 |
| 面积时间密度 | 全月有效小时分子之和除逐日有效面积×有效时长之和，单位h/(km²·d) |
| 组间效应 | 同定义、同单位的近/远距或侧别/对照密度之差，保留双方原始分子分母 |
| 相对差异/比值 | 仅基线有效且为正时计算，基线0/未知时不给无穷增幅，保留绝对差和原因 |
| 锋面频次 | 有效出现日数/对应有效观测日数，仅作背景，不代替同日空间关系证据 |

- 主问题优先采用面积时间密度及其组间差；总量、日均和密度分别命名，不用“强度”混称。月度总量不由每日平均值再随意平均；若采用日等权等其他估计量，需单列其问题、权重及版本，不冒充同一指标。
- 逐日分子与面积时间分母必须落在同一必需层共同支持。分母0或未知时指标不可计算，不填零；大于24小时可为多船累计，不自动删作异常。
- 同月时间支持变化、某距离带/侧别无面积或无可比日时，保留缺口。多个组和多个半径共用日期时，比较不能通过不同隐含纳入日产生假差异。
- 月度空间分布、距离关系和侧别摘要能回溯到逐日支撑；未知组、排除小时/面积及支持变化可查。未归属部分不能为图形整齐而消失。

### 6. 同月对照与关系解释

- 先明确对照问题：同一分析圆中可比远距带可构成距离参照；需要额外非锋面区域时，另记录候选空间域、匹配和P0支持，不能悄悄扩大用户分析圆或从无覆盖空海域构造背景。
- 对照与目标按同月同日及兼容有效支持比较；报告日期交集、面积/环境差异、匹配条件、权重、可比性和未匹配日。仅距离超过某阈值不自动等于可比，旧50km不能未经核实直接作为正式标准。
- 已有且质量支持时核对季节/日、位置、距岸、SST等可测因素；水深/渔具等资料没有就标未控制，不为本版新增无依据下载或以模型想象补齐。无法构造合格对照时保留描述关系，减少可声称范围。
- 同一主效应在明确成对可比日/支持上计算，保持目标、对照分子分母及权重。对照选择及平衡检查先于正式差异结论，不能以低活动或有利效果挑选对照。
- 输出“该月该支持范围的活动分布与锋面距离/侧别有关或没有稳定差异”等条件性解释。不能从同月相关推出锋面导致作业、鱼更多、捕捞成功率或收益，也不能以A单独证明预测增益；后者由后续独立预测实验检验。

### 7. 不确定性、参数冻结与敏感性

- 先报告效应、原始记录数、有效日/面积与可用独立组，再判断是否具备推断条件。空间邻格、相邻日期和嵌套半径不能当独立重复；旧186行事件记录也不是本月研究独立样本数。
- 月分析以日级可加基础量承载空间聚合，保留同日各组的对应关系；若相邻日相关，按有依据的连续时间块/分组重采样，必要时结合区域分组，不能仅开启“paired”选项就称解决全部相关性。
- 每次重采样保持目标/对照及各组共同结构，并重算小时和面积时间之比及效应，不默认对已算出的日均再平均。组长度/方案、置信水平、次数、随机种子和失效处理在正式运行前冻结并记录理由。
- 工具优先复用成熟统计实现，Ocean定制支持、分组和估计量；通用bootstrap接口并不自动给出合适的时空抽样设计。可参考 [SciPy bootstrap官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html) 与 [时间序列bootstrap官方实现说明](https://arch.readthedocs.io/en/latest/bootstrap/timeseries-bootstraps.html)，具体依赖及方法在冻结方案登记，不承诺同时使用全部组件。
- 置换/符号翻转仅在相应可交换/对称等假设可说明时作为补充。无法支持推断、有效独立组太少或重采样退化时，返回区间不可可靠估计及原因，保留描述和逐日变化；不为得到数字临时改用有利方法，也不设无依据统一最小样本数。
- 主分析距离带、主要效应、对照、质量门槛、异常规则与敏感性清单先冻结。源精度/覆盖小例可用于规则检查，不能以最终显著性调参；同月反复探索的结果标探索性，独立跨期复核留给G3。
- 敏感性至少覆盖P0支持的多个半径、边界归属、距离带、覆盖门槛及合法大活动格的影响。主结果保留全部合法值，其他处理只作有依据的敏感性方案，不删不利样本。
- 多个侧别、距离带和半径区分主分析与探索；如做正式多项检验，先登记检验族与相应处理，或只报告探索性区间和限制，不从大量结果中挑显著一项。

### 8. 图表、证据与最小结果消费

- 结果至少包含月度活动分布、距离关系、侧别比较、同月对照及逐日支撑；主消费界面只取一句简短解释、关键指标和一张主图，其他证据按需展开。无图所需资料则展示原因，不生成假曲线。
- 距离关系图明确横轴距离带、纵轴指标/单位、有效支持和可用区间；未知组/无可比支持有独立说明，不连线穿过缺测当真实趋势。
- 侧别和环境子分析写明子集、样本与分母变化；月度锋面频次可作背景，不能与月活动叠图代替逐日配对的证据。
- 给基准点、异点、边界、有效零、缺测和无稳定关系路径可读产物；正向、反向、无差异及资料不足都如实显示，不由模板固定写“锋面附近更适合捕捞”。
- 图、表、摘要、聚合导出和日级证据同源，标注条件/数据/方法版本与局限。基础成果包可包含允许的聚合表、图和运行清单；完整PDF编排、案例库和任务中心产品另行细化。
- 工作台/历史入口后续通过#21按A验收进度接入，AI只能组织已计算证据。A自身须可独立受控执行和读取结果，不把完整工作台或AI当核心数值验收前置；旧频次和实验规则仍保留其原身份，不冒充A。

### 9. 查询合同、缓存与跨模块交接

- 优先沿用已有确定性服务的条件、状态、证据和结果模式，增加明确月度分析用途/版本。现有历史轻量读取不能因兼容改造而隐式执行重任务；需要新增正式提交/结果入口时保持旧调用方语义。
- 主返回保留任务/结果身份、请求条件、支持状态、覆盖/排除、单位、日级/分组分子分母、效应/可用区间、方法与对照参数、图表数据、证据和局限；未知与0有明确区分。
- 对重复条件可复用身份一致的合格结果，直接重算与缓存/普通聚合一致；资料、几何、质量、对照或方法变化必须新身份，不能按月份或文件名粗略混用。失败中间产物不发布为完成。
- 内部逐日空间表与许可允许的聚合视图分开；对P1提供冻结的合法基础量、普通直接参照、查询语义和版本，普通数据库或Mosaic对照不能改变分母或引入未验证精度。
- B复用逐日支持和几何但另做固定区事件、前后窗口与对照；C复用兼容结果再做多区域并列；预测另作时间可知输入和独立验证。A不为这些后续任务预填效果或复用已看结果作为独立测试。

### 10. 冻结清单与完成关口

| 阶段 | 必须交付 | 实际前置 |
| --- | --- | --- |
| 合同与直接小例 | 输入/输出、日级基础量、估计量、几何与已知答案 | P0合同可复用；合法夹具可先做，真实资格不能由夹具解除 |
| 真实资料准入 | 目标用途月度资格、实际粒度、许可及共同支持 | P0 #39/#41 与 #44对应证据；源差异走既有ADR流程 |
| 直接完整月参照 | 全日历逐日匹配、分组与月度分子分母 | 准入及冻结规则通过，不使用显示样本 |
| 对照与不确定性 | 可比性、效应、分组/时间相关处理、退化状态 | 有支持的数据与假设；不足时描述降级并明确不可推断 |
| 成果及交接 | 同源图表/摘要、敏感性、版本与复算、确定性消费合同 | 正确参照与可解释结果；无需完整AI或论文优化 |

- 真正A完成需要至少一个经P0认可的真实完整月候选可复算，以及基准/异点/边界/零/缺测/无稳定关系等正确性路径。边界场景允许明确标注的合成补充，但不能用合成整月替代真实案例；无需刻意寻找真实“无关系”月来证明正负测试通过。
- 资料不足时可以交付接口、测试及缺口结果，但不将其登记为真实完整月研究已通过，也不关闭相关未完成工作包。软件功能完成、真实关口、PR、合并和部署分别记证。
- 参数在来源和探索小例检查后冻结，变更保留版本、理由和影响。没有最终冻结的距离数值、对照阈值、块长度和覆盖标准不凭空写死；该依赖在后续票据登记，不重问已确认研究目标。

## Testing Decisions

### 1. 已确认的主要验证入口

以“显式调用完整月确定性分析，取得同身份结果与证据”为主要端到端入口，优先沿用现有 FastAPI 测试客户端和确定性查询检查。通过真实读取、资格、逐日匹配、几何、分子分母与汇总链输出核对，而非只测试内部统计函数。

内部执行/批处理使用同一计算合同；图表、摘要和允许导出作为同结果的消费验证。工作台接入时补浏览器操作检查，不为A新建测试专用接口，也不等待全部#21/AI才能验证核心分析。

用户已于2026-10-24确认上述验证边界：明确提交的整月分析请求验证实际流程与同身份结果/证据；独立手算小例核对距离、侧别、小时、面积时间分母、零值/缺测及相关样本；真实合格整月与合成测试分开记证；复用现有API入口，工作台展示联动在后续集成任务验收。此前界面、P0和P1验证决定继续有效，不直接当A已通过。

### 2. 好的测试与既有基础

- 检查请求与实际条件、公开合同状态、真实分子分母、组归属、证据身份和可读产物，不绑定内部函数拆分、目录、字段排列或图表DOM结构。
- 复用已有确定性查询的正常/部分/空态、缺数据不报零和版本缓存检查，以及数据一致性工具。旧历史概率和事件表断言保留其旧用途，不强行套成A的完成依据。
- 用很小的可手算空间/日历夹具构造已知正/负/无差异、有效零和未知，独立参考实现或几何解析小例确定预期；禁止用被测聚合路径生成自己的期望。
- 真实候选月运行与合成合同验证分开。统计方法验证关注估计量、组结构、成对关系、种子复现和退化处理，不用“多数模拟都显著”作为功能标准。

### 3. 必须覆盖的场景

| 场景 | 可观察验收 |
| --- | --- |
| 任意受支持点/月份/公里范围 | 不查固定锚点；非法或不支持条件不静默更换，资格与结果一致 |
| 全日历与单层缺日 | 每天有状态，必需层交集正确，可选SST不无谓改变主分析 |
| 零、无记录与覆盖未知 | 不混为0；缺失不入有效分母，分母0和零基线不产生伪精确值 |
| 圆外近锋面与搜索边界 | 最近距离不受屏幕/分析圆截断，支持不足保留未知/下界 |
| 距离带端点/多锋面/侧别歧义 | 互斥归属、重叠去重、未知单列；分子分母使用同一子集 |
| 海岸/跨范围/不同纬度 | 圆、bbox和缓冲区分，面积和源粒度遵循P0及冻结容差 |
| 日级到月级聚合 | 小时、面积时间和权重可独立重算，不随意平均比值或均值 |
| 可比对照与失败匹配 | 同日/同月支持清楚，背景不足则降低结论，不补空海域作低背景 |
| 相关结构与区间 | 同日组保持配对，相邻日按冻结设计处理；独立组少/退化不强给区间 |
| 敏感性与多重探索 | 主分析固定，全部约定变化有记录，不选择性删除大值或不利结果 |
| 直接、缓存与聚合消费 | 同支持结果一致，换资料/方法有新身份；图表/摘要/导出同源 |
| 执行失败和改条件 | 结果只属于提交快照，中间产物不发布为完成，改条件不隐式重算 |
| 真实月与负结果 | 合格月可复算，无明显差异可正常展示；合成证据不冒充真实覆盖 |

### 4. 真实验收与证据

- 首选2024-08经P0核实后运行，保留实际输入/版本、全日历支持、逐日/分组聚合、对照与排除、运行环境、种子/分组、图表和敏感性。只保存许可允许的成果，原始及可逆细资料留在受控存储。
- 小例与真实运行均输出复算依据及数值容差。API结果、直接参照、图表和读取快照可相互核验；如公开摘要脱敏导致不能包含底表，保留内部证据定位而不泄露路径。
- 实施时按影响运行后端、数据和必要浏览器回归；统计/几何验证与性能测量分开。此轮仅整理规格，未运行新的真实月计算、科学检验、应用测试或部署；文档检查不能填写科学通过结论。

## Out of Scope

- B固定海域锋面经过事件、前后响应及C多区域正式比较；A仅交同日月度空间基础与可复用合同。
- 锋面生命周期/移动/分裂合并深度研究、跨年跨区独立复核、正式因果识别或证明普遍渔业收益。
- 活动预测训练及锋面信息增量回测、实时滚动预报、外部未来7/10天海温接入。
- 完整AI、多轮自然语言任务执行、完整任务中心/重启恢复/案例库及PDF产品化；最小确定性执行与结果状态不冒充上述完整能力。
- 重复P0审计与精度裁定、U1/U2布局配色、P1论文/数据库优化；不等待#57/#58反向阻塞A。
- 未批准的粒度替代、新资料授权/付费下载、受限数据公开、自动合并或部署；不输出渔获/收益、成功概率或综合推荐排名。

## Further Notes

- 本规格是A/#18的执行细化，后续to-tickets应从直接计算小例到真实月、对照/不确定性和成果逐项拆分，明确P0实际前置，复用#9实验基础但不搬用其逐行推断结果。
- 优先复用成熟统计与地理计算组件；Ocean独立设计同日空间支持、分母、归属、对照和解释边界，不要求先发明新模型。任何算法创新主张另需原始文献、基线与独立实验。
- A回答该月该海域范围内的条件关系；“更接近锋面”与“活动更多”的单图关联不足以证明因果或预测价值。正向、反向、无稳定差异和资料不足都是合法输出。
- 已有领域文档的固定增强阈值、评分与旧对照距离不在本规格重新确认；新分析遵循已确认统计协议与P0规则，必要变更记录版本，不静默覆盖ADR。
- 无硬性截止。当前完成的是可实施规格整理，不是数据关口解除或研究结果；后续依证据推进，重大范围/费用/许可或研究目标变化再作具体取舍。

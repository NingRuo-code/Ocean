# Ocean P1 演示提纲

> 用途：课堂/阶段汇报时的页面演示顺序。本文只描述当前仓库已经闭环的能力，不把 synthetic fixture 说成真实 AIS/GFW 证据。

## 1. 开场定位

一句话：

> Ocean 是一个面向渔场作业辅助的海洋锋面分析原型。它基于真实海洋锋面、SST、历史同期统计和 AIS apparent fishing effort 响应证据，帮助用户形成“哪里值得关注、依据是什么、边界在哪里”的作业线索。

必须强调：

- 当前不是“产量预测”或“收益预测”系统。
- 当前 AIS 响应是 `synthetic_fixture`，只验证数据契约、计算口径和 UI 证据链。
- AI 分析只组织证据，不直接生成科学数值。

## 2. 地图面板演示

演示顺序：

1. 顶栏设置出发地、作业范围和出海日。
2. 指出地图里的真实图层：陆地/海岸线、水温、锋面带、锋面线、冷暖侧、无观测区域。
3. 切换 10 / 20 / 30 km 作业范围，说明它是全局唯一范围真源。
4. 使用鼠标悬停展示任意点查询：经纬度、水温、最近锋面距离、是否锋面区。
5. 点击锋面线或作业线索，展示地图选中回执。

讲法：

> 地图不是装饰层。每条锋面线、每个对象编号、每个温度档位都来自离线数据文件，并由 `data-check` 和 e2e 回归验证。

## 3. 当前页演示

重点看三块：

- 当前渔情：范围内锋面区数量、最近锋面、所处侧、把握度。
- 作业线索：首选锋面区、方位、距离和可点击定位。
- 历史 AIS 响应：响应状态、post1-3 fishing hours、lift、non-front control 和 caveat。

讲法：

> 当前页把“现在有什么锋面线索”和“类似锋面情境下是否存在表观作业响应”放在同一个全局上下文里。日期和范围变化后，AIS 响应证据也必须跟着变。

## 4. 历史页与预测页演示

历史页：

- 当日 / 3 日 / 7 日 / 15 日 / 当月 / 整年六档。
- 重点说明 `front_present = 半径内锋面线像元数 > 0` 是唯一历史统计口径。
- 对样本不足的连续窗口、整月、整年，页面明确写出样本边界。

预测页：

- 展示 1 / 3 / 7 天规则预测参考。
- 强调它是规则参考，不是业务级预报。
- 已有样例日期可点回看实况，仍回到同一个出海日真源。

## 5. AI 分析与数据说明

AI 分析页讲法：

> AI 分析页展示的是证据组织和任务编排：当前证据、历史参照、规则预测参考、AIS 响应和限制项。它不生成 fishing hours、lift 或任何新的科学数值。

数据说明页讲法：

> 所有可展示的数值都必须能追溯到数据来源、计算口径和限制条件。AIS response 使用 apparent fishing effort / fishing hours，只表示表观捕捞活动，不等于渔获量、产量或收益。

## 6. P1 方法闭环

用一条典型事件说明：

- `front_event_id = 2024-08-05:F001`
- 前 7 天基线：2024-07-29 ~ 2024-08-04
- 后 1-3 天响应窗口：2024-08-06 ~ 2024-08-08
- 默认产品半径：20 km
- 20 km synthetic fixture：pre7 = 42.5 h，post1-3 = 57.8 h，control = 36.4 h，lift = +36%，状态为响应增强

讲法：

> 响应增强不是只看 post fishing hours 高不高，而是同时要求 post1-3 高于前 7 天基线的 120%，并且高于同日非锋面对照区。

## 7. 结尾

阶段结果：

- P1 已完成从 Front Response Table 到当前页、AI 证据链、数据说明和回归检查的最小闭环。
- 当前验证基线：`data-check` 897 项、`e2e-check` 108 项、`layout-check` 25 项全部通过。
- 后续真实样例接入时，沿用同一转换脚本和同一数据契约，不需要重写 UI 证据路径。

后续路线：

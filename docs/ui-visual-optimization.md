# 图形化界面优化说明

本轮优化目标是把锋面演示从“点和线的技术验证”升级为“更直观的海洋锋面图像”。当前实现仍完全离线运行，所有图层来自本地 NetCDF 裁剪结果。

## 视觉表达

| 图层 | 新表达 | 用途 |
|---|---|---|
| SST 温度场 | 后端 PNG raster + GeoJSON 面场兜底 | 让海温从散点变为真正图像底图 |
| 锋面带 | 深色半透明面 + 金色描边感 | 让锋面位置在海温背景上更醒目 |
| 锋面中心线 | 黑色线 + 金色辉光 | 保留精确线状位置，同时提升可读性 |
| 冷侧 / 暖侧 | 蓝色 / 橙色半透明面 | 更直观看出锋面两侧结构 |
| 锋面强度 | 橙红半透明面 | 本地存在 front_intensity 时展示强度热区；没有数据时显示占位和缺口 |
| 锋面对象 | 绿色虚线包围框 + 绿色质心点 | 把连续锋面线像元组织为可讨论的对象 |
| 多日追踪 | 紫色虚线 + 追踪节点 + 方向箭头 + 匹配分数 | 表达连续日期最近锋面对象的位置变化、速度、方向和匹配可信程度 |
| 选中高亮 | 黄色对象框 / 质心点 + 紫色轨迹节点高亮 | 点击对象或追踪日期后，地图可直接定位当前讨论对象 |
| 预测 baseline | 逐日概率卡片 + 驱动因子权重条 + 回测卡片 | 用历史同期、月度概率、近期状态和梯度修正解释未来 1—14 日锋面可能性 |
| 查询窗口 | 青色边框和淡填充 | 明确当前统计范围 |
| 查询点 | 高亮圆点 | 明确经纬度任务中心 |

## 界面分区

- 顶部为任务参数区：日期、经度、纬度、空间范围、概率口径、普通查询和“一键演示”按钮；
- 地图上方为读图卡片：海温场、锋面状态、对象识别、局地梯度和 raster 尺寸；
- 地图左下为图像图层开关：SST、锋面带、中心线、锋面强度、锋面对象、多日追踪、冷侧区、暖侧区；
- 右侧改为 Tab 化功能区：当前查询、历史统计、对象追踪、预测 baseline、数据状态和 AI 分析分开展示，减少长侧栏滚动负担；
- 一键演示会自动切换当前查询、对象追踪、历史统计、预测 baseline 和数据状态，并显示每一步讲解提示；
- 对象追踪区展示对象数量、最近对象 ID、选中对象详情、对象长度、质心、bbox、SST 均值、三日追踪状态、方向、速度和匹配分数；点击对象列表会聚焦地图 bbox；
- 追踪时间轴支持点击日期节点，右侧显示该日匹配方式、速度、方位角、连续性和候选数量，地图同步高亮轨迹点；
- 预测区展示首日预测概览、未来 7 日概率、预测状态、可信度、历史同期/月度/近期/梯度驱动因子、驱动权重条和回测观测；
- 历史区增加同期年份命中图和图例，直观看出 1982—2024 中哪些年份命中、未命中或缺失；
- 月度统计图同时显示概率柱和样本覆盖浅色条，避免只看概率而忽略样本量；
- 数据状态区展示 front/SST/front_intensity 文件数、日期数、文件体积、配对日期、就绪度仪表、缺失年份、强度缺口和 manifest 生成时间；
- 数据准备计划中的命令预览支持点击复制并显示反馈，方便继续补样、重建索引和运行验收；
- 当前查询区提供 JSON 原始结果导出、HTML 汇报预览和 HTML 文件导出；
- AI 区展示结构化任务、工具调用、结论、证据 ID 和解析说明；
- 历史区展示时间索引、空间索引、概率指标、趋势图、月度图和缓存。

## 验收关注点

1. 老师能直接看出“底色是海温、深色带是锋面、蓝橙是冷暖侧”；
2. 查询范围、查询点和右侧数值能同步变化；
3. “一键演示”能自动加载默认案例并完成查询，降低现场输入出错风险；
4. 绿色对象框和质心能让老师看出“对象级锋面”，点击地图对象或对象列表能在右侧查看详情并在地图高亮；
5. 紫色追踪线和箭头能说明连续日期变化方向，点击追踪日期能聚焦当天轨迹点；
6. 图层开关能独立控制，不影响查询结果；
7. AI 只解释和组织任务，不直接生成科学数值；
8. 导出报告包含单日分析、对象追踪、预测 baseline、历史统计、点位查询和 AI 结果；
9. HTML 汇报报告能在界面内预览，也能下载后直接打开阅读，适合阶段沟通和老师验收。

## 当前边界

- 当前 SST 底图已支持后端预渲染 PNG raster，冷暖侧、锋面带、对象框和追踪线仍使用 GeoJSON 叠加；
- front_intensity 是可选图层，当前本地未放入强度文件时不会阻塞演示；
- raster 已加入后端 PNG 缓存，并在无有效尺寸时避免前端加载 0 宽/高图像；
- 小范围演示足够清晰，全量大范围或长期数据接入后建议继续升级为瓦片、COG 或 Zarr；
- 预测 baseline 是透明规则基线，适合演示和模型对照，不代表论文级预报模型；
- 冷暖侧和锋面带来自 `front` 编码解释；对象 ID 来自连通像元聚类，不代表论文数据集中已有长期轨迹编号。

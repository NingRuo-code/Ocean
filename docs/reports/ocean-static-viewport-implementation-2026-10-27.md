## 完成内容

| 原问题 | 当前行为 |
|---|---|
| 静态字典可能因网格/几何/编码异常报错或误读 | 类型校验日期、有限值、范围、RLE和锋面对象；坏层降级，有效其他层仍可读 |
| 缺小时、覆盖或冲突来源可能混进展示 | 主小时/覆盖必须明确；单位、指标、日期显式冲突拒绝；缺值不补0 |
| 一好一坏重复身份可能择一 | 先按原始身份计重，再校验内容；重复全部排除 |
| JS包装和额外语句边界不明确 | 仅接受既有生成器字面量格式，不执行JS；重复键、二次赋值拒绝 |
| 静态响应点被当作同日活动格 | 明示`front_response_aggregate_points`及历史后1–3日窗口限制 |
| 摘要将缺失辅助指标补0或只算已知子集 | 逐指标要求全部返回记录已知；否则null；明确零/false仍可产生0 |
| 缓存旧结果可能绕过新校验 | 升级`static-prototype-v1-contract-v2`，查询版本`basic-query-v2` |

新增输入模块纳入已有发布包明确白名单，确保隔离原应用仍可导入。单文件32 MiB、展示网格2,000,000格上限；拒绝超预算，不以截断伪造完整数据。不是全球原档读取算法。

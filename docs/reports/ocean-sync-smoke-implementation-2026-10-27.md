## 修复了什么

旧脚本依赖首页包含“Ocean”和接口字符串，当前中文页面会被误拒；即使接口可读，历史缺资料或显式跳过也没有统一的范围就绪结果。现在沿用同一PowerShell入口，核当前页面标记和结构化API合同，输出安全JSON。

| 结果 | 退出码 | 本次可说明的事实 |
|---|---|---|
| ready | 0 | 选定API样例声明就绪且合同可读，不是研究或生产资格 |
| limited | 0 | 选定样例部分覆盖、资料不可用或显式跳过 |
| limited + RequireReady | 2 | 严格选定范围未通过 |
| failed | 1 | 传输、权限、畸形响应或条件/合同冲突 |

检查回显日期、bbox、step、来源类型、覆盖、单位和核心计数；部分覆盖框为有效请求子集，整体地理空覆盖为null。基础响应的活动缺层不等同于地理范围失效。SST/活动样例核有限数、合法坐标及非负小时，明确0保留。日活动清单与选定日期/格点数一致，缺小时或显式catch/kg冲突拒绝；未就绪索引不会冒充已读取日样本。

Windows PowerShell原生进程使用UTF-8读取API中文元数据。超时在安全处理范围内解析为1–120秒；输出不回显目标地址、正文、原错误和非法已知参数值。请求只用GET，可能填充原有缓存，不提交分析、不准备归档、不调用模型或修改服务。

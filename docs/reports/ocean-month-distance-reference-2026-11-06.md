# #62 逐日距离配对与共同支持直接参照

在既有受控月分析的显式提交/冻结读取实现直接距离参照，复用P0圆、共同支持和活动小时分摊。方法、边界与使用见[合同](../data/monthly-distance-reference.md)。结果标为自有合成小例、不可用作研究；真实执行需要#64准入，真实首月复算留在#68。

已独立核对的用例：赤道小方格面积用WGS84东西/南北每度长度计算，42小时保留；圆外近锋线可配对，已观测未检出和无足够搜索支持不同，分组月小时为42+0+8，月面积时间为三个支持日之和。重叠线不重复计时，同一0.09°经差在0°/60°落入不同带；跨端点不强判；海岸半格保留约21小时和0.024618 km²·d；已知零分母与缺测分开。非本人读取被拒绝；输入移除后本人仍能按原运行身份读取。请求点/版本失配或真实输入被拒绝，无部分结果。

首个端到端用例先因原入口没有新用途而失败，随后通过。审查发现外圈超界会丢弃可证下界、已观测但未分配的活动需要单列、非普通文件输入不能阻塞请求。新增失败用例后修复：跨经度边界外圈仅降级，内圈仍证明5公里下界；海岸已观测42小时保留21小时、排除21小时并记面积时间；缺锋面当天的7小时单列未分配。原后端完整回放另发现两个旧导出依赖字段顺序，恢复后相关27项通过。

最终完整后端330项（74.24秒）、共享工具143项（190.74秒）、data922项通过；Ruff、编译、差异检查通过。Standards和Spec双轴复审均无未解决项。远端无CI或部署验证由这些本地测试推出。

没有使用实际锋面或活动日档进行距离计算；2024-08真实原档日期、时间与有效覆盖未补齐。小例的带端点及误差参数仅是独立可复算的工程参照，不批准真实科研参数、细网格公开或生产部署。

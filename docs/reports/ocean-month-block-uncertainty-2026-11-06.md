# #66 月度近远密度差的相关日组区间

在原本人月提交和同身份读取中，登记合成配对参照可显式选择固定日历块、组数要求、置信水平、迭代数、种子及假设。实际日历缺口不压缩，抽样始终保持同日配对，用抽到的整组小时和面积时间分别重算两组密度。报告配对日期、空间贡献数、非空日历组、块内分子分母、实际运行版本和区间原因。合同见[相关日组区间](../data/monthly-block-uncertainty.md)。

八项原接口用例覆盖：固定种子重跑身份一致、两个不同大小的块在手算极端和总体效应下通过、相邻相关日不拆分、空日历块不拼接，正负零效应、无配对、组不足、组间假设未核实、常数分布及置信要求超出抽样分辨率。区间降级保留已有描述；没有以逐行抽样、置换或符号翻转代替。

最终完整后端 365 项通过（141.30 秒），数据一致性 922 项通过，改动文件 Ruff、编译和差异检查通过，Standards/Spec 无待修复项。该方法的假设和组数只用于登记合成例；没有生成真实候选月区间、确认真实块长或部署。真实统计方案由 #67 冻结，完整真实复算由 #68 验收。

# Hold the event study region fixed

The fixed-region study keeps one WGS84 circle for all dates and defines an event through observed front proximity and registered continuity rules. Holding the footprint fixed makes pre-event and later activity interpretable on the same region. The moving-buffer study retains its original results and geometry. Both use daily apparent fishing hours, the 0.01° analysis-resolution target, and the source and control principles in [ADR-0001](0001-use-apparent-fishing-effort-for-front-response.md).

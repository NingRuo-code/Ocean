# 第四周演示流程

## 启动

在项目根目录打开两个终端：

```powershell
& "C:\Users\lenovo\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\Scripts\uvicorn.exe" app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

```powershell
cd frontend
& "C:\Users\lenovo\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd" run dev -- --host 127.0.0.1 --port 5173
```

访问 `http://127.0.0.1:5173/`。

## 推荐演示步骤

1. 展示系统状态为“本地数据”并说明不依赖在线底图或云端接口。
2. 选择 `2024-08-05`、`124.5°E`、`30.2°N`、`1°` 范围并点击查询。
3. 切换 `10 km`、`±0.25°`、`±0.5°`、`±1°` 范围，展示查询边界框随范围变化。
4. 展示 SST 面场、锋面带、锋面中心线、冷侧区、暖侧区、查询点高亮、经纬网格和比例尺。
5. 关闭和重新打开图层，说明图层开关和图例。
6. 点击分析范围内地图位置，展示 SST、锋面类别、最近锋面距离、局地温差和温度梯度。
7. 展示右侧 SST 趋势、有效覆盖率、锋面线密度、历史概率和月度概率。
8. 在 AI 面板输入自然语言任务，展示结构化任务 JSON、工具调用流程、结论证据 ID 和下一步推荐。
9. 点击“导出当前分析”，说明结果可以保存为本地 JSON。
10. 点击重置查询，展示界面恢复和旧图层清理。

## 异常演示

- 输入超出经纬度范围的数值，展示输入校验。
- 选择不存在日期时，展示明确的无数据提示。
- 点击分析边界外的位置，展示范围外提示。

## 验收重点

- 数据日期、区域和图层同步变化；
- SST 单位展示为摄氏度；
- 冷暖侧编码和锋面线编码符合数据字典；
- 10 km 范围、点位查询和查询边界框能联动；
- AI 面板只组织任务和解释，科学数值来自后端工具；
- 页面断网后仍可使用已下载的本地数据完成演示。

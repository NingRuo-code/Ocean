# 静态视窗读取边界（#6）

沿#1已批准的原`GET /api/viewport`验收入口，复用#4/#5的覆盖与缓存合同。先用自建可手算JS导出小例验证有效Celsius/显式零、损坏层降级、日期/网格/RLE/有限值和历史响应窗口；再核既有许可展示资料及原服务实际响应。不测试私有函数，不造业务替身，不下载原档。

本批只完善现有静态展示适配，源档审计/P0资格仍独立；响应窗口小时不改成同日活动网格，缺字段不补0。原缓存合同升级版本，旧版响应不能绕过新校验。原始NetCDF读取接口保持其原档要求，不靠静态展示填补研究原档。

关键网格、锋面对象、海温编码和响应记录通过类型校验；坏/重复对象计排除数，无法确认的层标未就绪，有效0及多船累计超过24小时保留。SST只接受现有展示合同的明确`degree_C`和正分档；缺日期声明不提升原档时间资格，显式日期冲突则拒绝。竖直/水平线允许零宽/零高包围盒，视窗筛选仍是展示包围盒筛选，不充当研究几何裁切或面积分母。

静态单文件读取上限32 MiB，拒绝重复JSON键、非有限JSON和同一目标二次赋值；显示网格最多2,000,000格，不支持的输入标不可用，不静默截断。本票不支持直接读全球高分辨率原档。当前缓存仍面向固定展示版本，升级为`contract-v2`隔离旧输出；同版本热替换、全局源版本/P0资格及缓存治理按后续任务处理，不在此声称已完成。

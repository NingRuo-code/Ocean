# 显式来源审计与快照读取

关联 #36；沿用既有本地审计入口。此切片登记来源、角色、证据与访问缺口，逐日语义/有效支持和活动零值/粒度分别由 #37/#38 接续，完整月资格由 #41/#44 验收。

```powershell
node tools/audit-research-baseline.mjs --source-registry docs/data/source-registry.json --out data/processed/source-audit.json --report-out data/processed/source-audit.md --private-out data/processed/source-locators.private.json
node tools/audit-research-baseline.mjs --read-snapshot data/processed/source-audit.json
```

未指定新选项时，原展示文件/旧响应表基线输出保持兼容。来源登记是显式审计输入；调整位置可用本地登记文件及 `--source-root`，只选择已获准读取的小范围资料，不扩大下载或运行数据准备。

公共 JSON 和 Markdown 仅含声明的非敏感产品信息、角色、上游逻辑身份、字节/内容校验和及待核项；实际文件定位单独写入私有清单，默认示例存放在已忽略的加工目录。登记表的产品、单位、许可和证据引用均为**待核声明**，不得包含个人路径、凭据或私人端点；本切片不裁定许可正确性或批准公开发布。GFW 抓取代码的 BY-SA/API 非商业标记与治理文档的 BY-NC 标记均保留为冲突证据，须按具体产品/渠道核实。

快照绑定合同、登记处理身份及实际读取内容；生成时间单列。同输入重跑的实质身份一致，文件内容或登记改变会生成不同身份。读取快照仅校验已存结构/身份，不读取登记文件或重扫原数据；校验是完整性检查，不是签名/授权证明。

证据等级分别列声明是否完整、实际可读状态、尚未执行的语义验证及未知有效支持。缺路径和未知单位保留缺口，不填成零活动；空目录的已知文件数可为零，但不代表有效观测为零。展示或预计算表不升级为研究真源，接口健康和元信息齐全也不解除数据资格关口。

每次默认最多读取 1000 个受支持文件、256 MiB 内容；预算不足保留未核缺口，不声明全档完整。仅处理登记根内的资料，不跟随符号链接；输出不可覆盖登记/源资料，也不能与公共、Markdown或私有输出重合。扫描失败只暴露错误类别，内部定位不混入公共摘要。

验证入口：`node --test tools/tests/source-audit.test.mjs`。测试通过实际 CLI 和独立已知字节校验来源角色、内容身份、未知/冲突、私有分离、源移除后的只读回放，以及输出覆盖保护。合成测试不代表真实数据或许可已通过。

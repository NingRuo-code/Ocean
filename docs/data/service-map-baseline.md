## 运行

```powershell
# 已有离线展示路径，浏览器独立新配置后同配置重载。
node tools/benchmark-map.mjs --runs 3 --out data/processed/offline-baseline.json
# 本地原FastAPI与原前端，独立进程和本轮专属空raw/cache；不访问旧服务器。
node tools/benchmark-map.mjs --isolated-service --runs 3 --out data/processed/service-baseline.json
```

原服务复用已有启动适配，挂载当前工作区原前端，运行原应用；不是安装后固定发布，也不是测试业务替身。服务进程及其启动等待在操作计时外；软件依赖使用当前本机环境。每轮浏览器新配置，后端只在整个批次开始时新建空缓存，之后各轮共享；OS/存储缓存不受控，不能把每轮都称后端冷启动。启动状态接口仅在测量后读取，公开结果无地址或本地路径。

测量前的身份哈希会读取本地代码/展示文件，可能预热文件缓存。因此“fresh-profile”只表示浏览器新配置，不表示冷磁盘/冷OS；真正冷读和完整服务热冷对照需后续受控资料及缓存协议，不能从本批推导。

五类场景依次为导航、同配置重载、换日、缩放、平移；每次成功必须匹配当下日期/视野，等待两帧，原服务模式还要求仍在服务器模式且当前视窗就绪，不能静默退离线后判成功。日资料404/403/读取失败及时记失败，保存最后可见状态；HTTP 200和底图都不构成有效观测。无原档时原日接口404是本环境真实缺项，不能当成生产事故，更不能人为补原档以获得绿色。

`elapsed_ms`为动作派发开始到可用的总等待；`after_action_ms`为派发结束后的等待，拖动包含释放后的等待。二者是包含关系，不能相加。请求回调耗时基于Node收到事件的单调时钟；浏览器网络分段、绘制/面板分段存在重叠，不求和；轮询25ms与两帧确认开销包含在结果内。编码与HTTP字节只在可取得时给值，文件路径或在途响应缺字段保持null。

失败/超时的成功耗时为null，不记0；浏览器或原服务启动失败保留计划场景且`action_attempted=false`，这些不是独立的已执行交互。原服务启动失败不输出Python原始错误或配置值；身份收集预算不足等测量前错误仍直接拒绝，不伪造实际交互报告。小样本p95为null，正式目标仍未验收。脚本有失败即非零退出，同时写已形成的报告。

受管进程剔除父环境的OCEAN设置，固定原前端/展示目录、API前缀、独立raw/cache和规则模式；原Settings在导入业务应用前以禁用项目env文件的设置对象重建，不让私人配置改变实际运行来源。私有原始错误流只丢弃，不进入摘要或控制台；配置模块本身无法引入时也安全失败。

冻结前端、受管服务的后端代码、实际入口文档及测量辅助工具哈希，测量后再核；变化会在计算摘要前将成功尝试失效。Git提交与受控路径是否有已跟踪改动分别记录，不能把工作区改动谎称为提交字节。只递归当前代码/展示目录，不扫描原档；单文件流式哈希最多32 MiB，树登记最多20,000项及512 MiB声明大小。外部自建单文件计时夹具只冻结入口及已列出的项目文件，未声明外部依赖不算已冻结。

结果保留每轮浏览器/GPU、Node、原进程Python版本。受管模式还在实际服务进程启动时记录 `service.runtime.installed_distributions`：最多2048条可见分发包名称/版本，按规范化名称及版本排序并生成SHA256身份。名称最多128字符，版本最多128字符；不读取或公开安装路径、直连URL、环境变量或元数据全文。采集耗时独立记录，不混入操作计时。

`recorded`表示本次元数据清单完整取得且名称唯一；同名登记保留全部版本及 `duplicate_names` 并标 `ambiguous`，不悄悄选一份。格式/数量超限或读取异常时标 `unavailable`，条目、数量及身份保持null，不发布半份清单；服务仍可运行，其测量结果和资料缺口分别记录。未受管模式没有Python清单，服务启动失败也不能虚构版本。清单不证明这些包全部已被导入、实际选中了哪份同名包、运行中未变化或安装字节一致；不能替代依赖锁、平台构建及固定发布清单。完整本机清单留在本地加工目录，对外报告只提交审核后的版本摘要、状态、数量和身份。

请求只投影固定角色、方法、状态、编码、大小和时长，未知字段不猜；启动及异常不写入原始错误。`--page`限无凭据、查询覆盖或远程文件主机的本地文件/回环URL；受管模式不能另指定页面或声称自建夹具。

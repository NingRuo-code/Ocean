# 本人合成月任务软件

该适配只计算原已登记自有CC0合成月输入，沿用原月计算；不是正式A研究、长任务平台或TASK保护。默认`OCEAN_SYNTHETIC_RUN_STORE_PATH`未配置，持久任务不可用。需操作者明确指定独立SQLite文件，例如忽略目录`data/runs/synthetic-months.sqlite3`，本人令牌沿`OCEAN_MONTHLY_EXECUTION_TOKEN`配置，不能写入仓库。不要指向案例库、viewport缓存、未知数据库或真实资料文件。

在“月任务条件”中展开“本人合成小例任务”，输入当前服务令牌并核对已登记条件，再明确提交。原真实“提交分析（待接入）”按钮不开放，公开能力检查和旧进程内小例路由保持原合同。界面显示原请求、任务/意图/记录身份和冻结H/E及逐日证据，不自动改地图、保存案例或加入公开成果目录。

新接口为`/api/query/monthly-analysis/owner-runs`：GET `/options`受控读取登记条件及输入SHA256；POST空后缀接收`intent_id`、`input_sha256`和原`MonthlyRequest`的`request`；GET `/{id}`读取终态。每次校验本人；只读不初始化库。新意图核当前精确输入/方法/参数及条件，提交前再次核源；已提交同意图同请求重放直接读取原记录，原源消失后仍可读冻结结果，当前源可用和原样复算未知。相同意图改条件409，不静默新建或替换旧结果。

短同步计算、终态记录及意图映射在同一SQLite事务提交后才返回。终态只有completed/failed，不持久伪造排队/运行或百分比；算术失败保留安全失败原因且没有部分结果。事务中进程退出会回滚未提交的受理，不自动续跑；只保证同意图不重复发布记录，不保证崩溃前未提交的计算只发生过一次。响应丢失/前端超时/关闭页面均可能已受理；重新认证后明确核对或重发原意图，不能把停止观察称为服务端取消。

最多64条记录、每记录及响应1MiB、主库64MiB，SQLite写锁等待1秒；还会使用SQLite事务日志，不将主库限额冒充整个文件系统占用。来源沿原1MiB读取和31日/每日1000单位合同。默认读取不建文件；未知/损坏库、锁/容量/存储提交失败明确拒绝，旧记录保留。记录身份校验绑定原意图/请求/输入与结果身份，不是来源签名或生产备份恢复证明。

令牌仅本页内存，关闭月面板/锁定/来源切换/鉴权失败清令牌和私有显示。在途提交可能仍完成；未核实的原意图保留供本人明确核对。可明确清除本页提交引用以重新准备，但此动作不取消或删除服务记录。未配置时不回退浏览器或进程内保存，隔离公开只读包禁止全部新接口。

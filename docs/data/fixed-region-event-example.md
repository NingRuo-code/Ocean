## 本批实现边界

在原`tools/run-front-response-experiment.mjs`增加显式固定区域样例模式，旧移动锋面缓冲实验保持原语义。核心复用A01的已知单元/日状态及共同支持H/E，不搬旧增强阈值、逐行推断或预计算事件表作为固定区计算。

请求明确用途、地点、公里半径、锚日搜索起止及输入/方法/参数版本；输入必须是明确标注且允许公开聚合的自建合成夹具。圈及单元面积由样例声明，前后固定；真实GIS、完整事件识别和P0事件资格分别留给#62/#74/#75，不以本样例解除。

简单规则只接受搜索期内单一可核对的“前一日观测为未出现、当日观测为出现”事件；锚日不看活动小时。未知前日不当退出，多个候选不自行择优。锚日搜索期与实际前后读取范围分开，事件日0单列。已存在、缺观测和无新进入分别说明，不宣称物理生命周期。

独立计算前7日[-7,-1]、事件日[0,0]、后1–3日[1,3]和后1–7日[1,7]，列明每窗实际日期、已知小时、有效面积时间和日均/密度。只有整窗在同一固定已知单元支持上完整，才比较归一化变化；缺日不补零，零基线保留绝对差、相对变化未知且说明原因。

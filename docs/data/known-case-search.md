# S01：已知历史案例检索通路

变体：沿用coldstore，左深色控制台、右浅色阅读，冰色标操作与当前项。
主视觉：保留原地图与投影/海岸/网格/控制，候选在原历史子视图、原证据在底部按需展开。
密度与动效：少量候选、短说明、44px操作；来源与库范围折叠，不新增常驻评分/权重模块。

关联#160/#159，基线main `11989320f39fb84122a5ecb03af0f1367d646a3a`。采用已获用户确认的真实浏览器→实际只读服务→明确探索允许库→原证据/返回接缝，API辅助核身份/数值/权限。复用#97已应用条件与草稿/旧成果隔离，无需重新请求测试授权。

本批仅自建CC0合成探索目录，读取既有G3/A冻结月背景，不是实时渔业或真实B响应。初版严格匹配登记固定点/半径，候选完整月结束早于参考日；不猜海域，不以视野bbox代公里圆。季节±15日/环境特征排序属于S03以后，当前用确定的月份/ID顺序并直述未使用特征，不称相似程度或渔场排名。

只读GET不得执行分析、原档扫描/准备、下载或AI。目录明确阻止私人、验证保留、未知用途及真实来源，搜索/计数/详情均同一 gate；合成保留集反例不是实际独立性隔离证明。引用原A身份/条件/H/E/单位/逐日证据，缺活动或未知不补零，不把月背景称B事件。修改筛选或月草稿保留原查询并标待更新；明确重新检索才更新。离线如实提示需要服务，不模拟结果或自动回退。

操作：工作台→相似历史案例→少量候选→点击某月→底部原证据。关闭后可继续选择，重开已读证据不发送新请求。“按已应用条件检索”才使用当前筛选；“更多”继续旧查询。离开历史子视图、主标签或工作台快捷入口时取消旧请求，迟到返回不影响新页面。

接口：`GET /api/query/known-cases`接受`reference_date/longitude/latitude/radius_km/library_id/case_type`，当前库为`authored-exploration/v1`，类型仅`monthly_background`。首屏`offset=0,limit=3`；继续翻页和`GET /api/query/known-cases/{case_id}`必须带原`library_version`。409后明确重查，不继续旧页；403/身份或单位不可核对时清除旧案例值。固定点/半径不在当前登记中时如实提示不支持，不静默改条件。

默认2024-08-05、124.5°E/30.2°N、20km可查4个允许历史月，首屏3个。2024-06原H=10h、E=2km²·d、H/E=5，D=1/30；2023-08有效0；2024-12仅在更晚参考日可选，未知支持保持未知。目录中的合成私人/保留反例被本服务排除，但不代表对整个既有合成G3源实施真实研究隔离。

服务只加载随包的两份有界登记文件，无外部取源或数据准备；目录最多16项，页最多3项，读取超时10秒。原始来源/方法与逐日支持在底部折叠/滚动阅读，手机保留地图操作。完整实际验证及后续缺项见[交付记录](../reports/ocean-known-case-search-implementation-2026-10-26.md)。

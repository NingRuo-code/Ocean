# 月分析同日距离参照

在[直接距离参照](monthly-distance-reference.md)的登记合成包中，维护者可预先登记 `distance_comparison`。字段为 `version: same-day-distance-background/v1`、`target_band`、`reference_band`、`minimum_area_ratio`。目标与参照使用同圆内两个不同且按距离排序的已知带，以零为首索引；未知带不允许作参照。最小面积比须明确提供且在 (0,1] 内，当前不默认任何研究阈值，也不注册额外空间域。

每天在同样的 P0 规则和来源下取两带的小时及面积时间。双方均须有有效面积，较小面积与较大面积的比达到预先登记的要求。若按中心选格使其中一带的有效支持超出用户圆，保留主距离结果并排除该对。记录所有候选日、纳入日期、排除原因及双方按各自面积时间计算的日权重，不用小时高低选对照。对纳入的同一批日期分别重算两组分子与分母、密度和密度差；有效零背景或超出数值范围的比值仍可保留有限绝对差。无可比日期保留原距离描述，不填入背景。

逐日记录两带贡献代表点距圆心的局部投影面积加权平均，用于说明位置差异。有同日合格 SST 时，按[相同测温支持规则](monthly-side-environment.md)分别诊断两带，并在双方均有测温的纳入日上报告面积时间加权温差。可选温度叠置在每日活动格与温度格的潜在组合数超过 4096 时停用，并报告原因；这只是计算量上限。SST 诊断不调整近远组密度或匹配；距岸、水深、渔具及圆内位置仍属于未控制因素。未登记外部背景或环境资料时不代换、不补值。

逐日诊断和月比较由同一原提交和冻结结果读取。这一功能验证配对流程，不能推出真实候选月资格、因果、渔获收益或预测增益。正式主方案和敏感性规则另由 #67 冻结。

已登记配对结果可附[相关日组区间](monthly-block-uncertainty.md)，日期和两组分子分母仍沿用本表。

## 接口与权限

- `GET /api/query/monthly-analysis/examples`：读取明确标注的合成样例条件和版本，不执行计算。
- `POST /api/query/monthly-analysis`：显式提交用途、地点、公里半径、月份、输入/方法/参数版本。只有配置的本人Bearer凭据可执行；未配置时关闭执行，访客只读。
- `GET /api/query/monthly-analysis/{run_id}`：读取该进程保存的冻结运行状态和获准公开的合成聚合，不隐式重算或读源。未知/重启丢失的记录返回404。

调用者不能提交任意文件路径、原始逐格资料、执行者身份或研究资格。服务只接受服务端登记的合成输入，严格匹配其明确支持的点、公里圆、月份及版本；其他条件明确拒绝，不回退固定锚点。真实来源不能仅改标签通过；本阶段只允许仓内已审核的合成样例目录和schema。

这是同步、单进程、单本人受控适配。记录在内存中有界保存，容量满拒绝新执行，保留既有结果。没有持久队列、自动续跑、跨进程共享、取消或生产部署承诺；进程重启结果不可读，需显式重新提交。后续W/TASK复用计算与结果合同再扩展身份/持久任务。

当前只在隔离本地服务中启用本人执行：设置私有环境变量`OCEAN_MONTHLY_EXECUTION_TOKEN`，使用`Authorization: Bearer <私有值>`提交。未配置时POST返回503，凭据缺失或错误返回401；公开样例目录和已完成合成聚合可匿名读取。部署时默认保持关闭，本切片不安排公网凭据传输或生产启用。

请求示例（JSON正文，凭据放请求头）：

```json
{"purpose":"monthly_spatial_example","longitude":124.5,"latitude":30.2,"radius_km":20,"month":"2024-02","input_version":"synthetic-month/v1","method_version":"monthly-known-support/v1","parameter_version":"known-unit-membership/v1"}
```

返回运行ID、提交条件、实际状态历史、完成/失败及冻结结果。读取同一ID不访问输入文件；本进程最多保存64条运行，满后拒绝新提交而不删除旧结果。样例输入上限1MiB、16组条件、每月31条日记录、每天1000个已知单元；日期、单位、重复日/单元和来源角色冲突都会失败并保留无半成品的记录。

## 数值与证据

样例明确声明所属公里圆的已知空间单元和有效面积，不把bbox冒充圆，不宣称已计算实际海岸/格边或船舶格内位置。只有同日锋面和活动共同有效、有限非负小时且有效面积为正的单元进入分子和分母。缺可选SST不阻断这个最小主用途。

枚举月份全部日历日。逐日保留有效零、无记录未知、缺测、未准备和读取失败。总小时H、同支持日均H/D、面积时间E和密度H/E分别命名，E单位km²·d；无有效支持时四者保持未知。部分支持只报告已知支持的部分量，不解释成全圈或真实研究结论。

提交后冻结原请求、输入内容哈希、方法/参数版本和证据；完成只发布整体结果，异常记录失败且不带半成品。普通读取、切换其他请求或输入更新不重算/改写已有结果。公开产物不含单元细节、私人路径、凭据或执行者身份。

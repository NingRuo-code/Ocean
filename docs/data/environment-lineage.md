# 本地、离线与服务器资料身份核对

关联 #40、规格 #35。入口仍为显式审计CLI，不新增网页重任务或自动扫描、下载、部署。

```powershell
node tools/audit-research-baseline.mjs --compare-environments docs/data/environment-comparison.json --out data/processed/environment-comparison.json --report-out data/processed/environment-comparison.md
node tools/audit-research-baseline.mjs --read-environment-comparison data/processed/environment-comparison.json
```

配置至少包含两个不同逻辑环境，最多八个；环境ID是简短逻辑标签，路径相对配置文件。`source_snapshot`消费 #36 冻结快照，先校验其内容身份；可选 `daily_snapshot`复用 #37/#38 冻结读取器核身份，并验证它属于同一来源快照。不读取私有定位，不打开源资料，回放比较报告也不重新打开输入。配置声明了不可读或坏快照时明确失败；未能取得环境资料时不填路径，保留未知。

`evidence_kind`分别标记真实本地、捕获的远端资料或合成夹具。`deployment_commit`只接收已有证据支持的完整提交身份；不能填当前代码来代替旧结果、离线包或服务器提交。该字段仍标为维护者证据声明，不是签名认证。源快照、源处理版本、可选 `aggregation_version`和部署提交分别比较。

`acquired_at`是资料捕获/取得时刻的显式声明，采用带时区的ISO时间，不使用来源审计生成时间补齐。动态latest缺该证据时列为未知；即使时刻存在，也不能证明更早时刻的历史版本。比较报告绑定内容证据、参数声明和比较实现指纹，生成时间单列。源审计重生成但资料身份不变时，不因审计时刻改变比较身份。

## 怎么读比较结果

- `content`比较所捕获文件的SHA256及字节数多重集合，忽略所在路径和文件名；只有两边都完整可读且非空才判匹配/不同。部分、空、未取得不能变成完整一致。结果只适用于登记和捕获范围，不能外推完整服务器目录或全部月份。
- 各字段分开列 `matched/different/unknown`及证据指纹。产品/角色/单位/源关系/许可来自来源登记，属于声明的比较；逐日日期、实际坐标步长、声明粒度、时间验证及单位证据来自可选逐日审计。声明0.01°仍不是原始精度证明。
- 逐日审计的配置、程序及每来源结果证据指纹也分别比较。同源但采用不同小时字段、质量掩码或解码实现时，不会仅因日期/单位集合相同而隐藏处理变化；结果证据包含内容身份，证据不同本身仍不等于数值不同。
- 许可来源冲突与源到产物父项缺失继续显示；父项内容也参与核对。源、显示和预计算角色不会合并，旧响应表不会因此变成任意区域或后七日分析输入。
- 字节不同不等于数值不同。换行、编码、排序等差异需要独立解释；本工具不默认归一化源文件，不修改原始内容证据，也不以宽松比较提升研究资格。
- 公开投影只保留逻辑ID、快照/字段指纹、枚举、日期与粒度摘要；原始元信息值、路径、坐标/逐格小时和受限内容不回显。坏输入只返回通用错误。内部定位和实际捕获文件放在忽略目录。

输出JSON/Markdown采用临时文件后替换；拒绝覆盖输入、相互重叠和路径别名。内容哈希用于完整性与追踪，不是授权签名。所有比较均保持 `research_ready/public_release_approved=false`。

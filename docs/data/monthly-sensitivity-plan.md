# 月分析冻结记录与敏感性比较

用本地 `tools/monthly_sensitivity_plan.py --input <登记合成包> --plan <草案> --out <新登记包>` 先生成冻结文件，然后把输出作为原本人月分析入口的登记输入。已有目标文件不会被覆盖。工具记录基础输入、计划和执行程序的 SHA-256，以及几何与抽样运行库版本。计划包括版本 `ocean-month-sensitivity-plan/v1`、声明冻结时间、先前是否看过目标效果、理由及最多六个有身份和理由的变体。提交仍以完整登记包字节的 SHA-256 为 `input_version`；修改基础输入、计划或执行环境必须重新冻结。冻结时间是登记声明，不代替独立时间证明或研究批准。

合成参照通过原入口执行主方案和所有登记变体，保留矩阵而不选择有利结果。支持的单轴为公里半径、P0 分摊方式、距离带端点、分析圆最低实际共同覆盖和合法大值影响。共同覆盖只计圆内面积，即使按中心选入的非比较带贡献伸出了圆。大值诊断只在独立变体移除明确门槛以上的格并报告数量及小时，主分析保留所有合法小时。未支持的变体有失败原因；资料不够但能保留描述时仍返回该行。上限限制格数、几何顶点、距离计算和可选测温候选量，只是软件预算。

矩阵记录基础与派生身份、参数、成对日期、排除、两侧小时和面积时间、效应及区间状态。只有日期和两带实际支持几何身份均一致才标同支持。主结果仍含完整逐日表；矩阵内的主计算身份与附上矩阵后的最终成果身份分别可追溯。输出始终标为 `synthetic_exploratory`；不运行正式多项检验。

当前仅验证登记合成流程；带变体的真实研究请求及附带外部 P0 准入的变体请求不被本工具替代。正式 #67 还要用实际锋面精度、活动日界、共同覆盖与许可等依据冻结选择及理由，并为每个真实变体核对其同用途 P0 支持。首选 2024-08 中心三个半径仍为 0/31 天，不冻结真实科学阈值。真实结果由 #68 承接。

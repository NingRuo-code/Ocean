# 自有合成报告案例库

只保存经公开投影核验的CC0合成月报告及本人的人工标题/标签/笔记。它不是原始资料、完整TASK保护或真实研究案例交接。单一配置本人复用`OCEAN_MONTHLY_EXECUTION_TOKEN`，不支持多用户身份。

默认`OCEAN_CASE_STORE_PATH`未配置，案例读写不可用。需要本机软件验证时，由操作者明确指定独立SQLite文件，例如仓库已忽略的`data/cases/known-months.sqlite3`；令牌只通过既有服务端配置提供，不能写入仓库、URL或截图。服务/配置重启不改已有案例身份，令牌轮换仍是同一配置本人。

从公开合成月报告点击“保存合成案例”，在“我的案例”中输入该服务的访问令牌和人工信息后明确保存。令牌仅留在当前页面内存；离开案例区会锁定并清除令牌和未保存草稿，重新进入/刷新后需再输入。相同报告和未变表单复用同一保存意图；改变内容后才能形成新意图。响应丢失时可在原页重试或重新认证读取案例核对。

API位于现有`/api/query/monthly-analysis/cases`：POST显式保存，GET列举，GET `/{case_id}`重开。所有调用均在服务端校验Bearer本人边界；普通公开月/报告读取不需要令牌。保存新案例前核对当前公开许可和精确成果/投影/报告身份；已成功意图重放返回原冻结版本，不重读消失的上游包。案例从不加入公开目录或静态离线包。

标签每行一项，逗号属于标签内容，编辑笔记不拆改标签。目录只传标题和标签，人工笔记在选定版本详情读取，避免合法满库超出前端读取预算。

GET目录可传`q`按标题/标签作字面量、不区分大小写的检索，返回全部匹配项及数量（库上限64，不静默截断）。GET `/{case_id}/versions`列出最多16个版本；GET `/{case_id}?version=N`读取不可变旧版本。PUT `/{case_id}`仅接收人工信息、当前所见版本号/身份及独立幂等键，在同一事务内核并发；没有变化不制造新版本，版本冲突返回409并保留旧记录。界面拒绝时保留草稿，只有明确选择版本或“读取最新版”才替换编辑区。笔记是人工内容，永远不改冻结报告的科学值。

库使用应用标记和版本、SQLite原子事务及内容校验；只读不初始化存储，未知/损坏文件不被覆盖。当前最多64案例、每案例16版本、64MiB库预算；锁/空间/路径不可用明确失败，旧成功记录保留。不要将库放入viewport缓存或临时目录；仓库默认普通viewport清理不涉及独立案例库。备份、迁移、真实清理保护和恢复仍须按原TASK/OPS关口另验。

保存的科学值来自冻结合成报告，人工笔记不改科学解释。原包消失后仍可读的是保存时的允许聚合快照；当前源新鲜度、可重算性、真实研究资格均不因此成立。隔离只读发布包继续禁止案例API和全部写操作，未自动开启该功能。

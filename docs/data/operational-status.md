# 轻量分层状态（OPS #233）

沿规格 #226 已确认的原服务/API、真实浏览器和受控监测边界验收：原应用的只读状态适配、现有日期清单和已冻结公开样例；用独立日历例验证历史归档、未知频率、失败及采样陈旧。浏览器通过现有数据说明入口显式读取，网络故障在网络边界注入；不另造分析服务。服务器资源盘点 #47 和生产部署不在此处冒充完成。

实施范围：有界采样和单份内存缓存，公开投影不含主机、路径、配置或原始错误；回环/代理入口通过维护者本地的一次性探针分别记录，浏览器只证明其实际访问路径。未接入的任务、备份、活动数据和 P0 资格保持未连接。现有已冻结 A 为合成只读样例，能读取不等于真实整月研究完成。

验证计划：先贯通原 API 的历史日期索引及未知层；再验证有界缓存、损坏/缺失输入、日期规则与最近成功；接入真实浏览器并核地图条件和离线行为；最后在隔离发布中核相同发布身份及原入口。实际验证结果随交付报告记录。

## 使用与解释

页面“查看数据说明 → 服务与资料状态 → 读取状态”，不会自动轮询。折叠的“采样记录”保留完整时刻与发布身份，日常摘要不重复展开时间戳。离线文件仍可操作地图，但不能据随包日期推断服务可达。

`GET /api/status` 同属原 FastAPI 应用，`Cache-Control: no-store`，进程内最多保留一份快照及每层最近成功时刻，进程重启后最近成功重新从未知开始；不会写磁盘历史。30秒内复用同一快照，90秒后浏览器/探针标陈旧。数据读取失败只影响对应层；每次常规采样最多读日期索引64 KiB、公开冻结样例1 MiB、活动清单256 KiB，日历最多3660项；只读普通文件，不扫描目录或调用清单重建、分析、归档准备、AI。

服务端采样等待最多2秒，读文件时不持状态锁，同一进程最多一个后台采样工作；超时层明确`sampling_deadline`并保留最近成功，迟到工作不能覆盖结果或继续读取下一层。若底层文件系统长期挂起，这一个守护线程可能等待至文件系统恢复，但请求不会累计新采样工作；恢复后且达到下一采样周期才能重读，不冒充已终止底层IO。此限制不替代完整生产故障处理/监测资源准入。

日期索引仅证明导出登记，可分别显示锋面/海温日期和清单导出日期；不等于每个图层文件校验通过。当前随包为历史归档，更新频率未登记，不能据系统当天日期计算延误。活动清单若存在仅投影日期登记，忽略小时、格点、船舶与其他字段；来源的新鲜度、物理文件完整性和P0资格未验证。冻结A只核现有合成公开样例的读取/投影，分析执行未探测；隔离发布明确禁用执行和模型。任务、备份、代理以及P0资格尚无已连接权威状态，保留未连接。

维护者可显式指定实际回环与入口，以一次性探针分辨故障位置：

```powershell
python tools/sample-operational-status.py --direct <loopback-origin> --entry <entry-origin>
```

占位符换为本人核实的 HTTP(S) origin，无凭据、路径或查询；`--direct` 必须回环，`--entry` 可省略。无默认目标、不跟随跳转、不使用环境代理、不保存历史或输出地址/内部错误。每个路径仅顺序GET现有health/status，单响应64 KiB，路径由独立子进程限制6秒，总共最多两条路径；最多一份16 KiB输出，不探测浏览器或假装已核代理配置。重复采样建议间隔至少60秒；应用端仍有30秒采样缓存。浏览器路径必须另以实际页面核对。此命令只读但生产入口仍须使用实际获准连接信息；本轮仅在隔离回环/受控代理验证。

发布身份由已验证的隔离启动器设置；普通开发服务返回版本未知，不能用配置字符串假充已发布身份。`overall=partial` 表示本阶段存在未接入层，不是“全部正常”。后续任务/备份/P0适配依原票接入，不因本项完成改变科研、现服准入或生产关口。

# 月分析冷暖侧与海温子集

沿用[直接距离参照](monthly-distance-reference.md)的提交与同一结果读取。维护者可为登记的合成小例设置 `side_environment_version: p0-side-and-sst/v1`。完整包身份覆盖这个选项；不改变已经登记的输入、主距离规则和必需层。当前不接受正式真实请求附带该选项。

冷暖侧沿用 P0 有效锋面格的 `side` 标签。同日每个活动贡献必须全部落入同一已知侧，且与锋线位置不确定区分开。跨侧、缺标签或同日线材料、搜索未核实、位置下界为零，或两个不同候选锋线在误差范围内同为最近，均保留未知；完全重复或逆序重复线不作为第二个候选。侧别小时和面积时间使用同一贡献，日级三组加总核对主分析。无该组贡献时区分已知零面积与缺主支持，均不给密度。

可选 SST 只从同日、原登记来源、P0 校验为分析源的摄氏度格读取有限 `temperature_c` 值。对共同支持的空间重叠按面积分摊活动和面积时间，并以面积时间加权海温；偏移为 0 日。不填补无温度、缺日或时间、单位和覆盖未核实的格。缺可选 SST 只减少子集；明确要求 `front_effort_sst` 的主分析仍沿用其原三层交集。

日与月的 `side_environment` 与主距离共用冻结结果身份。结果含分组小时、面积时间、密度及零/未知原因，月表含各组日数、SST 来源与缺失原因。这里没有温差、梯度或锋面强度估计。合成参照不构成真实侧别资格，也不能推断捕捞量、收益或成功率。
